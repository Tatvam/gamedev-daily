Platform tilesets: nine pieces for a platform of any size

How four corners, four edges and one centre tile build a platform of any width and height, and how to pick the right piece for each cell.

You draw one nice platform tile: dirt inside, grass on top, a dark outline all round. Then you place six of them in a row and three rows deep, and the platform looks like a stack of crates. Every tile has its own outline and its own strip of grass, so the grid shows everywhere.

A platform only has an outline on its outside. The tiles in the middle should not know they are tiles.

Each cell needs to know which sides are open

Ask four questions about any cell of a rectangular platform: is there sky above it, below it, to its left, to its right? A top row cell needs grass and a top outline. A left column cell needs a left outline. A middle cell has platform on all sides, so it needs only dirt.

For a rectangle at least 2 by 2 there are only nine possible answers. That gives the nine-piece set (also called a 3 by 3 or nine-slice tileset): four corners with two open sides each, four edges with one open side each, and one centre with none.

The rule for picking a piece

Count columns from 1 at the left to w at the right, and rows from 1 at the top to h at the bottom. Then each cell picks its piece in two small steps:

  1. Column: 1 if the cell is in the first column, 3 if it is in the last, otherwise 2.
  2. Row: 1 if the cell is in the top row, 3 if it is in the bottom row, otherwise 2.

The piece number is (row − 1) × 3 + column. The top-left cell is row 1, column 1, so piece 1. A cell in the middle of the top row is row 1, column 2, so piece 2. It works for a 2 by 2 block and a 40 by 10 cliff alike.

Draw the nine as one block, then cut it

Do not draw the set tile by tile. Draw one small platform 3 by 3 tiles big (24 by 24 pixels for 8 pixel tiles) and cut it into nine squares. Because you drew it as one picture, the corners already join the edges and the edges already join the centre.

Two extra conditions are where most sets fail:

  • The repeating pieces must be seamless along their run. The top and bottom edges repeat sideways, the left and right edges repeat downwards, and the centre repeats both ways, so each must join copies of itself like a seamless tile.
  • The corners must also join each other directly. A 2 by 2 platform has no edge pieces at all, only the four corners side by side. Test that size first.

Shade all nine from one light. Lit from the top left, the left edge usually gets a light strip and the right and bottom edges a darker one.

Rule of thumb

Put detail where pieces appear once and keep it quiet where they repeat. The centre fills most of a big platform, so a bold mark there becomes a pattern.

Nine pieces is a convention for rectangles, not a law. It stops working at width or height 1: a one-tile-high ledge needs a piece with both a top and a bottom edge, and none of the nine has that. You will see it break in the demo.

The code

The sheet platform.png is the 24 by 24 block of nine 8 by 8 pieces. pieceFor is the two-step rule. The platform is the demo's starting size, 6 by 3 tiles, at 4x.

local TILE = 8
local SCALE = 4
local sheet
local quads = {}
local platform = { x = 2, y = 5, w = 6, h = 3 }   -- position and size in tiles

-- Which of the nine pieces does cell (x, y) of a w by h platform need?
local function pieceFor(x, y, w, h)
  local col = 2                                  -- middle column
  if x == 1 then col = 1 elseif x == w then col = 3 end
  local row = 2                                  -- middle row
  if y == 1 then row = 1 elseif y == h then row = 3 end
  return (row - 1) * 3 + col                     -- 1 to 9, read like a book
end

function love.load()
  love.graphics.setDefaultFilter("nearest", "nearest")
  sheet = love.graphics.newImage("platform.png")  -- 24 x 24: the 3 x 3 set
  for row = 1, 3 do
    for col = 1, 3 do
      quads[(row - 1) * 3 + col] = love.graphics.newQuad(
        (col - 1) * TILE, (row - 1) * TILE, TILE, TILE, 24, 24)
    end
  end
end

function love.draw()
  love.graphics.scale(SCALE)
  local p = platform
  for y = 1, p.h do
    for x = 1, p.w do
      local piece = pieceFor(x, y, p.w, p.h)
      love.graphics.draw(sheet, quads[piece], (p.x + x - 1) * TILE, (p.y + y - 1) * TILE)
    end
  end
end

Change w and h and the platform rebuilds from the same nine quads. Because x == 1 is tested first, a platform one tile wide gets only left pieces: the broken case from the demo.

Pitfalls

  • Edges that do not repeat. A top edge that looks fine once can show a seam every 8 pixels along a long platform. Test three copies in a row.
  • Only testing big sizes. At 2 by 2 the corners touch each other directly. Check 2 by 2, 3 by 3 and something large.
  • Platforms one tile thick. The nine pieces cannot close a 1 by n ledge or an n by 1 pillar. Covering every rectangle, thin ones included, takes 16 pieces, which is where the next lesson goes.
  • A busy centre. The centre is used (w − 2) × (h − 2) times, far more than anything else on a large platform. Use tile variants from the previous lesson for it rather than one loud tile.
  • Shading that ignores the light. A dark left edge in a game lit from the top left makes the platform look inside out. Shade the set as one form.

In real games

Corner, edge and centre sets like this one are a common way to build rectangular ground in 2D tile-based games, often with extra pieces for thin ledges and inner corners.

Engines use the same nine regions to stretch one image instead of repeating tiles. Unity's Sprite Editor lets you set borders on a sprite so that a Sprite Renderer in Sliced or Tiled draw mode keeps the corners fixed and stretches or repeats the rest. Godot has a NinePatchRect node that does the same for user interface panels. LÖVE has no built-in version, which is why the code above picks the pieces itself.

Your turn (15 minutes)

  1. In your pixel editor, make a 24 by 24 canvas and turn on an 8 by 8 grid.
  2. Draw a small platform that fills it: outline, a top surface, a fill, and shading from your game's light direction.
  3. Copy the middle column and paste it twice more to make a 40 pixel wide platform. Fix any seam you see in the top edge and the centre.
  4. Now delete the middle column and middle row to make a 16 by 16 platform from the corners alone. Fix any corner that does not meet its neighbour.

You are done when the 16 by 16, 24 by 24 and 40 by 24 versions all look like one solid object with no visible grid. For a bonus, export the block as platform.png and run the LÖVE code.

Takeaways

  • A cell's piece depends only on which of its sides face the outside of the platform.
  • Four corners, four edges and one centre cover every rectangle from 2 by 2 upwards.
  • Pick the piece from the column (first, middle, last) and the row (top, middle, bottom).
  • Draw the set as one 3 by 3 block, then check that edges repeat and corners meet each other.
  • Keep the repeated pieces quiet and put detail in the corners.
