Corner-aware autotiling: the 47 tile blob set

Why inner corners need the four diagonal neighbours, and how a simple rule shrinks 256 combinations down to the 47 tiles of a blob set.

Your terrain draws itself with the 16 tile set, and it looks right everywhere except one kind of spot: where the ground turns inwards, the outline stops short and leaves a little bite of bare dirt. Around a hole in the ground there are four of them.

The tile in that crook cannot draw the corner because it never looked at the corner. This lesson teaches it to look.

Look at all eight neighbours

Yesterday's mask asked four questions: is the cell above, right, below and left of me ground? An inner corner is the spot where two of those answers are yes but the cell between them, on the diagonal, is sky. Four sides cannot tell that cell apart from solid fill, so it gets tile 15 and no corner is drawn.

The fix is to also check the four diagonal neighbours, the cells that touch only at a corner. Keep the side values from before and give each corner the next free power of two, going clockwise: up-right 16, down-right 32, down-left 64, up-left 128. The mask now has eight bits and runs from 0 to 255.

Why not 256 tiles?

Eight bits give 256 combinations, but most of them look the same. In the right-hand example the cell has sky above it, so its top edge is already drawn. Whether the up-left cell is ground or sky changes nothing, because the corner is part of the edge. That gives the one rule of corner-aware autotiling:

The corner rule

Count a diagonal neighbour only when both sides next to it are ground. Up-right needs up and right, down-right needs down and right, down-left needs down and left, up-left needs up and left.

Apply the rule to all 256 masks and only 47 different ones are left. You can count them by asking, for each pattern of sides, how many corners are still allowed to matter:

This set is usually called the blob tile set, because it can draw any blob-shaped area of terrain, holes and all. The 16 tiles from yesterday are still in it: they are the versions where every corner that matters is ground. The other 31 add one or more inner corners.

Drawing 47 tiles without drawing 47 tiles

The art comes from the same parts as before plus one new part: an inner corner patch, three to six pixels where the outline of the neighbour above meets the outline of the neighbour to the side. Draw one patch per corner, and every one of the 47 tiles is fill, plus an edge for each missing side bit, plus a patch for each missing corner bit.

The patch must continue what the neighbours draw. At a top-left inner corner in the demo, the wall above brings its outline and lit column down, and the ledge to the left brings its grass across. The patch closes the outline with one pixel and lets the grass run into the corner.

A convention, not a law

The bit values and the sheet order are conventions; many tools number the eight neighbours clockwise from up instead. Any order works if your code and your sheet agree.

The code

The sheet terrain47.png is 64 by 48 pixels: 47 tiles of 8 by 8, eight per row, sorted by mask from smallest to largest. maskAt applies the corner rule as it builds the mask, and love.load numbers the 47 masks that can come out of it, which is exactly the order of the sheet.

local TILE = 8
local SCALE = 4
local UP, RIGHT, DOWN, LEFT = 1, 2, 4, 8
local UPRIGHT, DOWNRIGHT, DOWNLEFT, UPLEFT = 16, 32, 64, 128
local sheet
local quads = {}
local slotOf = {}       -- slotOf[mask] is 1 to 47
local map = {}          -- map[y][x] is true where there is ground

local START = {
  "............",
  ".........##.",
  "..###....##.",
  "..#.#.......",
  "..###...#...",
  "##......##..",
  "####..######",
  "############",
}

local function has(mask, bit)
  return math.floor(mask / bit) % 2 == 1
end

local function solid(x, y)
  local row = map[y]
  return row ~= nil and row[x] == true    -- outside the map counts as sky
end

local function maskAt(x, y)
  local mask = 0
  if solid(x, y - 1) then mask = mask + UP end
  if solid(x + 1, y) then mask = mask + RIGHT end
  if solid(x, y + 1) then mask = mask + DOWN end
  if solid(x - 1, y) then mask = mask + LEFT end
  -- the corner rule: a diagonal counts only when both sides next to it are ground
  if has(mask, UP) and has(mask, RIGHT) and solid(x + 1, y - 1) then mask = mask + UPRIGHT end
  if has(mask, DOWN) and has(mask, RIGHT) and solid(x + 1, y + 1) then mask = mask + DOWNRIGHT end
  if has(mask, DOWN) and has(mask, LEFT) and solid(x - 1, y + 1) then mask = mask + DOWNLEFT end
  if has(mask, UP) and has(mask, LEFT) and solid(x - 1, y - 1) then mask = mask + UPLEFT end
  return mask
end

local function obeysRule(mask)
  if has(mask, UPRIGHT) and not (has(mask, UP) and has(mask, RIGHT)) then return false end
  if has(mask, DOWNRIGHT) and not (has(mask, DOWN) and has(mask, RIGHT)) then return false end
  if has(mask, DOWNLEFT) and not (has(mask, DOWN) and has(mask, LEFT)) then return false end
  if has(mask, UPLEFT) and not (has(mask, UP) and has(mask, LEFT)) then return false end
  return true
end

function love.load()
  love.graphics.setDefaultFilter("nearest", "nearest")
  sheet = love.graphics.newImage("terrain47.png")
  local slot = 0
  for mask = 0, 255 do
    if obeysRule(mask) then
      slot = slot + 1                      -- ends at 47
      slotOf[mask] = slot
      quads[slot] = love.graphics.newQuad(
        ((slot - 1) % 8) * TILE, math.floor((slot - 1) / 8) * TILE, TILE, TILE, 64, 48)
    end
  end
  for y = 1, #START do
    map[y] = {}
    for x = 1, #START[y] do
      map[y][x] = START[y]:sub(x, x) == "#"
    end
  end
end

function love.draw()
  love.graphics.scale(SCALE)
  for y = 1, #map do
    for x = 1, #map[y] do
      if map[y][x] then
        local slot = slotOf[maskAt(x, y)]
        love.graphics.draw(sheet, quads[slot], (x - 1) * TILE, (y - 1) * TILE)
      end
    end
  end
end

The demo uses the same values, map and sheet order: its slot number is the index into quads.

Pitfalls

  • Using the raw 8-bit mask as the tile index. Without the corner rule you need 256 tiles, 209 of them duplicates. Apply the rule first, then look up the slot.
  • Mixing up which corner is which. Up-right needs up and right, not up and left. A swapped pair draws a patch on the wrong side and the outline breaks in a new place. Test with a ring around a single hole: all four corners must close.
  • A wider update area. Painting one cell now changes the masks of all eight neighbours, not four. If you cache tile numbers, recompute the 3 by 3 block around every change.
  • Patches that ignore the neighbours. A patch must line up with the outline, grass and shading of the cells around it. Check it inside a ring, never on its own.
  • Cells that touch only at a corner. They are not neighbours in this scheme, so they draw as two separate blocks. That is usually what you want; if not, paint the gap.

In real games

Godot 4's TileSet terrains have a Match Corners and Sides mode, which compares all eight neighbours, alongside Match Sides from yesterday and Match Corners. The Tiled map editor's terrain sets come in corner, edge and mixed types, and the mixed type considers both. Unity's Rule Tile from the 2D Tilemap Extras package lets each rule check all eight neighbours, so a blob set can be set up there by hand. Some tools, RPG Maker among them, avoid drawing every whole tile by assembling each one from quarter-tile pieces; the corner rule decides which quarter goes where.

Your turn (15 minutes)

  1. Take your 16 tile sheet from yesterday, or draw tile 15 as plain seamless fill.
  2. On a separate 24 by 24 canvas, build a 3 by 3 ring by hand: eight edge and corner tiles around a single empty cell.
  3. Draw the four inner corner patches onto the four corner tiles of the ring. Each of them touches the hole only diagonally and has ground on both sides next to it, so it is the one that has to close the outline.
  4. Check the ring at 1x. Then copy each patch into a fresh tile 15 to get the four single-corner tiles of the blob set.

You are done when the outline around the hole is unbroken at 1x and all four inner corners look the same apart from the direction of the light.

Takeaways

  • Four sides cannot see inner corners. Add the four diagonals with values 16, 32, 64 and 128.
  • A diagonal only counts when both sides next to it are ground; otherwise an edge already covers it.
  • That rule leaves 47 of the 256 masks, which is the blob tile set.
  • Draw one inner corner patch per corner and assemble the 47 tiles from parts.
  • Sort the masks that pass the rule and number them: that order is your sheet order.
