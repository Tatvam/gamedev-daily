Dithering patterns: two colours, many shades

How checker and ordered dither patterns fake in-between shades with only two colours, and how to choose the pattern and how far to spread it.

Your palette has room for two shades on a rock: a light one and a dark one. Where they meet there is a hard line, and the rock looks like two pieces glued together. You need a third shade, and there is no slot left for it. Dithering is how you get it.

Mixing colours in the eye

Dithering means placing two colours in a fine, alternating pattern so that, at real size, the eye blends them into a colour between the two. No new colour goes into the palette. The mix only exists in the viewer's eye.

The simplest pattern is the checker: every other pixel, like a chessboard. Half the pixels are light and half are dark, so from a distance it reads as a shade halfway between them. That gives you exactly one extra tone.

More tones from a threshold map

To get more than one in-between tone, you need patterns with a quarter dark pixels, three quarters, and so on, and they have to look even, not clumped. Ordered dithering does this with a small grid of numbers called a threshold map, often a Bayer matrix after the engineer who described it. Each number says how early that pixel turns dark.

For a tone of k dark pixels out of 16, every pixel whose number is below k turns dark. The map repeats every 4 pixels, so the same rule covers any area.

With a 4 by 4 map you get 15 in-between tones; a 2 by 2 map gives 3; the checker gives 1. Because the order is fixed, a smooth change in tone becomes a smooth change in pattern, and neighbouring pixels never clump into blobs.

How far to spread it

The spread is how wide the dithered zone is between the solid light and the solid dark. A narrow spread, two to four pixels, softens an edge between two bands. A wide spread turns the whole area into a gradient. On a lit ball the spread decides whether the shadow edge looks sharp, like a hard object in strong light, or soft, like a matte surface.

Choosing when to dither

These are conventions, not laws, but they are widely shared:

  • Dither between neighbours. Neighbouring ramp colours blend into a believable middle shade. Colours far apart in value read as a texture, like cloth or a grille.
  • Dither areas, not details. A pattern needs room to read as a tone, usually a zone at least three or four pixels across. On an 8 by 8 sprite each pixel is a feature, and a checker reads as noise.
  • Prefer order to noise. Random placement clumps and leaves gaps, so it reads as grain rather than a shade.

Rule of thumb

Dither only between two neighbouring shades of one ramp, over an area big enough to show the pattern, using a regular pattern. If you have a palette slot for the middle colour and the area is small, a real third colour is usually cleaner.

The code

This LÖVE program draws the demo's gradient strip with ordered dithering. Each pixel stores a palette index, 1 for light and 2 for dark, so the art still uses only two colours. Press Space to switch to the checker.

local W, H, ZOOM = 32, 8, 12
local EDGE, SPREAD = 16, 16   -- where the shade changes, and how wide the dither zone is
local PALETTE = { { 0.82, 0.45, 0.31 }, { 0.54, 0.23, 0.32 } }   -- 1 = light, 2 = dark
local BAYER = {
  {  0,  8,  2, 10 },
  { 12,  4, 14,  6 },
  {  3, 11,  1,  9 },
  { 15,  7, 13,  5 },
}

-- How dark a column should be: 0 = all light, 1 = all dark.
local function darkness(x)
  local d = x + 0.5 - EDGE
  if SPREAD == 0 then
    if d >= 0 then return 1 else return 0 end
  end
  return math.max(0, math.min(1, d / SPREAD + 0.5))
end

local function ordered(x, y, t)
  local m = BAYER[y % 4 + 1][x % 4 + 1]
  if t * 16 > m + 0.5 then return 2 else return 1 end
end

local function checker(x, y, t)
  if t <= 0 then return 1 elseif t >= 1 then return 2 end
  return (x + y) % 2 + 1
end

local pattern = ordered

function love.keypressed(key)
  if key == "space" then
    if pattern == ordered then pattern = checker else pattern = ordered end
  end
end

function love.draw()
  for y = 0, H - 1 do
    for x = 0, W - 1 do
      love.graphics.setColor(PALETTE[pattern(x, y, darkness(x))])
      love.graphics.rectangle("fill", x * ZOOM, y * ZOOM, ZOOM, ZOOM)
    end
  end
end

The highlighted lines are the whole of ordered dithering: look up the pixel's threshold, and turn it dark once the wanted darkness passes it. The + 1 is there because Lua tables start at 1.

Pitfalls

  • Dithering far-apart colours. A checker of near-black and near-white looks like a pattern, not grey. Dither between neighbouring ramp steps.
  • Dithering tiny sprites. On a 16 by 16 face, a checker reads as dirt. Save it for larger areas and backgrounds.
  • Noise from automatic conversion. Image editors often reduce colours with error diffusion, which scatters pixels unevenly and looks grainy. Turn it off, or clean up by hand.
  • Bad scaling. Fractional or smooth scaling turns a checker into grey mush or uneven stripes. Keep integer, nearest neighbour scaling.
  • Covering up banding. Dithering a banded edge gives a dithered stripe. Stagger the edges first, then dither if you still want a softer step.
  • Dithering in screen space. If a game adds dithering in a shader using screen coordinates, the pattern stays still while the object moves, so it seems to crawl across the surface. Pattern drawn into the sprite moves with it.

In real games

Dithering was a natural fit for hardware with few colours. The original Game Boy shows four shades, so checker and ordered patterns are a common way to suggest more. On consoles usually played through composite video, such as the Sega Mega Drive, artists are widely reported to have used fine stripes that the blurry signal blended into a mixed colour or a see-through effect. On a sharp modern display the stripes show plainly. This is a general account; I have not checked specific titles.

Some modern games are built on dithering. Return of the Obra Dinn by Lucas Pope renders a 3D world in two colours and relies on dithering for all its shading. Its development log discusses keeping the pattern stable as the camera moves, which is the screen-space problem from the pitfalls.

Takeaways

  • Dithering fakes an in-between shade by mixing two colours in a fine pattern that the eye blends at real size.
  • The checker gives one extra tone; ordered dithering with a 4 by 4 threshold map gives fifteen without clumping.
  • The spread sets how wide the dithered zone is: narrow softens an edge, wide makes a gradient.
  • It works best between neighbouring ramp colours, on areas big enough to show the pattern, with a regular pattern instead of noise.
  • Judge it at 1x and keep integer, nearest neighbour scaling, or the pattern breaks.
