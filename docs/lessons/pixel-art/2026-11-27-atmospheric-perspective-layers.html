Atmospheric perspective: fade far layers into the sky

How mixing each background layer towards the sky colour lowers its contrast and pushes it back, so the play area stands out in front.

You draw three rows of hills behind your level, all with the same green ramp you used for the ground. In a screenshot they merge into one flat wall of green, and a play tester tries to jump onto a hill that is only scenery.

The hills are drawn well. They are just as loud as the ground, so nothing tells the eye which is close.

Air sits between you and far things

On a clear day the nearest ridge of real hills has deep shadows and strong colour, the next is paler and bluer, and the last is a soft shape barely darker than the sky. This is atmospheric perspective, also called aerial perspective: things look less contrasted and more like the sky the further away they are.

Air, dust and water droplets scatter sunlight, so every bit of air between you and a hill adds some sky-coloured light. The further away the hill, the more is added and the less of the hill's own light gets through.

Distance changes three things at once:

  • Contrast drops. The darkest and lightest colours of a far layer are closer together.
  • Value moves towards the sky. On a bright day, far shadows get lighter. (Value is how light or dark a colour is.)
  • Colour moves towards the sky's hue. Far green turns blue-grey under a blue sky, and pinkish under a sunset.

One operation does all three: mix towards the haze

Pick a haze colour: usually the sky colour just above the horizon, the colour of a lot of air seen edge on. Then give each background layer a fade amount from 0 (untouched) to 1 (fully sky). Every colour in that layer's ramp is mixed towards the haze by that amount, separately for red, green and blue:

faded = colour + (haze - colour) * fade

Every colour is pulled towards the same point, so the gap between darkest and lightest shrinks to (1 - fade) of what it was. At the same time the whole ramp slides towards the sky's value and hue. In the demo below, the green hill ramp has a value range of 36 (on a scale of 0 to 100). Faded by 0.15, 0.40 and 0.65, the three layers keep ranges of 31, 22 and 13, while the play layer in front keeps 68.

Choosing the amounts

These are conventions, not laws, but they hold up in most side views:

  • The play layer gets no fade. It owns the darkest darks, the brightest lights and the outline colour. The player has to read it instantly, so it keeps the strongest contrast on screen.
  • Each step back fades more. A near layer usually needs only a little, around 0.1 to 0.2. The last layer can be faded so far that it is barely a shape against the sky.
  • Remove detail as you fade. On a far layer small clusters only add noise. Usually it is a silhouette with one lit edge.

Ignore the first rule and backgrounds compete with the level: the eye cannot tell a solid platform from a painted hill. Fade everything too far and the scene looks washed out, as if under fog; that can be the mood you want, but make it a choice.

Fade towards the sky, not towards white

The haze is whatever colour the air is. At night it is a dark blue, so far hills get darker, not lighter. In a smoky cave it might be near black. Mixing towards white under a blue sky makes layers look pasted on.

Each faded layer needs its own ramp, so three layers add nine colours. In a tight palette, share colours: the far layer's lightest step can simply be the haze colour.

The code

Hills are stored as ramp indexes; each layer gets its own faded ramp at load. The numbers match the demo's daytime sky. Written for LÖVE 11, where colours run from 0 to 1.

local W, H, SCALE = 96, 56, 4
local HAZE = { 0.722, 0.847, 0.925 }   -- sky colour at the horizon, #b8d8ec
local HILL_RAMP = {                    -- one ramp for every layer: dark, mid, light
  { 0.184, 0.353, 0.227 },
  { 0.310, 0.541, 0.290 },
  { 0.549, 0.753, 0.380 },
}
local LAYERS = {                       -- back to front
  { name = "far",  base = 24, amp = 5, fade = 0.65 },
  { name = "mid",  base = 32, amp = 5, fade = 0.40 },
  { name = "near", base = 40, amp = 4, fade = 0.15 },
}

local function mix(a, b, t)
  return a + (b - a) * t
end

local function fadeRamp(ramp, haze, fade)
  local out = {}
  for i, c in ipairs(ramp) do
    out[i] = { mix(c[1], haze[1], fade), mix(c[2], haze[2], fade), mix(c[3], haze[3], fade) }
  end
  return out
end

local function ridge(layer, x)   -- y of the hill top in column x
  return math.floor(layer.base - layer.amp * math.sin(x * 0.07 + layer.base)
                    - 2 * math.sin(x * 0.19 + layer.base * 2))
end

local function shadeIndex(layer, x, y)   -- 1 dark, 2 mid, 3 light
  if y - ridge(layer, x) < 2 then return 3 end   -- lit top edge
  if (math.floor(x / 2) * 7 + math.floor(y / 2) * 3 + layer.base) % 5 == 0 then return 1 end
  return 2
end

function love.load()
  love.graphics.setDefaultFilter("nearest", "nearest")
  for _, layer in ipairs(LAYERS) do
    local ramp = fadeRamp(HILL_RAMP, HAZE, layer.fade)
    local data = love.image.newImageData(W, H)   -- starts fully transparent
    for y = 0, H - 1 do
      for x = 0, W - 1 do
        if y >= ridge(layer, x) then
          local c = ramp[shadeIndex(layer, x, y)]
          data:setPixel(x, y, c[1], c[2], c[3], 1)
        end
      end
    end
    layer.image = love.graphics.newImage(data)
  end
end

function love.draw()
  love.graphics.clear(HAZE[1], HAZE[2], HAZE[3])   -- the sky
  love.graphics.scale(SCALE)
  love.graphics.setColor(1, 1, 1)
  for _, layer in ipairs(LAYERS) do   -- far first, near last
    love.graphics.draw(layer.image, 0, 0)
  end
  -- draw the play layer last, with its own unfaded palette
end

The sky here is just the haze colour; the demo adds a darker band at the top. Fading happens once at load, so it costs nothing while the game runs.

An alternative: after drawing each layer, draw a screen-sized rectangle of the haze colour with alpha a. It mixes everything behind it towards the haze by a, the same mix as above, and far layers collect the fade of every rectangle in front of them.

Pitfalls

  • Tinting by multiplying. love.graphics.setColor, Godot's modulate and Unity's SpriteRenderer.color multiply the sprite's colours. Multiplying can only darken, so it cannot fade towards a light sky. Use faded ramps, the overlay rectangle or a mixing shader.
  • Fading the play layer. Fade only what the player cannot touch.
  • The same fade on every layer. The hills then sit at one distance from each other. Fade more with each step back.
  • A haze that does not match the sky. Grey haze under a blue sky looks cut out. Sample the haze from the horizon.
  • Keeping the outline colour in the background. A black outline on a far hill pulls it forward again. If background layers have outlines, take them from the layer's own faded ramp.

In real games

Landscape painters have used atmospheric perspective for centuries, and it carries straight over to games with layered backgrounds. Pause a side-scroller with several background layers and you will usually find the furthest ones paler, lower in contrast and tinted towards the sky. Viewing a few screenshots in greyscale shows how far each game pushes it.

Because the sprite tints in Godot, Unity and LÖVE multiply, fading towards a light sky is usually done in the art, with an overlay or with a small shader.

Your turn (15 minutes)

  1. Draw one hill layer, 64 by 32 pixels, with a three-colour ramp: a lit top edge, a mid body and a few dark clusters.
  2. Duplicate it twice, shift the copies sideways and stack the three at different heights over a sky.
  3. Pick the haze colour from your sky near the horizon. Recolour the middle copy with a fade of about 0.4 and the back copy with about 0.65.
  4. Put your character on a ground strip in front.

You are done when, in greyscale at 1x, you can tell the three hill layers apart and the character is the highest-contrast thing on screen.

Takeaways

  • Distance lowers contrast and moves colours towards the sky's value and hue.
  • Mixing a layer's ramp towards the haze colour by a fade amount does all of that in one step, and shrinks the value range to 1 - fade of the original.
  • The play layer keeps full contrast; each layer further back fades more.
  • The haze is the sky colour at the horizon. At night that makes far layers darker, not lighter.
