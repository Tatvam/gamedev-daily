Circles and ellipses at tiny sizes

How to build small pixel circles from one eighth of runs mirrored eight ways, why some diameters come out rounder, and when to pick odd or even.

You need a coin, a bubble or an eye, so you drag out a circle tool on a 16 by 16 canvas. At real size the result looks like a rounded square, or it has a lump on one side, or it sits half a pixel off the centre of its tile. At this size, a circle is a set of choices.

A circle is one eighth, mirrored

A circle looks the same when you flip it left to right, top to bottom, or across either diagonal. Those four mirror lines cut it into eight equal slices, called octants. Draw one octant well and the other seven are copies: flip it across the diagonal to finish a quarter, then flip the quarter to finish the circle.

Inside one octant the outline is a line, so everything from the line lessons applies. Read it as runs, the groups of pixels in one row before the line steps down. Start at the top centre and move towards the 45 degree point. On a round circle the runs get shorter and shorter: a long flat top, then shorter steps, then single pixels at the diagonal. Past the diagonal the mirror copy plays the same runs backwards, so they grow again down to the flat side.

Where the runs come from

One common way to get a starting circle is to fill every pixel whose centre lies inside the true circle, then keep only the edge. Circle tools do something similar, each rounding a little differently. An octant drops only about 0.15 of the diameter from the top to the 45 degree point, one or two rows on a 10 pixel circle. The maths wants fractional runs, pixels come in whole numbers, and the rounding does not always land well.

Two things that spoil a small circle

A bump. A run that is longer than the run before it, reading from the top. With the method above, the 27 pixel circle comes out as runs 4, 3, 1, 2. The late 2 is a flat spot. The fix is the one from the curves lesson: sort the runs into 4, 3, 2, 1. The total length stays the same, so the ends still meet the mirror copies.

A double at the 45 degree point. If the last run is longer than one pixel and ends exactly on the diagonal, the mirror copy reuses its end pixel and the corner becomes an L of three pixels: a double. The 10 pixel circle, runs 2, 2, has this problem and looks squarish. Shorten the last run by one.

Rule of thumb

Reading from the top centre to the 45 degree point, the runs should never get longer, and the last one should not leave an L at the diagonal. If both hold, the circle usually reads as round at real size.

Odd or even?

An odd diameter, such as 7 or 15, has a single middle pixel. Pick odd when something must sit exactly in the middle: the pupil in an eye, the axle of a wheel. An even diameter, such as 8 or 16, has its middle on the corner where four pixels meet. Pick even when the circle must be centred in an even-sized space, like a coin in a 16 pixel tile; a 15 pixel circle there is always one pixel closer to one side.

Neither is rounder in general. The rounding of the runs decides that at each size, so trying one pixel bigger or smaller is normal.

Ellipses

An ellipse has only two mirror lines, so you draw a whole quarter instead of an eighth. The rule carries over: from the flat top, horizontal runs usually shrink steadily, then vertical runs grow down to the flat side. On a wide ellipse the top runs are simply longer.

Try it

The code

A game that draws circles on a low resolution grid, such as a radar ping or a blast ring, uses the same steps. eighthRuns reads the runs of one octant from the maths, tidyRuns sorts them and removes the double, and buildOutline mirrors them eight ways. Up and down change the size; T toggles tidying.

local SCALE = 12          -- each art pixel is 12 screen pixels wide
local diameter = 10
local tidy = false
local runs, outline

-- Runs of the top-right eighth, from the top centre down to the 45 degree point.
local function eighthRuns(d)
  local r = d / 2
  local off = (d % 2 == 0) and 0.5 or 0   -- even sizes: centre on a corner
  local h = math.ceil(d / 2)
  local result, prev = {}, -1
  for v = h - 1, 0, -1 do
    local m = -1                          -- last pixel in this row inside the circle
    for u = 0, h - 1 do
      if (u + off) * (u + off) + (v + off) * (v + off) <= r * r then m = u end
    end
    if m > v or m == prev then break end   -- past the diagonal
    result[#result + 1] = m - prev
    prev = m
  end
  return result
end

local function tidyRuns(d, raw)
  local out, rest = { raw[1] }, {}
  for i = 2, #raw do rest[#rest + 1] = raw[i] end
  table.sort(rest, function(a, b) return a > b end)   -- runs only shrink
  for i = 1, #rest do out[#out + 1] = rest[i] end
  local u = -1
  for i = 1, #out do u = u + out[i] end
  local v = math.ceil(d / 2) - #out
  if u == v and out[#out] > 1 then out[#out] = out[#out] - 1 end   -- no double at 45
  return out
end

local function buildOutline(d, eighth)
  local h = math.ceil(d / 2)
  local off = (d % 2 == 0) and 0.5 or 0
  local filled = {}
  local function plot(u, v)               -- copy one pixel into all four quarters
    for _, sx in ipairs({ -1, 1 }) do
      for _, sy in ipairs({ -1, 1 }) do
        filled[(d / 2 + sy * (v + off) - 0.5) * d + (d / 2 + sx * (u + off) - 0.5)] = true
      end
    end
  end
  local u = -1
  for i = 1, #eighth do
    local v = h - i
    for k = u + 1, u + eighth[i] do
      plot(k, v)                          -- the eighth itself
      plot(v, k)                          -- its mirror across the diagonal
    end
    u = u + eighth[i]
  end
  return filled
end

local function rebuild()
  runs = eighthRuns(diameter)
  if tidy then runs = tidyRuns(diameter, runs) end
  outline = buildOutline(diameter, runs)
end

function love.load()
  rebuild()
end

function love.keypressed(key)
  if key == "up" and diameter < 32 then diameter = diameter + 1 end
  if key == "down" and diameter > 3 then diameter = diameter - 1 end
  if key == "t" then tidy = not tidy end
  rebuild()
end

function love.draw()
  love.graphics.clear(0.91, 0.89, 0.83)
  love.graphics.setColor(0.16, 0.14, 0.22)
  for y = 0, diameter - 1 do
    for x = 0, diameter - 1 do
      if outline[y * diameter + x] then
        love.graphics.rectangle("fill", 20 + x * SCALE, 40 + y * SCALE, SCALE, SCALE)
        love.graphics.rectangle("fill", 440 + x, 40 + y, 1, 1)   -- real size
      end
    end
  end
  love.graphics.print(diameter .. " px, runs " .. table.concat(runs, ", "), 20, 12)
end

The keys in filled come out as whole numbers because the halves cancel. For shapes you draw often, build the outline once and keep it.

Pitfalls

  • Trusting the circle tool. Editors round differently, so a tool can leave a bump or a double. Read the runs of one eighth every time.
  • Shrinking a big circle. Scaling a large circle down gives uneven runs and, with smooth scaling, blurred colours. Build small circles at real size.
  • Tiny sizes are not really circles. At 3 pixels the choice is a plus or a square ring; at 4 or 5, a square with cut corners. Below about 6 pixels you choose what reads as round.
  • Wrong parity for the slot. Decide what the circle must line up with before you pick its size, or it ends up off by one.
  • Breaking symmetry by hand. One edited octant makes the circle look dented. Edit one eighth and mirror it again.

In real games

Coins, bubbles, wheels, eyes and bullets are small round shapes in countless sprites. At 8 or 16 pixels they are usually placed or cleaned by hand, because a few pixels decide whether they read as round.

The same eight-way symmetry is the basis of the midpoint circle algorithm, a classic way for a program to draw a circle on a pixel grid: it works out one octant step by step and mirrors each pixel into the other seven.

Your turn (15 minutes)

On a blank canvas, draw circles of 8, 9, 15 and 16 pixels without a circle tool. For each, write down the runs of one eighth first, draw that eighth, then mirror it. Check the rule: runs never get longer towards the diagonal, and no L at the 45 degree point.

Then draw an ellipse 16 pixels wide and 10 tall by drawing one quarter and mirroring it. You are done when all five shapes look round at real size, and you can say which of your circles would centre in a 16 pixel tile.

Takeaways

  • A pixel circle is one octant mirrored seven times; an ellipse is one quarter mirrored three times.
  • From the flat top to the 45 degree point the runs should only shrink. A longer run is a bump; sort the runs to fix it.
  • A run longer than one pixel that ends on the diagonal makes a double at 45 degrees. Shorten it by one.
  • Runs are whole numbers, so some diameters come out clean and others need tidying.
  • Odd diameters have a centre pixel, even diameters a centre corner. Choose by what the circle must line up with.
