Polar coordinates: how does the boss fire a ring of bullets?

How describing a point by a radius and an angle from a centre makes rings, spirals and outward-flying bullets a few lines of Lua.

Your boss should fire twelve bullets in a perfect ring. You could work out twelve x and y pairs by hand, but then the designer asks for sixteen, then for a spiral that winds twice, and the table of numbers has to be rewritten every time.

The fix is to stop asking "how far across and how far down" and ask "how far out and which way". That is what polar coordinates are.

Two ways to say where something is

This lesson and its demo use y pointing down, as on a screen and in LÖVE. Angles start at "right" and positive angles turn clockwise, just as in the last three lessons.

So far every point has been a pair (x, y), how far across and how far down. Those are Cartesian coordinates. Polar coordinates describe the same point with two different numbers, measured from a chosen centre:

  • the radius r: how far the point is from the centre;
  • the angle a: which way you face to look at it, measured from "right".

"Is it inside the room?" is a Cartesian question. "Spread these evenly around the boss" is a polar one.

From radius and angle to x and y

The unit circle lesson showed that (cos a, sin a) is an arrow of length 1 pointing at angle a. The scaling lesson showed that multiplying an arrow by r makes it r times as long without turning it. Put the two together:

x = r × cos a
y = r × sin a

Worked example: r = 2, a = 90°. cos 90° = 0 and sin 90° = 1, so the point is (2 × 0, 2 × 1) = (0, 2): two squares straight down, a quarter turn clockwise from right.

Most of the time the centre is not (0, 0) but a boss or a player. Add the centre (cx, cy) on afterwards: (cx + r cos a, cy + r sin a).

And back again

To go from (x, y) to polar, you already have both tools. The radius is the length of the vector, from Pythagoras, and the angle comes from atan2:

r = √(x² + y²)
a = atan2(y, x)

For the point (3, 4) in the diagram: r = √(9 + 16) = √25 = 5, and atan2(4, 3) is about 0.927 radians, or 53.1°. Feed 5 and 53.1° back into the first formula and you get (3, 4) again.

Patterns: let a loop count round the circle

Polar coordinates shine when you place many things. A ring of n bullets keeps the same radius for all of them and spaces the angles evenly. One full turn is 360°, so the angle between neighbours, the step, is 360° / n. Bullet number i, counting from 0, sits at angle i × step.

Worked example: a ring of 4 at radius 3. The step is 360° / 4 = 90°, so the angles are 0°, 90°, 180° and 270°, and the bullets land on (3, 0), (0, 3), (−3, 0) and (0, −3): right, down, left and up.

A spiral is a ring whose radius grows a little with every bullet: r = start radius + growth × i. Take 8 bullets, start radius 1, growth 0.5. Bullet 2 has r = 1 + 0.5 × 2 = 2 at angle 2 × 45° = 90°, so it is at (0, 2). Bullet 4 has r = 3 at 180°, so it is at (−3, 0). Each bullet sits a bit further out than the one before it, and the dots curl outwards.

Finally, a twist adds a few extra degrees to every step: step = 360° / n + twist. With 36 bullets and a twist of 10°, the step is 10° + 10° = 20°, so the 36 bullets go round 36 × 20° = 720°: a spiral that winds twice. A twist of 180° makes every bullet jump to the opposite side, and the pattern splits into two arms.

Rule of thumb

In polar coordinates, "fly straight away from the centre" means "make r bigger", and "orbit" means "change a". When a movement is about a centre, store the bullet as (r, a) and convert to (x, y) only when you draw it.

The code

Two conversions, one pattern function, and a boss firing the demo's "Spiral" preset every second. Bullets are stored as radius and angle, so flying outwards is one addition.

-- y grows downwards, as on LÖVE's screen, so a positive angle turns clockwise.
-- Angles are in radians.
local function fromPolar(radius, angle)
  return radius * math.cos(angle), radius * math.sin(angle)
end

local function toPolar(x, y)
  return math.sqrt(x * x + y * y), math.atan2(y, x)
end

-- count bullets, each one 'step' further round and 'growth' further out.
local function pattern(count, startRadius, startAngle, growth, twist)
  local step = 2 * math.pi / count + twist
  local result = {}
  for i = 0, count - 1 do                 -- 0 to count - 1, not 1 to count
    table.insert(result, {
      radius = startRadius + growth * i,
      angle = startAngle + step * i,
    })
  end
  return result
end

local UNIT = 40                           -- pixels per grid square
local boss = { x = 400, y = 300 }         -- the centre, in pixels
local SPEED = 3                           -- squares per second, outwards
local bullets = {}
local timer = 0

function love.update(dt)
  timer = timer - dt
  if timer <= 0 then                      -- a new spiral every second
    timer = timer + 1
    for _, b in ipairs(pattern(36, 1, 0, 0.15, math.rad(10))) do
      table.insert(bullets, b)
    end
  end
  for i = #bullets, 1, -1 do              -- backwards, so removing is safe
    local b = bullets[i]
    b.radius = b.radius + SPEED * dt        -- flying away is just a bigger radius
    if b.radius > 20 then
      table.remove(bullets, i)
    end
  end
end

function love.draw()
  for _, b in ipairs(bullets) do
    local x, y = fromPolar(b.radius, b.angle)
    love.graphics.circle("fill", boss.x + x * UNIT, boss.y + y * UNIT, 5)
  end
end

To check by hand: fromPolar(3, math.pi / 2) returns about 0 and 3, and toPolar(3, 4) returns 5 and about 0.927. pattern(4, 3, 0, 0, 0) gives angles 0, π/2, π and 3π/2: the ring of 4 from the worked example.

Built-in versions: Godot 4 has Vector2.from_angle(angle) for the length-1 arrow, so Vector2.from_angle(a) * r converts, and v.length() and v.angle() go back. In Unity, write it out with Mathf.Cos, Mathf.Sin and Mathf.Atan2.

Pitfalls

  • Dividing by count − 1. It feels right that the last bullet should land on 360°, but 360° is the same direction as 0°. With a step of 360° / (n − 1), the first and last bullets sit on top of each other, so you see only n − 1 bullets. Divide by n and count i from 0 to n − 1.
  • Count of 0. 2π / 0 is infinity in Lua. The loop then runs no times, so nothing breaks, but guard it if anything else uses the step.
  • Degrees instead of radians. A twist of 10 means 10 radians, more than one and a half turns. Write math.rad(10).
  • Expecting your angle back. atan2 always answers between −180° and 180°. A bullet placed at 270° comes back as −90°, and one at 450° comes back as 90°. These are the same directions, so the point is right, but do not compare angles with ==. The next lesson deals with this properly.
  • Radius 0. At the centre every angle gives the same point, so the angle means nothing. math.atan2(0, 0) returns 0 rather than an error, which can hide the problem: a bullet spawned exactly on the boss has no direction of its own.
  • Rings thin out. The gap between neighbours is about 2π r / n, so it grows as a ring flies out: twelve bullets have gaps of over 10 squares at radius 20. That is how a player squeezes through.

In real games

Shoot-'em-ups, especially the screen-filling "bullet hell" style, build many patterns from rings and spirals fired from a centre, often turning the start angle a little between volleys so the pattern rotates.

The same idea appears well beyond bullets: placing shields or pickups evenly around a player, laying out the slices of a radial weapon wheel, sending explosion particles out at random angles and speeds, and drawing a radar where an enemy's offset becomes a distance and a bearing. Each one is a radius, an angle, and the two lines of fromPolar.

Your turn (15 minutes)

Start from the code above and make the bullets curve. Give each bullet a turn speed and, in love.update, add b.angle = b.angle + math.rad(30) * dt next to the radius line. Then make the boss turn its start angle by 15° each volley, by keeping a volley counter and passing math.rad(15) * volley as the start angle.

You are done when each volley curls clockwise as it flies outwards and each new volley starts 15° further round. A negative turn speed reverses the curl.

Takeaways

  • Polar coordinates describe a point by a radius r and an angle a from a centre.
  • To convert: x = cx + r cos a, y = cy + r sin a. Back: r = √(x² + y²), a = atan2(y, x).
  • A ring of n is r fixed and a = i × 360° / n for i from 0 to n − 1. Grow r with i for a spiral, add a twist to wind it.
  • Moving out from a centre is "increase r", orbiting is "change a". Store (r, a) and convert when drawing.
  • atan2 answers between −180° and 180°, so an angle may come back looking different but pointing the same way.
