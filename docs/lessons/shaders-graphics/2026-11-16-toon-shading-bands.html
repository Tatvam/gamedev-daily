Toon shading: cutting light into bands

Multiply N·L by a band count, take floor, divide back: smooth light becomes a few flat cartoon tones. Add soft band edges and a hard specular spot.

Your characters are drawn with flat colours and bold shapes, but the 3D lighting shades them with a smooth gradient, and they look like plastic toys instead of drawings. Cartoon artists paint a shadow as one flat, darker tone with a clear edge. A shader can do the same with one line: snap the light to a few fixed levels.

From a smooth ramp to a staircase

A fragment shader is a small function that runs once per pixel and returns a colour. In the Lambert lesson that function computed diffuse = max(N·L, 0): 0 where the surface turns away from the light, 1 where it faces it, and every value in between. Toon shading keeps that number and changes only what we do with it.

Quantising means rounding a smooth value to one of a few fixed steps. Here is how to snap diffuse into bands flat steps of light:

x     = diffuse * bands          -- stretch 0..1 to 0..bands
band  = floor(x)                 -- which step this pixel is on: 0, 1, 2 ...
level = band / (bands - 1)       -- squeeze back so the steps run from 0 to 1

With 3 bands, every pixel with diffuse below 1/3 gets level 0, below 2/3 gets 0.5, and the rest get 1. Three tones, with hard edges at 1/3 and 2/3. Dividing by bands − 1 instead of bands makes the brightest band fully lit. A min(level, 1) catches the single value diffuse = 1, where floor would return bands itself.

Turning the level into a colour

A level of 0 should not be black. Cartoon shadows are a darker version of the base colour. So mix between a shadow brightness and full brightness:

colour = albedo * mix(shadow, 1.0, level)    -- shadow = 0.35 in the demo

Softening the edges

Hard steps alias: they crawl along a moving model as stair-stepped pixels. A small ramp at each band edge fixes that. fract(x) is the position of the pixel inside its band, from 0 to just under 1. Let the last part of each band fade up into the next one with smoothstep:

level = (band + smoothstep(1 - softness, 1, fract(x))) / (bands - 1)

softness is a fraction of one band. At 0.02 the edges look hard but are smooth enough not to shimmer. At 0.5 half of every band is a gradient, and the look drifts back towards normal shading. One catch: smoothstep(a, b, x) is undefined in GLSL when a ≥ b, so keep the softness above zero with max(softness, 0.001).

A hard specular spot

The Blinn-Phong highlight, spec = pow(max(N·H, 0), shininess), is also a smooth value. Threshold it in the same way and it becomes the bright, sharp-edged spot that cartoons put on eyes, hair and metal: spot = smoothstep(0.5 − w, 0.5 + w, spec). A smaller shininess makes a bigger spot. The spot is then mixed towards white, so it can never push the colour above 1.

Axes and colour space

The demo uses x right, y up and z out of the screen, with gl_FragCoord's (0, 0) at the bottom-left. The eye looks straight down −z, so V = (0, 0, 1). LÖVE's screen_coords start at the top-left with y down, so the LÖVE code flips y. Godot's NORMAL and VIEW are in view space; the Unity tab works in world space. The demo does its maths on the colour values as written, without gamma conversion. Engines convert colour pickers from sRGB to linear, so the band tones will look a little different there.

Try it

Step through the Stage menu first. Stage 3 is the surprise: fract(x) draws a little gradient inside every band, and the toon look simply throws that gradient away. Then set the stage to the final colour, drag the light (or focus the canvas and use the arrow keys) and change Bands from 2 to 8. Turn on Split to see smooth shading on the left half and toon on the right.

Finally, set Edge softness to 0 and look closely at a band edge, then raise it a little. Watch the graph: the steps get rounded corners.

The code

In LÖVE the shader is a string with the effect entry point, drawn over the whole window. The mouse moves the light. Press [ or ] to change the band count, - or = to change the softness, and s to toggle the specular spot.

local RADIUS = 0.38          -- sphere radius, as a fraction of the window height
local bands = 3
local softness = 0.05        -- fraction of a band that fades into the next
local shadow = 0.35          -- brightness of the darkest band
local shininess = 40
local spotOn = 1
local shader

local pixelcode = [[
uniform vec2 u_resolution;
uniform vec3 u_light;
uniform float u_bands;
uniform float u_softness;
uniform float u_shadow;
uniform float u_shininess;
uniform float u_spot;
const float RADIUS = 0.38;
const vec3 ALBEDO = vec3(0.95, 0.5, 0.2);
const vec3 V = vec3(0.0, 0.0, 1.0);

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
  vec2 p = (screen_coords - 0.5 * u_resolution) / u_resolution.y / RADIUS;
  p.y = -p.y;                                  // LÖVE's y grows downwards: make it grow up
  float aa = 1.5 / (u_resolution.y * RADIUS);
  float mask = 1.0 - smoothstep(1.0 - aa, 1.0, length(p));
  vec3 n = vec3(p, sqrt(max(1.0 - dot(p, p), 0.0)));
  float diffuse = max(dot(n, u_light), 0.0);

  float x = diffuse * u_bands;
  float band = floor(x);
  float inBand = fract(x);
  float w = max(u_softness, 0.001);
  float level = min((band + smoothstep(1.0 - w, 1.0, inBand)) / (u_bands - 1.0), 1.0);
  vec3 col = ALBEDO * mix(u_shadow, 1.0, level);

  vec3 h = normalize(u_light + V);
  float spec = pow(max(dot(n, h), 0.0), u_shininess);
  float spot = smoothstep(0.5 - 0.5 * w, 0.5 + 0.5 * w, spec) * step(0.001, diffuse);
  col = mix(col, vec3(1.0), u_spot * spot);

  vec3 bg = vec3(0.1, 0.11, 0.14);
  return vec4(mix(bg, col, mask), 1.0) * color;
}
]]

local function normalize(x, y, z)
  local len = math.sqrt(x * x + y * y + z * z)
  if len < 1e-6 then return 0, 0, 1 end
  return x / len, y / len, z / len
end

function love.load()
  shader = love.graphics.newShader(pixelcode)
end

function love.keypressed(key)
  if key == "]" then bands = math.min(bands + 1, 8) end
  if key == "[" then bands = math.max(bands - 1, 2) end
  if key == "=" then softness = math.min(softness + 0.05, 0.5) end
  if key == "-" then softness = math.max(softness - 0.05, 0) end
  if key == "s" then spotOn = 1 - spotOn end
end

function love.draw()
  local w, h = love.graphics.getDimensions()
  local mx, my = love.mouse.getPosition()
  local lightX = (mx - 0.5 * w) / h / RADIUS
  local lightY = -(my - 0.5 * h) / h / RADIUS  -- flip: screen y goes down
  local lx, ly, lz = normalize(lightX, lightY, 1.0)
  shader:send("u_light", { lx, ly, lz })
  shader:send("u_resolution", { love.graphics.getPixelDimensions() })
  shader:send("u_bands", bands)
  shader:send("u_softness", softness)
  shader:send("u_shadow", shadow)
  shader:send("u_shininess", shininess)
  shader:send("u_spot", spotOn)
  love.graphics.setShader(shader)
  love.graphics.rectangle("fill", 0, 0, w, h)
  love.graphics.setShader()
  love.graphics.print("bands " .. bands .. "  softness " .. softness, 10, 10)
end
precision mediump float;

uniform vec2 u_resolution;
uniform vec3 u_light;        // unit vector from the surface towards the light
uniform vec2 u_lightPos;     // where the sun marker is drawn, device pixels, origin bottom-left
uniform float u_bands;       // number of flat tones, 2 or more
uniform float u_softness;    // fraction of a band that fades into the next
uniform float u_shadow;      // brightness of the darkest band
uniform float u_shininess;   // Blinn-Phong exponent: smaller means a bigger spot
uniform float u_spot;        // 1 = draw the hard specular spot
uniform float u_split;       // 1 = smooth shading on the left half
uniform float u_stage;       // 0 normals ... 4 final colour

const float RADIUS = 0.38;                // sphere radius, as a fraction of the canvas height
const vec3 ALBEDO = vec3(0.95, 0.5, 0.2); // surface colour
const vec3 V = vec3(0.0, 0.0, 1.0);       // towards the eye

void main() {
  // the sphere, its normal and its Lambert diffuse, as in the earlier lessons
  vec2 p = (gl_FragCoord.xy - 0.5 * u_resolution) / u_resolution.y / RADIUS;
  float aa = 1.5 / (u_resolution.y * RADIUS);
  float mask = 1.0 - smoothstep(1.0 - aa, 1.0, length(p));
  vec3 n = vec3(p, sqrt(max(1.0 - dot(p, p), 0.0)));
  float diffuse = max(dot(n, u_light), 0.0);

  // 1. stretch, then split into band number and position inside the band
  float x = diffuse * u_bands;
  float band = floor(x);
  float inBand = fract(x);
  // 2. the band number, with a soft ramp at the top of each band, squeezed back to 0..1
  float w = max(u_softness, 0.001);
  float level = min((band + smoothstep(1.0 - w, 1.0, inBand)) / (u_bands - 1.0), 1.0);
  // 3. from shadow tone to full colour
  vec3 col = ALBEDO * mix(u_shadow, 1.0, level);
  // 4. a hard specular spot: Blinn-Phong, then a threshold
  vec3 h = normalize(u_light + V);
  float spec = pow(max(dot(n, h), 0.0), u_shininess);
  float spot = smoothstep(0.5 - 0.5 * w, 0.5 + 0.5 * w, spec) * step(0.001, diffuse);
  col = mix(col, vec3(1.0), u_spot * spot);

  // smooth shading, for the split view
  vec3 smoothCol = ALBEDO * mix(u_shadow, 1.0, diffuse);
  smoothCol = mix(smoothCol, vec3(1.0), u_spot * spec * step(0.001, diffuse));
  float left = u_split * step(p.x, 0.0);
  col = mix(col, smoothCol, left);

  if (u_stage < 3.5) col = vec3(mix(level, diffuse, left));
  if (u_stage < 2.5) col = vec3(inBand);
  if (u_stage < 1.5) col = vec3(diffuse);
  if (u_stage < 0.5) col = n * 0.5 + 0.5;

  vec3 bg = vec3(0.1, 0.11, 0.14);
  col = mix(bg, col, mask);
  float line = u_split * (1.0 - smoothstep(0.5 * aa, aa, abs(p.x)));
  col = mix(col, vec3(0.9), 0.8 * line);

  // the sun marker
  float lw = max(1.0, u_resolution.y / 300.0);
  float d = length(gl_FragCoord.xy - u_lightPos);
  vec3 sun = vec3(1.0, 0.82, 0.25);
  col = mix(col, vec3(0.0), 1.0 - smoothstep(lw, 2.0 * lw, abs(d - 8.5 * lw)));
  col = mix(col, sun, 1.0 - smoothstep(4.5 * lw, 5.5 * lw, d));
  gl_FragColor = vec4(col, 1.0);
}
// Godot 4, a ShaderMaterial on a MeshInstance3D (try a SphereMesh).
// Unshaded: the shader does all the lighting itself from one light direction.
shader_type spatial;
render_mode unshaded;

uniform vec3 albedo : source_color = vec3(0.95, 0.5, 0.2);
uniform vec3 light_dir = vec3(-0.5, 0.5, 0.7);  // world space, towards the light
uniform float bands : hint_range(2.0, 8.0, 1.0) = 3.0;
uniform float softness : hint_range(0.0, 0.5) = 0.05;
uniform float shadow : hint_range(0.0, 1.0) = 0.35;
uniform float shininess : hint_range(4.0, 128.0) = 40.0;

void fragment() {
    vec3 n = normalize(NORMAL);                                    // view space
    vec3 l = normalize((VIEW_MATRIX * vec4(light_dir, 0.0)).xyz);  // world to view space
    float diffuse = max(dot(n, l), 0.0);
    float x = diffuse * bands;
    float w = max(softness, 0.001);
    float level = min((floor(x) + smoothstep(1.0 - w, 1.0, fract(x))) / (bands - 1.0), 1.0);
    vec3 col = albedo * mix(shadow, 1.0, level);
    float spec = pow(max(dot(n, normalize(l + VIEW)), 0.0), shininess);
    float spot = smoothstep(0.5 - 0.5 * w, 0.5 + 0.5 * w, spec) * step(0.001, diffuse);
    ALBEDO = mix(col, vec3(1.0), spot);
}
// Built-in render pipeline, on any mesh with smooth normals. Uses the main directional light.
Shader "GameDevDaily/Toon"
{
    Properties
    {
        _Albedo ("Albedo", Color) = (0.95, 0.5, 0.2, 1)
        _Bands ("Bands", Range(2, 8)) = 3
        _Softness ("Edge softness", Range(0, 0.5)) = 0.05
        _Shadow ("Shadow brightness", Range(0, 1)) = 0.35
        _Shininess ("Shininess", Range(4, 128)) = 40
    }
    SubShader
    {
        Tags { "RenderType" = "Opaque" }
        Pass
        {
            Tags { "LightMode" = "ForwardBase" }
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            fixed4 _Albedo;
            float _Bands;
            float _Softness;
            float _Shadow;
            float _Shininess;

            struct v2f
            {
                float4 pos : SV_POSITION;
                float3 worldNormal : TEXCOORD0;
                float3 worldPos : TEXCOORD1;
            };

            v2f vert (appdata_base v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.worldNormal = UnityObjectToWorldNormal(v.normal);
                o.worldPos = mul(unity_ObjectToWorld, v.vertex).xyz;
                return o;
            }

            fixed4 frag (v2f i) : SV_Target
            {
                float3 n = normalize(i.worldNormal);
                float3 l = normalize(_WorldSpaceLightPos0.xyz);           // directional light
                float3 v = normalize(_WorldSpaceCameraPos - i.worldPos);
                float diffuse = max(dot(n, l), 0.0);
                float bands = round(_Bands);
                float x = diffuse * bands;
                float w = max(_Softness, 0.001);
                float level = min((floor(x) + smoothstep(1.0 - w, 1.0, frac(x))) / (bands - 1.0), 1.0);
                float3 col = _Albedo.rgb * lerp(_Shadow, 1.0, level);
                float spec = pow(max(dot(n, normalize(l + v)), 0.0), _Shininess);
                float spot = smoothstep(0.5 - 0.5 * w, 0.5 + 0.5 * w, spec) * step(0.001, diffuse);
                return fixed4(lerp(col, float3(1.0, 1.0, 1.0), spot), 1.0);
            }
            ENDCG
        }
    }
}

Only the highlighted lines are new; everything else is the Lambert and Blinn-Phong code from earlier lessons. HLSL spells fract as frac and mix as lerp. The Godot version is unshaded and takes its light direction from a uniform to stay short; to use the scene's real lights, move the banding into Godot's light() function. In URP Shader Graph the chain is Dot Product, Saturate, Multiply by bands, Floor, Divide by bands − 1, then Lerp from shadow colour to base colour. URP has no built-in main light direction node, so feed it from a Custom Function node or a material property.

Pitfalls

  • Bands of 1. bands − 1 is then 0 and the division blows up. Clamp the band count to 2 or more, as every tab does.
  • A fractional band count. 2.5 bands gives a last band that is only half wide. Round the value, as the Unity tab does with round(_Bands), or make the slider step in whole numbers.
  • Banding on low-poly meshes. Band edges follow the interpolated normals, so on a coarse mesh they zigzag along the triangles. Smooth normals, more vertices or a little softness hide it.
  • Quantising after the light colour and shadows. Banding diffuse × lightColour × shadowMap creates extra edges. Band the plain N·L, then multiply by the rest.
  • Zero softness under motion. A perfectly hard edge aliases. A small softness, such as 0.02 to 0.05, is hard to see when the model is still and removes most of the crawl.

What it costs

Over plain Lambert, toon shading adds a multiply, a floor, a fract, a smoothstep and a divide. That is nothing, even on a phone. The hard spot costs the same as Blinn-Phong plus one smoothstep. Many toon looks replace the maths with a tiny ramp texture: a strip of colours looked up with diffuse as the U coordinate. That costs one texture read and lets an artist paint the bands, including coloured shadows.

In real games

Quantised lighting is the core of cel-shaded games. The Legend of Zelda: The Wind Waker and Jet Set Radio are the classic examples, both known for flat-toned shadows. Godot's StandardMaterial3D has a Toon option for both its diffuse and specular modes, and ramp textures are common in stylised games because artists can tune the bands without touching code. This lesson shows one way to get the look; it does not claim to be how those particular games implement it.

Your turn (15 minutes)

Start from the LÖVE program.

  1. Give the shadow its own colour: add uniform vec3 u_shadowColor and replace the mix with mix(ALBEDO * u_shadowColor, ALBEDO, level). Try a cool purple, {0.35, 0.3, 0.6}.
  2. Move the edge of a two-band shader: add an offset so the terminator sits where you like, with diffuse = clamp(dot(n, u_light) + u_offset, 0.0, 1.0).
  3. Add a hard rim from the previous lesson: step(0.7, 1.0 - dot(n, V)), mixed towards white on the lit side only.

You are done when the ball has two purple-shadowed bands, a sharp white spot and a crisp rim line, and all three follow the mouse.

Takeaways

  • Toon shading is Lambert with one extra step: floor(diffuse × bands) / (bands − 1) snaps the light to a few flat tones.
  • fract(diffuse × bands) is the position inside a band. Feed it through smoothstep for soft band edges that do not alias.
  • Mix from a shadow tone to the full colour instead of to black.
  • Threshold the Blinn-Phong highlight with smoothstep to get a hard cartoon spot.
  • It costs a handful of instructions, and a ramp texture is an artist-friendly alternative.
