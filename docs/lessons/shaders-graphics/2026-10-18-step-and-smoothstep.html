Step and smoothstep: hard edges and soft edges

step turns a value into a hard 0 or 1 at an edge; smoothstep blends across a band instead. Together they draw every edge a shader makes.

A health bar has to stop at exactly 37 percent. A spotlight should fade out at its rim, not cut off. A circle drawn with a plain if has jagged stairs around it.

All three ask one number the same question: is it past the edge, and how gently does the answer change? GLSL has two built-in functions for this, and nearly every shape in later lessons uses them.

From a gradient to an edge

A fragment shader is a small function that runs once per pixel and returns a colour. So far ours have returned smooth gradients, such as the UV coordinate x running from 0.0 at the left to 1.0 at the right. To draw a shape we need a place where the colour changes.

The tool is a threshold: a value we compare against. The answer is a number from 0.0 to 1.0 called a mask, because it decides where a colour shows and where it is hidden.

step: a hard edge

step(edge, x) returns 0.0 when x is less than edge and 1.0 otherwise. The edge comes first, which surprises almost everyone: step(0.5, 0.3) is 0.0 and step(0.5, 0.7) is 1.0. Multiply a colour by this mask and the colour only appears on one side of the edge.

smoothstep: a soft edge

smoothstep(e0, e1, x) returns 0.0 below e0, 1.0 above e1, and a smooth curve in between. The gap between e0 and e1 is the softness: how wide the fade is. Inside the gap it computes:

float t = clamp((x - e0) / (e1 - e0), 0.0, 1.0);   // 0 to 1 across the gap
float result = t * t * (3.0 - 2.0 * t);

The first line alone is a straight ramp. The second bends it into an S shape whose slope is zero at both ends. A straight ramp meets the flat parts at a sharp corner, and the eye sees a faint line at each corner. The S curve joins them smoothly, so the fade looks soft all the way across.

Building it up, one line at a time

Here is the demo's picture as four lines of GLSL. The demo's Stage menu shows the result after each:

float x = uv.x;                          // 1. input: a gradient from 0 to 1
float m = step(0.5, x);                  // 2. mask: hard edge at 0.5
m = smoothstep(0.4, 0.6, x);             //    or a soft edge from 0.4 to 0.6
vec3 col = vec3(1.0, 0.55, 0.15) * m;    // 3. final: orange where the mask is 1

One float goes in per pixel and one float comes out. Nothing in it knows about the screen: x could be a distance from a point, a health value or a noise value, and the same line turns it into a shape. To fade the other way, write 1.0 - smoothstep(e0, e1, x).

Rule of thumb

Use step when the edge must be exact, such as a bar that fills to a value. Use smoothstep for shapes: about one pixel of softness for a crisp edge, more for a glow.

The code

The Lua version runs the same shape function in LÖVE, whose pixel shaders use the entry point effect instead of main. Left and right move the edge, up and down change the softness, 1 to 3 pick the function, F flips and S cycles the stage.

-- The demo's starting values.
local edge = 0.5
local soft = 0.2     -- never 0: smoothstep needs e0 < e1
local fn = 0         -- 0 step, 1 smoothstep, 2 straight ramp
local flip = 0
local stage = 2      -- 0 input, 1 mask, 2 final colour
local strip = { 20, 200, 600, 120 }   -- x, y, width, height in pixels
local shader

local pixelcode = [[
uniform float u_edge;
uniform float u_soft;
uniform float u_fn;
uniform float u_flip;
uniform float u_stage;
uniform vec4 u_rect;

float shape(float x)
{
    float e0 = u_edge - 0.5 * u_soft;
    float e1 = u_edge + 0.5 * u_soft;
    float m = step(u_edge, x);                                  // 0. hard edge
    if (u_fn > 0.5) m = smoothstep(e0, e1, x);                  // 1. soft edge
    if (u_fn > 1.5) m = clamp((x - e0) / (e1 - e0), 0.0, 1.0);  // 2. straight ramp
    if (u_flip > 0.5) m = 1.0 - m;                              // flip the mask
    return m;
}

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
    float x = (screen_coords.x - u_rect.x) / u_rect.z;   // 0 at the left of the strip
    float m = shape(x);
    vec3 col = vec3(1.0, 0.55, 0.15) * m;
    if (u_stage < 1.5) col = vec3(m);
    if (u_stage < 0.5) col = vec3(x);
    return vec4(col, 1.0);
}
]]

function love.load()
  shader = love.graphics.newShader(pixelcode)
end

function love.update(dt)
  if love.keyboard.isDown("right") then edge = edge + 0.5 * dt end
  if love.keyboard.isDown("left") then edge = edge - 0.5 * dt end
  if love.keyboard.isDown("up") then soft = soft + 0.3 * dt end
  if love.keyboard.isDown("down") then soft = soft - 0.3 * dt end
  edge = math.max(0, math.min(1, edge))
  soft = math.max(0.02, math.min(0.6, soft))
end

function love.keypressed(key)
  if key == "1" or key == "2" or key == "3" then fn = tonumber(key) - 1 end
  if key == "f" then flip = 1 - flip end
  if key == "s" then stage = (stage + 1) % 3 end
end

function love.draw()
  shader:send("u_edge", edge)
  shader:send("u_soft", soft)
  shader:send("u_fn", fn)
  shader:send("u_flip", flip)
  shader:send("u_stage", stage)
  shader:send("u_rect", strip)
  love.graphics.setShader(shader)
  love.graphics.rectangle("fill", strip[1], strip[2], strip[3], strip[4])
  love.graphics.setShader()
end
precision mediump float;

uniform vec2 u_resolution;
uniform float u_dpr;
uniform float u_edge;
uniform float u_soft;
uniform float u_fn;
uniform float u_flip;
uniform float u_stage;
uniform float u_probe;

// The lesson: turn any value x into a mask from 0.0 to 1.0.
float shape(float x) {
  float e0 = u_edge - 0.5 * u_soft;
  float e1 = u_edge + 0.5 * u_soft;
  float m = step(u_edge, x);                                  // 0. hard edge
  if (u_fn > 0.5) m = smoothstep(e0, e1, x);                  // 1. soft edge
  if (u_fn > 1.5) m = clamp((x - e0) / (e1 - e0), 0.0, 1.0);  // 2. straight ramp
  if (u_flip > 0.5) m = 1.0 - m;                              // flip the mask
  return m;
}

// Demo only: 1.0 inside the rectangle lo..hi, 0.0 outside.
float box(vec2 p, vec2 lo, vec2 hi) {
  vec2 s = step(lo, p) * step(p, hi);
  return s.x * s.y;
}

void main() {
  vec2 px = gl_FragCoord.xy;          // pixels, origin bottom-left
  vec2 res = u_resolution;
  float pad = 14.0 * u_dpr;
  float t = 1.5 * u_dpr;              // half the width of a line, in pixels
  float x0 = pad;
  float w = res.x - 2.0 * pad;
  float x = (px.x - x0) / w;          // 0.0 at the left, 1.0 at the right
  vec3 col = vec3(0.13, 0.14, 0.16);

  // The picture: the strip at the bottom, one stage at a time.
  float inStrip = box(px, vec2(x0, pad), vec2(x0 + w, 0.30 * res.y));
  float m = shape(x);
  vec3 pic = vec3(1.0, 0.55, 0.15) * m;   // 3. final colour
  if (u_stage < 1.5) pic = vec3(m);       // 2. the mask as grey
  if (u_stage < 0.5) pic = vec3(x);       // 1. the input as grey
  col = mix(col, pic, inStrip);

  // The graph: output m (up) against input x (across).
  float gy0 = 0.44 * res.y;
  float gy1 = res.y - 32.0 * u_dpr;
  float gh = gy1 - gy0;
  float inGraph = box(px, vec2(x0, gy0), vec2(x0 + w, gy1));
  col = mix(col, vec3(0.18, 0.19, 0.22), inGraph);

  float e0 = u_edge - 0.5 * u_soft;
  float e1 = u_edge + 0.5 * u_soft;
  float zone = step(e0, x) * step(x, e1) * step(0.5, u_fn);
  col = mix(col, vec3(0.25, 0.28, 0.35), zone * inGraph);

  float guide = step(abs(px.y - gy0), 0.6 * u_dpr) + step(abs(px.y - gy1), 0.6 * u_dpr)
              + step(abs(px.y - gy0 - 0.5 * gh), 0.5 * u_dpr) * 0.5;
  col = mix(col, vec3(0.45, 0.47, 0.52), clamp(guide, 0.0, 1.0) * inGraph);

  float dash = step(0.5, fract(px.y / (8.0 * u_dpr)));
  float edgeLine = step(abs(px.x - (x0 + u_edge * w)), 0.75 * u_dpr);
  col = mix(col, vec3(0.70, 0.72, 0.76), edgeLine * dash * inGraph);

  float probeX = x0 + u_probe * w;
  float probeLine = step(abs(px.x - probeX), 0.75 * u_dpr) * (inGraph + inStrip);
  col = mix(col, vec3(0.35, 0.75, 1.0), 0.85 * probeLine);

  // The curve: in each column, fill from the lowest to the highest value nearby.
  float fa = shape((px.x - t - x0) / w);
  float fb = shape((px.x + t - x0) / w);
  float lo = gy0 + min(fa, fb) * gh - t;
  float hi = gy0 + max(fa, fb) * gh + t;
  float onCurve = step(lo, px.y) * step(px.y, hi) * box(px, vec2(x0, gy0 - t), vec2(x0 + w, gy1 + t));
  col = mix(col, vec3(0.98, 0.72, 0.28), onCurve);

  // The probe: what goes in (x) and what comes out (m).
  float d = length(px - vec2(probeX, gy0 + shape(u_probe) * gh));
  col = mix(col, vec3(0.35, 0.75, 1.0), step(d, 5.0 * u_dpr));
  col = mix(col, vec3(1.0), step(d, 2.0 * u_dpr));

  gl_FragColor = vec4(col, 1.0);
}

shader_type canvas_item;

uniform float u_edge : hint_range(0.0, 1.0) = 0.5;
uniform float u_soft : hint_range(0.02, 0.6) = 0.2;
uniform float u_fn = 0.0;      // 0 step, 1 smoothstep, 2 straight ramp
uniform float u_flip = 0.0;
uniform float u_stage = 2.0;

float shape(float x) {
    float e0 = u_edge - 0.5 * u_soft;
    float e1 = u_edge + 0.5 * u_soft;
    float m = step(u_edge, x);
    if (u_fn > 0.5) m = smoothstep(e0, e1, x);
    if (u_fn > 1.5) m = clamp((x - e0) / (e1 - e0), 0.0, 1.0);
    if (u_flip > 0.5) m = 1.0 - m;
    return m;
}

void fragment() {
    float x = UV.x;   // 0 at the left edge of the ColorRect
    float m = shape(x);
    vec3 col = vec3(1.0, 0.55, 0.15) * m;
    if (u_stage < 1.5) col = vec3(m);
    if (u_stage < 0.5) col = vec3(x);
    COLOR = vec4(col, 1.0);
}
// Built-in render pipeline, unlit. Put it on a material and apply it to a Quad.
Shader "GameDevDaily/StepSmoothstep"
{
    Properties
    {
        _Edge ("Edge", Range(0, 1)) = 0.5
        _Soft ("Softness", Range(0.02, 0.6)) = 0.2
        _Fn ("Function (0 step, 1 smooth, 2 ramp)", Float) = 0
        _Flip ("Flip (0 or 1)", Float) = 0
        _Stage ("Stage (0, 1 or 2)", Float) = 2
    }
    SubShader
    {
        Tags { "RenderType" = "Opaque" }
        Pass
        {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            float _Edge, _Soft, _Fn, _Flip, _Stage;

            struct v2f
            {
                float4 pos : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            v2f vert (appdata_base v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = v.texcoord.xy;
                return o;
            }

            float shape (float x)
            {
                float e0 = _Edge - 0.5 * _Soft;
                float e1 = _Edge + 0.5 * _Soft;
                float m = step(_Edge, x);
                if (_Fn > 0.5) m = smoothstep(e0, e1, x);
                if (_Fn > 1.5) m = saturate((x - e0) / (e1 - e0));
                if (_Flip > 0.5) m = 1.0 - m;
                return m;
            }

            fixed4 frag (v2f i) : SV_Target
            {
                float x = i.uv.x;
                float m = shape(x);
                float3 col = float3(1.0, 0.55, 0.15) * m;
                if (_Stage < 1.5) col = float3(m, m, m);
                if (_Stage < 0.5) col = float3(x, x, x);
                return fixed4(col, 1.0);
            }
            ENDCG
        }
    }
}

HLSL's step and smoothstep take arguments in the same order as GLSL; saturate(v) means clamp(v, 0.0, 1.0). In URP, Shader Graph has Step and Smoothstep nodes that do the same.

This lesson uses only the horizontal coordinate, where everyone agrees that 0 is on the left. Vertical differs: gl_FragCoord in WebGL starts at the bottom-left, Godot's canvas_item UV.y is 0 at the top, a Unity Quad's uv.y is 0 at the bottom, and LÖVE's screen_coords count from the top-left.

Pitfalls

  • Arguments in the wrong order. step(x, 0.5) compiles and returns the opposite mask. If a shape appears inside out, check this first.
  • Swapping smoothstep's edges to reverse it. The GLSL ES specification says the result is undefined when e0 >= e1. Many GPUs return the mirrored curve, so it works on your machine and fails on another. Use 1.0 - smoothstep(e0, e1, x), and never let the softness reach zero; the demo's slider stops at 0.02.
  • Softness that depends on the screen. A softness of 0.01 in UV units is about 3 pixels on a 360 pixel phone and 19 on a 1920 pixel monitor; the Soft zone readout shows your screen. For about one pixel, use 1.0 / u_resolution.x. Godot and Unity can also use fwidth(x), how much x changes between neighbouring pixels; WebGL 1 needs the OES_standard_derivatives extension for it.
  • Expecting anti-aliasing to fix a hard step. Multisample anti-aliasing (MSAA) smooths triangle edges but normally runs the fragment shader once per pixel, so a step edge inside a triangle stays jagged. A narrow smoothstep is how a shader smooths its own edges.

What it costs

Both are cheap, even on a phone. step is a compare and select, often one instruction. smoothstep is a subtract, a divide, a clamp and a few multiplies; with constant edges the compiler can precompute 1.0 / (e1 - e0) and drop the divide. A later lesson on branching compares them with if.

In real games

Distance field text is the best-known use. Each texel of the font texture stores how far it is from a letter's edge, and the shader thresholds that distance at the halfway value. Chris Green's 2007 Valve paper on the technique, used in Team Fortress 2, describes the threshold and softening the edge around it so letters stay smooth at any size. Unity's TextMesh Pro also renders text from distance fields.

Alpha cutout, which draws leaves or a fence as solid or empty depending on whether alpha passes a cutoff, is the same threshold applied to a texture's alpha. Unity's Shader Graph has Step and Smoothstep nodes, and Godot's visual shader editor has a SmoothStep node.

Your turn (15 minutes)

Turn the LÖVE example into a health bar:

  1. Add a u_health uniform (0.0 to 1.0), sent from Lua and changed by the up and down keys.
  2. Colour the filled part by multiplying with a mask: vec3(0.2, 0.9, 0.3) * (1.0 - step(u_health, x)). Pixels left of the health value are green and the rest are black.
  3. Add a white band that marks the end of the fill: subtract two smoothsteps, smoothstep(u_health - 0.02, u_health, x) - smoothstep(u_health, u_health + 0.02, x), and add it to the colour.

You are done when the fill stops exactly at the health value and the white marker follows it with soft edges.

Takeaways

  • A shader draws an edge by turning a value into a mask from 0.0 to 1.0.
  • step(edge, x) gives a hard edge; the edge comes first.
  • smoothstep(e0, e1, x) fades from e0 to e1 with no visible corners. Keep e0 below e1; reverse with 1.0 - smoothstep.
  • Softness is in the units of x; tie it to the resolution for a fixed pixel width.
  • Both are cheap, even on phones.
