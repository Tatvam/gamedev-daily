Noise in a fragment shader: value noise and gradient noise

Hash the four corners of a pixel's cell and blend them with an eased weight: smooth value noise. Hash a direction instead: gradient noise.

Yesterday's hash gave every cell its own random grey, which is fine for tiles and stars. Clouds, terrain heights and the wobble of a flame need randomness that changes gradually: a point should be close in value to its neighbours. Blocky white noise cannot do that, but blending the hashes of nearby cells can.

Blend the corners, do not paint the cell

A fragment shader is a small function that runs once per pixel: a position goes in, a colour comes out. Noise is one more function in that chain: a position goes in, and a number from 0 to 1 comes out that looks random at large scales but changes smoothly at small ones. Both kinds here start from a grid of cells, the lattice.

Step 1: which cell, and where inside it

vec2 p = gl_FragCoord.xy / u_resolution.y * u_scale;   // u_scale cells tall
vec2 i = floor(p);    // the cell's bottom-left corner: (0, 0), (1, 0) ...
vec2 f = fract(p);    // where the pixel sits in that cell, 0 to 1

Dividing by the height, not the width, keeps the cells square at any aspect ratio.

Step 2: a random value on every corner

Hash the corner instead of the cell. The four corners of cell i are i, i + (1, 0), i + (0, 1) and i + (1, 1). Neighbouring cells share corners, so they share values along their common edge. That sharing is what makes the result continuous.

Step 3: blend the four values

Blend the bottom pair across by f.x, the top pair the same way, then blend those two results up by f.y. This is bilinear interpolation, the same maths as linear texture filtering.

Step 4: ease the weights

With f as the weight, the result is continuous but its slope jumps at every cell edge, and the eye picks out the grid as a pattern of diamonds and creases. Pass f through a fade curve first. The classic one is 3f² − 2f³, the same curve as smoothstep(0.0, 1.0, f). Its slope is zero at 0 and 1, so the creases vanish. Ken Perlin's 2002 "improved noise" uses 6f⁵ − 15f⁴ + 10f³, whose curvature is also continuous, which matters when lighting uses the noise.

vec2 u = f * f * (3.0 - 2.0 * f);
float n = mix(mix(a, b, u.x), mix(c, d, u.x), u.y);

This is value noise: random values at the corners, smoothly blended between them.

Gradient noise: store a slope, not a height

Value noise puts its hills and valleys on the corners, so it still looks a little blocky. Gradient noise, the family that includes Perlin noise, hashes a random direction g for each corner instead.

Each corner contributes dot(g, p − corner): zero at the corner itself, rising in the direction of g and falling behind it. Then the same eased bilinear blend combines the four.

vec2 gradient(vec2 c) {
  float a = 6.2831853 * hash(c);      // a random angle
  return vec2(cos(a), sin(a));        // a unit direction
}
float a = dot(gradient(i), f);        // and likewise for the other three corners
float b = dot(gradient(i + vec2(1.0, 0.0)), f - vec2(1.0, 0.0));

The result lies between about −0.7 and 0.7, so the demo maps it with n * 0.5 + 0.5. Bumps now fall between the corners.

Which corner is (0, 0), and which colours

WebGL's gl_FragCoord starts at the bottom-left with y up. LÖVE's screen_coords and Godot's canvas UV start at the top-left with y down, so the code below flips y to match the demo. Unity's mesh UVs start at the bottom-left. The island colours are written as display (sRGB) values; in a project using linear colour space, such as Unity's Linear setting, they come out lighter.

Try it

Start on stage 2 with Value noise: each cell is painted with its bottom-left corner's hash. Step to stage 4 to see the corners blended. Now set Fade to linear and look for the creases along the grid lines, then switch back. Then change Noise type to gradient: stage 2 now shows each corner's direction as colour.

The code

In LÖVE the shader is a string with the effect entry point, drawn over the whole window. Tab switches the noise type; the up and down arrows change the scale. The scroll is wrapped on the CPU, and the hash wraps its corners every 64 cells, so the wrap is seamless.

local scale = 6          -- cells across the height of the window
local speed = 0.5        -- scroll speed in cells per second
local offset = 0         -- scroll so far, in cells
local noiseType = 0      -- 0 value noise, 1 gradient noise
local PERIOD = 64        -- the noise repeats every 64 cells, as in the shader
local shader

local pixelcode = [[
uniform vec2 u_resolution;
uniform float u_scale;
uniform float u_offset;
uniform float u_type;
const float PERIOD = 64.0;

float hash(vec2 c)
{
  c = mod(c, PERIOD);    // corners repeat, so the scroll can wrap
  return fract(sin(dot(c, vec2(12.9898, 78.233))) * 43758.5453);
}

vec2 gradient(vec2 c)
{
  float a = 6.2831853 * hash(c);
  return vec2(cos(a), sin(a));
}

float valueNoise(vec2 i, vec2 u)
{
  float a = hash(i);
  float b = hash(i + vec2(1.0, 0.0));
  float c = hash(i + vec2(0.0, 1.0));
  float d = hash(i + vec2(1.0, 1.0));
  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
}

float gradientNoise(vec2 i, vec2 f, vec2 u)
{
  float a = dot(gradient(i), f);
  float b = dot(gradient(i + vec2(1.0, 0.0)), f - vec2(1.0, 0.0));
  float c = dot(gradient(i + vec2(0.0, 1.0)), f - vec2(0.0, 1.0));
  float d = dot(gradient(i + vec2(1.0, 1.0)), f - vec2(1.0, 1.0));
  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y) * 0.5 + 0.5;
}

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
  // LÖVE's origin is the top-left: flip y so cell (0, 0) is bottom-left, as in the demo
  vec2 pos = vec2(screen_coords.x, u_resolution.y - screen_coords.y);
  vec2 p = pos / u_resolution.y * u_scale + vec2(u_offset, 0.0);
  vec2 i = floor(p);
  vec2 f = fract(p);
  vec2 u = f * f * (3.0 - 2.0 * f);
  float n = valueNoise(i, u);
  if (u_type > 0.5) n = gradientNoise(i, f, u);

  vec3 col = vec3(0.10, 0.22, 0.45);                                  // deep water
  col = mix(col, vec3(0.20, 0.45, 0.70), smoothstep(0.40, 0.44, n));  // shallows
  col = mix(col, vec3(0.86, 0.80, 0.56), smoothstep(0.53, 0.55, n));  // sand
  col = mix(col, vec3(0.32, 0.58, 0.26), smoothstep(0.56, 0.59, n));  // grass
  col = mix(col, vec3(0.20, 0.38, 0.18), smoothstep(0.66, 0.70, n));  // forest
  return vec4(col, 1.0) * color;
}
]]

function love.load()
  shader = love.graphics.newShader(pixelcode)
end

function love.keypressed(key)
  if key == "tab" then noiseType = 1 - noiseType end
  if key == "up" then scale = math.min(scale + 1, 32) end
  if key == "down" then scale = math.max(scale - 1, 2) end
end

function love.update(dt)
  offset = (offset + speed * dt) % PERIOD   -- keeps the shader's inputs small
end

function love.draw()
  local w, h = love.graphics.getDimensions()
  local pw, ph = love.graphics.getPixelDimensions()
  shader:send("u_resolution", { pw, ph })
  shader:send("u_scale", scale)
  shader:send("u_offset", offset)
  shader:send("u_type", noiseType)
  love.graphics.setShader(shader)
  love.graphics.rectangle("fill", 0, 0, w, h)
  love.graphics.setShader()
end
#ifdef GL_FRAGMENT_PRECISION_HIGH
precision highp float;   // the hash needs 32-bit floats
#else
precision mediump float;
#endif

uniform vec2 u_resolution;
uniform float u_scale;    // cells across the height of the canvas
uniform float u_offset;   // scroll in cells, wrapped to 0..64 on the CPU
uniform float u_type;     // 0 value noise, 1 gradient noise
uniform float u_fade;     // 0 linear, 1 cubic (smoothstep), 2 quintic
uniform float u_stage;    // 0 cell position ... 4 final colour
uniform float u_grid;     // 1 draws the cell borders

const float PERIOD = 64.0;   // corners repeat every 64 cells, so the scroll can wrap

float hash(vec2 c) {
  c = mod(c, PERIOD);
  return fract(sin(dot(c, vec2(12.9898, 78.233))) * 43758.5453);
}

vec2 gradient(vec2 c) {
  float a = 6.2831853 * hash(c);
  return vec2(cos(a), sin(a));
}

vec2 fade(vec2 f) {
  if (u_fade < 0.5) return f;
  if (u_fade < 1.5) return f * f * (3.0 - 2.0 * f);
  return f * f * f * (f * (f * 6.0 - 15.0) + 10.0);
}

float valueNoise(vec2 i, vec2 u) {
  float a = hash(i);
  float b = hash(i + vec2(1.0, 0.0));
  float c = hash(i + vec2(0.0, 1.0));
  float d = hash(i + vec2(1.0, 1.0));
  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
}

float gradientNoise(vec2 i, vec2 f, vec2 u) {
  float a = dot(gradient(i), f);
  float b = dot(gradient(i + vec2(1.0, 0.0)), f - vec2(1.0, 0.0));
  float c = dot(gradient(i + vec2(0.0, 1.0)), f - vec2(0.0, 1.0));
  float d = dot(gradient(i + vec2(1.0, 1.0)), f - vec2(1.0, 1.0));
  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y) * 0.5 + 0.5;
}

void main() {
  vec2 p = gl_FragCoord.xy / u_resolution.y * u_scale;   // square cells, u_scale tall
  p.x += u_offset;
  vec2 i = floor(p);                                     // 1. which cell
  vec2 f = fract(p);                                     //    where inside it
  vec2 u = fade(f);                                      // 3. eased weights
  float n = valueNoise(i, u);                            // 4. the noise
  if (u_type > 0.5) n = gradientNoise(i, f, u);

  // 5. use it: colour height bands as an island map
  vec3 col = vec3(0.10, 0.22, 0.45);                                  // deep water
  col = mix(col, vec3(0.20, 0.45, 0.70), smoothstep(0.40, 0.44, n));  // shallows
  col = mix(col, vec3(0.86, 0.80, 0.56), smoothstep(0.53, 0.55, n));  // sand
  col = mix(col, vec3(0.32, 0.58, 0.26), smoothstep(0.56, 0.59, n));  // grass
  col = mix(col, vec3(0.20, 0.38, 0.18), smoothstep(0.66, 0.70, n));  // forest

  if (u_stage < 3.5) col = vec3(n);
  if (u_stage < 2.5) col = vec3(u, 0.0);
  if (u_stage < 1.5) {
    // 2. what the corner holds: a grey value, or a direction shown as colour
    col = vec3(hash(i));
    if (u_type > 0.5) col = vec3(gradient(i) * 0.5 + 0.5, 0.5);
  }
  if (u_stage < 0.5) col = vec3(f, 0.0);

  float cellPx = u_resolution.y / u_scale;
  vec2 e = min(f, 1.0 - f) * cellPx;                     // pixels to the nearest border
  float line = 1.0 - step(1.5, min(e.x, e.y));
  col = mix(col, vec3(1.0), line * u_grid * 0.6);
  gl_FragColor = vec4(col, 1.0);
}

shader_type canvas_item;

uniform vec2 rect_size = vec2(640.0, 360.0);  // set this to the ColorRect's size
uniform float scale = 6.0;                    // cells across the height
uniform float speed = 0.5;                    // cells per second
uniform bool use_gradient = false;

const float PERIOD = 64.0;

float hash(vec2 c) {
    c = mod(c, PERIOD);
    return fract(sin(dot(c, vec2(12.9898, 78.233))) * 43758.5453);
}

vec2 gradient(vec2 c) {
    float a = 6.2831853 * hash(c);
    return vec2(cos(a), sin(a));
}

void fragment() {
    // UV starts at the top-left with y down: flip y to match the demo.
    vec2 pos = vec2(UV.x, 1.0 - UV.y) * rect_size;
    vec2 p = pos / rect_size.y * scale;
    p.x += mod(TIME * speed, PERIOD);
    vec2 i = floor(p);
    vec2 f = fract(p);
    vec2 u = f * f * (3.0 - 2.0 * f);
    float n;
    if (use_gradient) {
        float a = dot(gradient(i), f);
        float b = dot(gradient(i + vec2(1.0, 0.0)), f - vec2(1.0, 0.0));
        float c = dot(gradient(i + vec2(0.0, 1.0)), f - vec2(0.0, 1.0));
        float d = dot(gradient(i + vec2(1.0, 1.0)), f - vec2(1.0, 1.0));
        n = mix(mix(a, b, u.x), mix(c, d, u.x), u.y) * 0.5 + 0.5;
    } else {
        float a = hash(i);
        float b = hash(i + vec2(1.0, 0.0));
        float c = hash(i + vec2(0.0, 1.0));
        float d = hash(i + vec2(1.0, 1.0));
        n = mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
    }
    COLOR = vec4(vec3(n), 1.0);
}
// Built-in render pipeline, unlit, value noise. Put it on a Quad.
Shader "GameDevDaily/ValueNoise"
{
    Properties
    {
        _Cells ("Cells across (x) and down (y)", Vector) = (10, 6, 0, 0)
        _Speed ("Scroll speed (cells per second)", Float) = 0.5
    }
    SubShader
    {
        Tags { "RenderType" = "Opaque" }
        Pass
        {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            float4 _Cells;
            float _Speed;

            struct v2f
            {
                float4 pos : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            v2f vert (appdata_base v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = v.texcoord.xy;
                return o;
            }

            float hash (float2 c)
            {
                c = c - 64.0 * floor(c / 64.0);   // GLSL's mod; HLSL's fmod differs for negatives
                return frac(sin(dot(c, float2(12.9898, 78.233))) * 43758.5453);
            }

            fixed4 frag (v2f i) : SV_Target
            {
                // Unity UVs start at the bottom-left, like gl_FragCoord in the demo.
                float2 p = i.uv * _Cells.xy;
                p.x += frac(_Time.y * _Speed / 64.0) * 64.0;
                float2 c = floor(p);
                float2 f = frac(p);
                float2 u = f * f * (3.0 - 2.0 * f);
                float n = lerp(lerp(hash(c), hash(c + float2(1, 0)), u.x),
                               lerp(hash(c + float2(0, 1)), hash(c + float2(1, 1)), u.x), u.y);
                return fixed4(n, n, n, 1.0);
            }
            ENDCG
        }
    }
}

HLSL spells mix as lerp and fract as frac. In URP you do not need to write this at all: Shader Graph's Simple Noise node is a value noise and its Gradient Noise node is a gradient noise. Godot also ships CPU-side noise as the FastNoiseLite resource, which a NoiseTexture2D can bake into a texture.

Pitfalls

  • Feeding it raw time or world positions. The hash lives on the last digits of a 32-bit float. u_time * speed after an hour, or a world position of 20 000, turns the noise blocky. Keep the inputs small: wrap the scroll, and wrap the lattice with mod so the wrap is invisible.
  • Linear weights. Without a fade curve you get creases along every grid line.
  • Expecting gradient noise to fill 0 to 1. It stays near the middle and is exactly 0.5 on every corner. Thresholds tuned for value noise give smaller islands. Rescale it, or tune for it.
  • Visible grid at low scale. One layer of either shows its square lattice. Layering several scales, coming in later lessons, hides it.
  • mediump on phones. The sine hash falls apart at 16-bit precision. Request highp, as the demo does, or use a texture.

What it costs, and when a texture wins

Value noise is four hashes and three mixes per pixel. Gradient noise adds a sin and cos per corner and four dot products. One layer of either is cheap, even on a phone. Five layers over the full screen is not; there, one read from a small tiling noise texture is often cheaper, at the price of memory and visible repetition. Compute noise when it must animate or be unbounded; bake it when it is fixed and the target is weak. Measure on the real device.

In real games

Ken Perlin created gradient noise after working on the film Tron (1982) and received a Technical Achievement Academy Award for it in 1997. Scrolling noise distorts water and heat haze, thresholded noise drives dissolves, and layered noise generates terrain heights. Unity's Shader Graph has the two noise nodes named above and Mathf.PerlinNoise on the CPU, and Godot has FastNoiseLite.

Your turn (15 minutes)

Turn the LÖVE program into drifting clouds.

  1. Replace the island colours with mix(vec3(0.35, 0.6, 0.9), vec3(1.0), smoothstep(0.5, 0.75, n)).
  2. Add a second noise at twice the scale: float n2 = valueNoise(floor(p * 2.0), ...) with its own f and u, and use n = 0.65 * n + 0.35 * n2.
  3. Scroll the second layer slower than the first by giving it its own offset in love.update.

You are done when the clouds have soft edges with smaller lumps on them, and the two layers drift at different speeds without a jump when the offsets wrap.

Takeaways

  • Noise is a function from a position to a smooth random-looking value, rebuilt in every pixel from the hash of nearby lattice corners.
  • Value noise: hash a value on each corner and blend the four with mix.
  • Ease the weights with 3f² − 2f³ (or the quintic) or the grid shows as creases.
  • Gradient noise: hash a direction on each corner and blend dot(g, p − corner). It is zero on the corners and looks less blocky.
  • Keep inputs small and use highp; wrap the lattice with mod so wrapped time does not jump.
