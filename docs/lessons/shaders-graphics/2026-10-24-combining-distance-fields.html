Combining distance fields: union, subtraction and smooth blends

min joins two distance fields, max keeps their overlap, max(a, -b) cuts one out of the other, and a smooth minimum melts them together.

A button with a notch cut out for a badge. Two blobs of slime that stretch towards each other and merge. Each is two simple shapes put together, and layering two masks gives hard seams, no notch and no melting.

If both shapes are signed distance functions, one more line joins, cuts or melts them, and the result is still a distance you can draw with the same smoothstep.

Two distances in, one distance out

A fragment shader is a small function that runs once per pixel and returns a colour. Last time it worked out one signed distance d per pixel, negative inside and positive outside. Now it works out two, a for a circle A and b for a rounded box B, and must turn them into one d before drawing.

float a = sdCircle(p - posA, 0.18);
float b = sdBox(p - posB, vec2(0.18, 0.12) - 0.04) - 0.04;
float d = min(a, b);                     // the only new line
float m = 1.0 - smoothstep(-aa, aa, d);  // the same mask as before

Subtracting a centre such as posA from p moves a shape there, because the function now measures from that point.

Union is min

A pixel is in the union of two shapes when it is inside either one. Inside means negative, and min(a, b) is negative as soon as either value is. Outside both, the nearest edge is the nearer of the two, again the smaller distance.

Intersection is max

The intersection is where a pixel is inside both shapes. max(a, b) is negative only when both values are, so it keeps just the overlap.

Subtraction is max with a flipped sign

Negating a distance turns its shape inside out: -b is negative everywhere except inside B. Intersect A with that and you get A with B cut out of it: max(a, -b). The order matters. max(b, -a) cuts the circle out of the box instead.

The result is not always an exact distance. min is exact outside the union and max inside the intersection. Elsewhere the number is a bound: the real edge is at least that far away, never closer. The zero line, which is all the mask uses, is always in the right place.

Smooth union: melt the corner

Where A and B meet, min switches from one distance to the other with a sharp crease. A smooth minimum replaces that switch with a curve over a band of width k:

float smin(float a, float b, float k) {
    float h = clamp(0.5 + 0.5 * (b - a) / k, 0.0, 1.0);
    return mix(b, a, h) - k * h * (1.0 - h);
}

h is how much a wins: 1.0 when a is smaller by k or more, 0.0 when b is, 0.5 when they are equal. mix blends the two distances by that weight. On its own, a blend sits above the smaller value, so the last term pulls it back down, by up to k / 4 where the two are equal. Far from the seam h is exactly 0 or 1 and smin is the same as min.

The same trick smooths the other two: a smooth maximum is -smin(-a, -b, k), which gives a smooth intersection, and -smin(-a, b, k) is a smooth subtraction with a rounded cut.

Rule of thumb

Combine the distances, then make the mask once. A union of two masks looks the same as min, but masks cannot be cut, rounded, outlined or melted afterwards. Distances can.

Then choose Smooth union and pull the shapes apart slowly: a bridge forms before they touch. In the Stage menu, stages 1 and 2 are each distance alone and stage 3 the combined one. With the hard union the bands crease sharply between the shapes; with the smooth union the crease is rounded.

The code

The Lua version runs the demo's shader in LÖVE, whose pixel shaders use the entry point effect instead of main. Drag to move the nearer shape. Keys 1 to 4 pick the operation, up and down change k, S cycles the stage and G toggles the guides.

-- The demo's starting values. Centred uv: (0, 0) in the middle, y up.
local posA = { -0.15, 0.02 }   -- circle centre
local posB = { 0.15, -0.02 }   -- rounded box centre
local op = 0                   -- 0 union, 1 subtraction, 2 intersection, 3 smooth union
local k = 0.1                  -- smoothness, in uv units
local stage = 4                -- 0 a, 1 b, 2 combined d, 3 mask, 4 final
local guides = 1
local rect = { 20, 20, 640, 360 }   -- x, y, width, height in pixels
local dragging = nil
local shader

local pixelcode = [[
uniform vec2 u_posA;
uniform vec2 u_posB;
uniform float u_op;
uniform float u_k;
uniform float u_stage;
uniform float u_guides;
uniform vec4 u_rect;

float sdCircle(vec2 p, float r) {
    return length(p) - r;
}

float sdBox(vec2 p, vec2 b) {
    vec2 q = abs(p) - b;
    return length(max(q, vec2(0.0))) + min(max(q.x, q.y), 0.0);
}

float smin(float a, float b, float k) {
    float h = clamp(0.5 + 0.5 * (b - a) / k, 0.0, 1.0); // 1: a wins, 0: b wins
    return mix(b, a, h) - k * h * (1.0 - h);
}

float combine(float a, float b) {
    float d = min(a, b);                              // union
    if (u_op > 0.5) d = max(a, -b);                   // subtraction: A minus B
    if (u_op > 1.5) d = max(a, b);                    // intersection
    if (u_op > 2.5) d = smin(a, b, max(u_k, 0.0001)); // smooth union
    return d;
}

vec3 bands(float d, float aa) {
    vec3 side = mix(vec3(0.35, 0.6, 1.0), vec3(1.0, 0.62, 0.2), step(d, 0.0));
    vec3 c = side * (0.75 + 0.25 * cos(6.2832 * 20.0 * d));
    return mix(c, vec3(1.0), 1.0 - smoothstep(aa, 2.0 * aa, abs(d)));
}

float contour(float d, float aa) {
    return 1.0 - smoothstep(0.5 * aa, 1.5 * aa, abs(d));
}

vec3 shade(vec2 uv, float aa) {
    float a = sdCircle(uv - u_posA, 0.18);                         // 1. circle
    float b = sdBox(uv - u_posB, vec2(0.18, 0.12) - 0.04) - 0.04;  // 2. rounded box
    float d = combine(a, b);                                       // 3. one distance
    float m = 1.0 - smoothstep(-aa, aa, d);                        // 4. mask
    vec3 col = mix(vec3(0.1, 0.12, 0.22), vec3(1.0, 0.62, 0.2), m); // 5. final
    if (u_stage < 3.5) col = vec3(m);
    if (u_stage < 2.5) col = bands(d, aa);
    if (u_stage < 1.5) col = bands(b, aa);
    if (u_stage < 0.5) col = bands(a, aa);
    float g = max(contour(a, aa), contour(b, aa)) * u_guides;
    return mix(col, vec3(0.2, 0.9, 0.5), 0.8 * g);
}

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
    vec2 uv = (screen_coords - u_rect.xy - 0.5 * u_rect.zw) / u_rect.w;
    uv.y = -uv.y;                     // y points down here; make it point up
    float aa = 1.0 / u_rect.w;        // one pixel, in uv units
    return vec4(shade(uv, aa), 1.0);
}
]]

local function toUV(x, y)
  local u = (x - rect[1] - rect[3] / 2) / rect[4]
  local v = -(y - rect[2] - rect[4] / 2) / rect[4]
  return u, v
end

function love.load()
  shader = love.graphics.newShader(pixelcode)
end

function love.mousepressed(x, y, button)
  if button ~= 1 then return end
  local u, v = toUV(x, y)
  local da = (u - posA[1]) ^ 2 + (v - posA[2]) ^ 2
  local db = (u - posB[1]) ^ 2 + (v - posB[2]) ^ 2
  if da < db then dragging = posA else dragging = posB end   -- the nearer one
  dragging[1], dragging[2] = u, v
end

function love.mousemoved(x, y)
  if dragging then dragging[1], dragging[2] = toUV(x, y) end
end

function love.mousereleased()
  dragging = nil
end

function love.keypressed(key)
  if key == "1" then op = 0 end
  if key == "2" then op = 1 end
  if key == "3" then op = 2 end
  if key == "4" then op = 3 end
  if key == "up" then k = math.min(0.3, k + 0.01) end
  if key == "down" then k = math.max(0, k - 0.01) end
  if key == "s" then stage = (stage + 1) % 5 end
  if key == "g" then guides = 1 - guides end
end

function love.draw()
  shader:send("u_posA", posA)
  shader:send("u_posB", posB)
  shader:send("u_op", op)
  shader:send("u_k", k)
  shader:send("u_stage", stage)
  shader:send("u_guides", guides)
  shader:send("u_rect", rect)
  love.graphics.setShader(shader)
  love.graphics.rectangle("fill", rect[1], rect[2], rect[3], rect[4])
  love.graphics.setShader()
end

precision highp float;
#else
precision mediump float;
#endif

uniform vec2 u_resolution;
uniform vec2 u_posA;
uniform vec2 u_posB;
uniform float u_op;
uniform float u_k;
uniform float u_stage;
uniform float u_guides;

float sdCircle(vec2 p, float r) {
  return length(p) - r;
}

float sdBox(vec2 p, vec2 b) {
  vec2 q = abs(p) - b;
  return length(max(q, vec2(0.0))) + min(max(q.x, q.y), 0.0);
}

float smin(float a, float b, float k) {
  float h = clamp(0.5 + 0.5 * (b - a) / k, 0.0, 1.0); // 1: a wins, 0: b wins
  return mix(b, a, h) - k * h * (1.0 - h);
}

float combine(float a, float b) {
  float d = min(a, b);                              // union
  if (u_op > 0.5) d = max(a, -b);                   // subtraction: A minus B
  if (u_op > 1.5) d = max(a, b);                    // intersection
  if (u_op > 2.5) d = smin(a, b, max(u_k, 0.0001)); // smooth union
  return d;
}

vec3 bands(float d, float aa) {
  vec3 side = mix(vec3(0.35, 0.6, 1.0), vec3(1.0, 0.62, 0.2), step(d, 0.0));
  vec3 c = side * (0.75 + 0.25 * cos(6.2832 * 20.0 * d));
  return mix(c, vec3(1.0), 1.0 - smoothstep(aa, 2.0 * aa, abs(d)));
}

float contour(float d, float aa) {
  return 1.0 - smoothstep(0.5 * aa, 1.5 * aa, abs(d));
}

vec3 shade(vec2 uv, float aa) {
  float a = sdCircle(uv - u_posA, 0.18);                         // 1. circle
  float b = sdBox(uv - u_posB, vec2(0.18, 0.12) - 0.04) - 0.04;  // 2. rounded box
  float d = combine(a, b);                                       // 3. one distance
  float m = 1.0 - smoothstep(-aa, aa, d);                        // 4. mask
  vec3 col = mix(vec3(0.1, 0.12, 0.22), vec3(1.0, 0.62, 0.2), m); // 5. final
  if (u_stage < 3.5) col = vec3(m);
  if (u_stage < 2.5) col = bands(d, aa);
  if (u_stage < 1.5) col = bands(b, aa);
  if (u_stage < 0.5) col = bands(a, aa);
  float g = max(contour(a, aa), contour(b, aa)) * u_guides;
  return mix(col, vec3(0.2, 0.9, 0.5), 0.8 * g);
}

void main() {
  vec2 px = gl_FragCoord.xy;                    // pixels, origin bottom-left
  vec2 uv = (px - 0.5 * u_resolution) / u_resolution.y; // centred, y up
  float aa = 1.0 / u_resolution.y;              // one pixel, in uv units
  gl_FragColor = vec4(shade(uv, aa), 1.0);
}

// Put this in a ShaderMaterial on a ColorRect.
shader_type canvas_item;

uniform vec2 pos_a = vec2(-0.15, 0.02);
uniform vec2 pos_b = vec2(0.15, -0.02);
uniform float smoothness : hint_range(0.0, 0.3) = 0.1;
uniform float aspect = 1.0;    // set to the ColorRect's width / height

float sd_box(vec2 p, vec2 b) {
    vec2 q = abs(p) - b;
    return length(max(q, vec2(0.0))) + min(max(q.x, q.y), 0.0);
}

float smin(float a, float b, float k) {
    float h = clamp(0.5 + 0.5 * (b - a) / k, 0.0, 1.0);
    return mix(b, a, h) - k * h * (1.0 - h);
}

void fragment() {
    vec2 uv = (UV - 0.5) * vec2(aspect, 1.0);
    uv.y = -uv.y;              // UV (0, 0) is the top-left; make y point up
    float a = length(uv - pos_a) - 0.18;
    float b = sd_box(uv - pos_b, vec2(0.18, 0.12) - 0.04) - 0.04;
    float d = smin(a, b, max(smoothness, 0.0001));
    float aa = fwidth(uv.y);   // one pixel, in uv units
    float m = 1.0 - smoothstep(-aa, aa, d);
    COLOR = vec4(mix(vec3(0.1, 0.12, 0.22), vec3(1.0, 0.62, 0.2), m), 1.0);
}

        _K ("Smoothness", Range(0, 0.3)) = 0.1

The Godot and Unity versions show the smooth union; swap the smin line for min, max(a, -b) or max(a, b) for the others. In URP Shader Graph, Minimum and Maximum nodes do the hard operations and smin fits in a Custom Function node.

The positions assume y up. WebGL's gl_FragCoord and a Unity Quad's uv start at the bottom-left with y up; Godot's canvas_item UV and LÖVE's screen_coords start at the top-left with y down, so those versions flip y. In a Unity project set to Linear colour space, the hard-coded colours are treated as linear values and look lighter than on this page.

Pitfalls

  • Subtracting the wrong way round. max(a, -b) is A minus B. If the wrong shape disappears, swap the arguments.
  • A smoothness of zero. smin divides by k. Clamp it to a tiny positive value, as the code does, or branch to plain min.
  • Smooth union grows the shape. smin is never larger than min, so the shapes swell where they meet and join before they touch. If two parts must stay separate until they collide, use a smaller k.
  • Trusting the distance far from the edge. After a max or a blend, the value away from zero is a bound. The fill is right; a wide glow or thick outline can come out uneven near cuts.
  • Combining masks instead of distances. Once you have taken a smoothstep, the distance is gone. Do all the combining first and take the mask once at the end.

What it costs

min and max are single instructions, and smin is roughly half a dozen: a division, a clamp, a mix and a few multiplies. That is nothing next to the shapes, which every pixel evaluates in full, near them or not. Ten shapes cost ten shapes for every pixel: fine on a phone for a button, worth measuring for a full-screen effect. The if statements on u_op are cheap because every pixel takes the same path.

In real games

Inigo Quilez's articles on distance functions and the smooth minimum are where many shader programmers learned these operations, and they appear across Shadertoy. Media Molecule's Dreams lets players sculpt by adding and subtracting shapes with soft blends, built on signed distance fields, as Alex Evans described in his SIGGRAPH 2015 talk Learning from Failure.

In 2D the same lines draw UI shapes that are awkward as textures, such as a panel with a notch for a tab, and merging blobs of liquid or slime. They work unchanged in 3D, where a later ray marching lesson uses them.

Your turn (15 minutes)

Turn the LÖVE example into a pair of lava lamp blobs:

  1. Replace the box with a second circle of radius 0.12, and add uniform float u_time;, sent from a Lua variable that love.update(dt) increases by dt.
  2. Set posA to { 0, 0 } and move the small circle up and down through it: centre vec2(0.0, 0.3 * sin(u_time)).
  3. Join them with smin and k = 0.15.

You are done when the small blob stretches a neck towards the big one before touching, merges, and pulls away again with no hard seam.

Takeaways

  • min(a, b) is the union, max(a, b) the intersection, and max(a, -b) cuts B out of A.
  • smin(a, b, k) rounds the seam over a band of width k, so shapes melt together and join slightly before they touch.
  • The combined value is still a signed distance at the edge, so the same smoothstep draws it. Away from the edge it can be a bound.
  • Combine distances first and take the mask once.
  • The operations are almost free; every shape in the shader still costs every pixel.
