Dissolve: burning a sprite away with a noise threshold

Give every pixel a noise value, delete the pixels below a rising threshold, and colour a thin band above it to burn a sprite away.

An enemy dies and simply vanishes between one frame and the next. Fading its alpha is better, but the whole sprite turns into a ghost at once. A dissolve eats the sprite in ragged holes that spread out behind a glowing rim, and it needs only one number from the game: how far the burn has got.

Every pixel gets a turn

A fragment shader is a small function that runs once per pixel and returns a colour. For a dissolve, that function needs to know one extra thing about its pixel: when should this pixel disappear? We store that as a number from 0 to 1 called the threshold map, written n. A pixel with n = 0.1 burns early; a pixel with n = 0.9 lasts almost to the end.

The game sends one value for the whole sprite, progress, which climbs from 0 to 1 while the enemy dies. Each pixel compares its own n with that value. If n is lower, the pixel is gone: its alpha becomes 0. That comparison is a threshold, and in a shader it is one call to step:

alive = step(cut, n)        -- 1.0 when n >= cut, otherwise 0.0
alpha = texel.a * alive

Why noise

Any map from 0 to 1 works, and the map decides the look. A vertical gradient wipes the sprite from the top; distance from a point burns outwards; a random value per pixel crumbles it into specks. Smooth noise, the layered fBm from the procedural materials lesson, is the classic choice: neighbours have similar values, so holes start as blobs and grow into each other like burning paper.

The burning edge

A hard cut looks like an eraser. The burn comes from the pixels about to go: those whose n lies between cut and cut + edge, where edge is the band's width. We paint them in a flat edge colour:

band = alive * (1.0 - step(cut + edge, n))   -- 1.0 just above the cut
rgb  = mix(texel.rgb, edgeColor, band)

Making both ends of the slider honest

Two details make progress = 0 mean "all there" and progress = 1 mean "all gone". First, the band must start below 0, or the edge glows before the death begins. So the cut is stretched by the band width:

cut = progress * (1.0 + edge) - edge   -- runs from -edge up to 1.0

At progress = 0 the band covers -edge to 0, where no pixel lives. At progress = 1 the cut is 1 and every pixel is below it.

Second, fBm bunches up in the middle: measured over a large area, 98 percent of this lesson's noise values fall between about 0.22 and 0.83. Unfixed, the first fifth of the slider does nothing. Stretching with (fbm - 0.2) / 0.6 and clamping to 0.001 to 0.999 spreads the burn over the whole slider and keeps every value strictly inside the range.

Coordinates and colour space

Read the noise in the sprite's own coordinates, so the holes move with it. The demo builds them from gl_FragCoord, whose (0, 0) is the canvas's bottom-left with y up. LÖVE's texture_coords and Godot's UV start at the image's top-left with y down, so that code flips y to burn the same holes. Unity's UVs start at the bottom-left with y up: no flip. The edge colour is mixed as stored (sRGB) here; linear-space projects get slightly different in-between shades.

Try it

Press Burn or drag Progress. Step through Stage: the threshold map shows n as grey (darkest goes first); the mask shows kept in white, gone in black and the band in the edge colour. Try each Burn order, and click, drag or use the arrow keys on the canvas to move the burn's starting point. Turn off One value per sprite pixel to see smooth holes cut through chunky pixels.

The code

The LÖVE program builds the slime from the hit flash lesson in code and draws it eight times larger with the dissolve shader. Press space to kill it and space again to bring it back. The numbers match the demo's defaults.

local DISSOLVE_TIME = 1.2                -- seconds from first hole to gone
local EDGE_WIDTH = 0.08                  -- width of the burning band
local EDGE_COLOR = { 1.0, 0.55, 0.1 }    -- orange
local NOISE_SCALE = 4.0                  -- noise cells across the sprite
local progress = 0                       -- 0 = whole sprite, 1 = gone
local dying = false
local sprite, shader

local pixelcode = [[
uniform float u_progress;
uniform float u_edge;
uniform vec3 u_edgeColor;
uniform float u_scale;

const vec2 SPRITE_SIZE = vec2(24.0, 20.0);

float hash(vec2 c)
{
  c = fract(c * vec2(0.1031, 0.1137));
  c += dot(c, c + 19.19);
  return fract(c.x * c.y);
}

float valueNoise(vec2 p)
{
  vec2 i = floor(p);
  vec2 f = fract(p);
  vec2 u = f * f * (3.0 - 2.0 * f);
  return mix(mix(hash(i), hash(i + vec2(1.0, 0.0)), u.x),
             mix(hash(i + vec2(0.0, 1.0)), hash(i + vec2(1.0, 1.0)), u.x), u.y);
}

float fbm(vec2 p)
{
  float sum = 0.0;
  float amp = 0.5;
  for (int k = 0; k < 4; k++) {
    sum += amp * valueNoise(p);
    p = p * 2.0 + vec2(5.3, 1.7);
    amp *= 0.5;
  }
  return sum / 0.9375;
}

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
  vec4 texel = Texel(tex, texture_coords) * color;
  // sprite pixels with y up, like the demo (LÖVE's texture y = 0 is the top row)
  vec2 sp = vec2(texture_coords.x, 1.0 - texture_coords.y) * SPRITE_SIZE;
  vec2 np = floor(sp) + 0.5;                     // one value per sprite pixel
  float n = (fbm(np / SPRITE_SIZE.x * u_scale) - 0.2) / 0.6;
  n = clamp(n, 0.001, 0.999);
  float cut = u_progress * (1.0 + u_edge) - u_edge;
  float alive = step(cut, n);
  float edge = alive * (1.0 - step(cut + u_edge, n));
  return vec4(mix(texel.rgb, u_edgeColor, edge), texel.a * alive);
}
]]

local function inside(x, y, cx, cy, rx, ry)
  local dx = (x - cx) / rx
  local dy = (y - cy) / ry
  return dx * dx + dy * dy < 1
end

-- the slime, 24 by 20 pixels; py counts upwards like the demo
local function slimePixel(x, y)
  local px, py = x + 0.5, 19.5 - y
  local r, g, b, a = 0, 0, 0, 0
  if inside(px, py, 12, 9, 10.5, 8.5) and py > 1 then r, g, b, a = 0.10, 0.30, 0.14, 1 end
  if inside(px, py, 12, 9, 9.5, 7.5) and py > 2 then
    local t = py / 17
    r, g, b, a = 0.20 + 0.16 * t, 0.58 + 0.22 * t, 0.28 + 0.12 * t, 1
  end
  if inside(px, py, 7.5, 13, 1.6, 1.6) then r, g, b, a = 0.78, 0.96, 0.74, 1 end
  if inside(px, py, 9, 9.5, 2.2, 2.2) or inside(px, py, 15, 9.5, 2.2, 2.2) then
    r, g, b, a = 0.96, 0.96, 0.96, 1
  end
  if inside(px, py, 9.5, 9, 1.1, 1.1) or inside(px, py, 15.5, 9, 1.1, 1.1) then
    r, g, b, a = 0.08, 0.08, 0.12, 1
  end
  return r, g, b, a
end

function love.load()
  local data = love.image.newImageData(24, 20)
  data:mapPixel(function(x, y) return slimePixel(x, y) end)
  sprite = love.graphics.newImage(data)
  sprite:setFilter("nearest", "nearest")
  shader = love.graphics.newShader(pixelcode)
end

function love.keypressed(key)
  if key == "space" then
    if progress >= 1 then
      progress = 0          -- respawn
      dying = false
    else
      dying = true          -- start the dissolve
    end
  end
end

function love.update(dt)
  if dying then
    progress = math.min(progress + dt / DISSOLVE_TIME, 1)
  end
end

function love.draw()
  local w, h = love.graphics.getDimensions()
  love.graphics.clear(0.15, 0.17, 0.22)
  if progress >= 1 then return end   -- fully gone: do not draw it at all
  shader:send("u_progress", progress)
  shader:send("u_edge", EDGE_WIDTH)
  shader:send("u_edgeColor", EDGE_COLOR)
  shader:send("u_scale", NOISE_SCALE)
  love.graphics.setShader(shader)
  love.graphics.draw(sprite, w / 2 - 96, h / 2 - 80, 0, 8, 8)
  love.graphics.setShader()
end
#ifdef GL_FRAGMENT_PRECISION_HIGH
precision highp float;   // the hash needs 32-bit floats
#else
precision mediump float;
#endif

uniform vec2 u_resolution;
uniform float u_progress;   // 0 = whole sprite, 1 = all gone
uniform float u_edge;       // width of the burning band
uniform vec3 u_edgeColor;   // colour of the band
uniform float u_scale;      // noise cells across the sprite
uniform float u_pattern;    // 0 noise, 1 random per pixel, 2 top down, 3 from a point, 4 point + noise
uniform vec2 u_origin;      // burn origin, in sprite pixels
uniform float u_snap;       // 1 = one value per sprite pixel, 0 = smooth
uniform float u_stage;      // 0 texel, 1 threshold map, 2 mask, 3 final

const vec2 SPRITE_SIZE = vec2(24.0, 20.0);   // in sprite pixels
const float ROW = 9.5;                       // the row plotted in the graph

float ellipse(vec2 p, vec2 c, vec2 r) {
  return length((p - c) / r);   // below 1.0 inside the ellipse
}

// The "texture": colour and alpha of one sprite pixel, y up.
vec4 sprite(vec2 sp) {
  vec4 col = vec4(0.0);
  if (ellipse(sp, vec2(12.0, 9.0), vec2(10.5, 8.5)) < 1.0 && sp.y > 1.0)
    col = vec4(0.10, 0.30, 0.14, 1.0);                                   // outline
  if (ellipse(sp, vec2(12.0, 9.0), vec2(9.5, 7.5)) < 1.0 && sp.y > 2.0)
    col = vec4(mix(vec3(0.20, 0.58, 0.28), vec3(0.36, 0.80, 0.40), sp.y / 17.0), 1.0);  // body
  if (length(sp - vec2(7.5, 13.0)) < 1.6) col = vec4(0.78, 0.96, 0.74, 1.0);    // shine
  if (length(sp - vec2(9.0, 9.5)) < 2.2) col = vec4(0.96, 0.96, 0.96, 1.0);     // eyes
  if (length(sp - vec2(15.0, 9.5)) < 2.2) col = vec4(0.96, 0.96, 0.96, 1.0);
  if (length(sp - vec2(9.5, 9.0)) < 1.1) col = vec4(0.08, 0.08, 0.12, 1.0);     // pupils
  if (length(sp - vec2(15.5, 9.0)) < 1.1) col = vec4(0.08, 0.08, 0.12, 1.0);
  return col;
}

// A hash without sin(), so the graph below can repeat it on the CPU.
float hash(vec2 c) {
  c = fract(c * vec2(0.1031, 0.1137));
  c += dot(c, c + 19.19);
  return fract(c.x * c.y);
}

float valueNoise(vec2 p) {
  vec2 i = floor(p);
  vec2 f = fract(p);
  vec2 u = f * f * (3.0 - 2.0 * f);
  return mix(mix(hash(i), hash(i + vec2(1.0, 0.0)), u.x),
             mix(hash(i + vec2(0.0, 1.0)), hash(i + vec2(1.0, 1.0)), u.x), u.y);
}

// four octaves, each twice as fine and half as strong
float fbm(vec2 p) {
  float sum = 0.0;
  float amp = 0.5;
  for (int k = 0; k < 4; k++) {
    sum += amp * valueNoise(p);
    p = p * 2.0 + vec2(5.3, 1.7);
    amp *= 0.5;
  }
  return sum / 0.9375;   // 0.5 + 0.25 + 0.125 + 0.0625
}

// The threshold map: when does this pixel burn? 0 = first, 1 = last.
float thresholdMap(vec2 sp) {
  float noise = (fbm(sp / SPRITE_SIZE.x * u_scale) - 0.2) / 0.6;   // stretch to fill 0..1
  float speck = hash(floor(sp));
  float topDown = 1.0 - sp.y / SPRITE_SIZE.y;
  float fromPoint = length(sp - u_origin) / 30.0;
  float n = noise;
  if (u_pattern > 0.5) n = speck;
  if (u_pattern > 1.5) n = topDown;
  if (u_pattern > 2.5) n = fromPoint;
  if (u_pattern > 3.5) n = mix(fromPoint, noise, 0.4);
  return clamp(n, 0.001, 0.999);   // never exactly 0 or 1
}

void main() {
  vec2 p = (gl_FragCoord.xy - 0.5 * u_resolution) / u_resolution.y;   // (0, 0) centre, y up

  // background: a dark tiled floor
  vec2 tile = floor(p * 8.0);
  vec3 bg = mix(vec3(0.15, 0.17, 0.22), vec3(0.19, 0.21, 0.27), mod(tile.x + tile.y, 2.0));

  // the sprite's quad: 0.6 of the canvas height wide, centred
  float pixelSize = 0.6 / SPRITE_SIZE.x;
  vec2 sp = (p - vec2(-0.3, -0.25)) / pixelSize;   // sprite pixel coordinates
  bool inQuad = sp.x >= 0.0 && sp.x < SPRITE_SIZE.x && sp.y >= 0.0 && sp.y < SPRITE_SIZE.y;

  vec3 col = bg;
  if (inQuad) {
    vec4 texel = sprite(floor(sp) + 0.5);                 // 1. read the texel
    vec2 np = mix(sp, floor(sp) + 0.5, u_snap);
    float n = thresholdMap(np);                            // 2. when does it burn?
    float cut = u_progress * (1.0 + u_edge) - u_edge;      // 3. the moving threshold
    float alive = step(cut, n);                            //    1 while n >= cut
    float edge = alive * (1.0 - step(cut + u_edge, n));    //    1 just above the cut
    vec3 rgb = mix(texel.rgb, u_edgeColor, edge);          // 4. colour the band
    col = mix(bg, rgb, texel.a * alive);                   //    and cut the alpha

    float shape = mix(0.45, 1.0, texel.a);   // dims the empty part of the quad
    if (u_stage < 2.5) col = mix(vec3(alive * 0.9), u_edgeColor, edge) * shape;
    if (u_stage < 1.5) col = vec3(n) * shape;
    if (u_stage < 0.5) col = mix(bg, texel.rgb, texel.a);
    if (u_stage > 0.5 && u_stage < 2.5 && abs(sp.y - ROW) < 0.12) col = vec3(1.0, 0.3, 0.6);
  }

  // demo only: a ring on the burn origin
  if (u_pattern > 2.5 && abs(length(sp - u_origin) - 0.9) < 0.15) col = vec3(1.0, 0.3, 0.6);
  gl_FragColor = vec4(col, 1.0);
}

shader_type canvas_item;

uniform float progress : hint_range(0.0, 1.0) = 0.0;
uniform float edge_width : hint_range(0.0, 0.3) = 0.08;
uniform vec4 edge_color : source_color = vec4(1.0, 0.55, 0.1, 1.0);
uniform float noise_scale = 4.0;

float hash(vec2 c) {
    c = fract(c * vec2(0.1031, 0.1137));
    c += vec2(dot(c, c + vec2(19.19)));
    return fract(c.x * c.y);
}

float value_noise(vec2 p) {
    vec2 i = floor(p);
    vec2 f = fract(p);
    vec2 u = f * f * (3.0 - 2.0 * f);
    return mix(mix(hash(i), hash(i + vec2(1.0, 0.0)), u.x),
               mix(hash(i + vec2(0.0, 1.0)), hash(i + vec2(1.0, 1.0)), u.x), u.y);
}

float fbm(vec2 p) {
    float sum = 0.0;
    float amp = 0.5;
    for (int k = 0; k < 4; k++) {
        sum += amp * value_noise(p);
        p = p * 2.0 + vec2(5.3, 1.7);
        amp *= 0.5;
    }
    return sum / 0.9375;
}

void fragment() {
    vec4 texel = texture(TEXTURE, UV);
    vec2 size = 1.0 / TEXTURE_PIXEL_SIZE;              // the texture in pixels
    vec2 sp = vec2(UV.x, 1.0 - UV.y) * size;           // Godot's UV y points down
    vec2 np = floor(sp) + 0.5;
    float n = clamp((fbm(np / size.x * noise_scale) - 0.2) / 0.6, 0.001, 0.999);
    float cut = progress * (1.0 + edge_width) - edge_width;
    float alive = step(cut, n);
    float edge = alive * (1.0 - step(cut + edge_width, n));
    COLOR = vec4(mix(texel.rgb, edge_color.rgb, edge), texel.a * alive);
}

            float _EdgeWidth;

                float4 vertex : POSITION;
                float2 uv : TEXCOORD0;

                float4 pos : SV_POSITION;

The demo's shader has extra branches for burn orders, stages and the graph row; the engine versions keep only the noise order. For URP, build it in a Sprite Unlit Shader Graph: a Simple Noise node gives n, two Step nodes against the cut give alive and the band, a Lerp mixes in the edge colour, and alive times the texture's alpha goes to Alpha. Simple Noise bunches its values differently, so check both ends of the progress range.

Pitfalls

  • Noise in screen coordinates. With gl_FragCoord or SCREEN_UV the holes stay fixed on screen while the sprite moves under them.
  • Sprites from an atlas. The UVs cover only the sprite's region and the texture size is the atlas size, so the noise stretches or changes between animation frames. Pass the region's rectangle and convert to region-local coordinates first.
  • A dead start and a sudden end. The threshold map does not cover 0 to 1. Stretch it.
  • Smooth holes in pixel art. Full-resolution noise cuts curves through big square pixels. Read it once per texel with floor(sp) + 0.5.
  • Forgetting the game side. At progress = 1 the shader still runs over an invisible quad and the collider still exists. Stop drawing the sprite, and switch off collisions when the dissolve starts.
  • Every enemy burns at once. As with the hit flash, a shared material shares progress. Give each dying enemy its own value.

What it costs

Four octaves of value noise is sixteen hashes per pixel: nothing for one sprite, even on a phone, but it adds up across a screen of large dissolving sprites. Production games usually read the noise from a small grey texture instead, one texture read. The hash also needs highp; in mediump, which some phones use in fragment shaders, it loses digits and the noise turns blocky. In 3D, opaque models dissolve with discard (Unity's clip), called alpha clipping. Discarding can stop the GPU from rejecting hidden pixels early, which tile-based mobile GPUs feel most, so switch to a clipping material only while the object dissolves.

In real games

Noise-threshold dissolves are a stock effect for defeated enemies, teleports and spawning objects in 2D and 3D games. Both engines can supply the noise without code: Godot has the NoiseTexture2D resource and Unity's Shader Graph has noise nodes. The same trick with a hand-painted grey map instead of noise makes screen wipes and oddly shaped fill bars: the map decides the order, the threshold moves.

Make the slime burn from where it was hit, like the demo's Point + noise order.

  1. Add uniform vec2 u_origin; to the LÖVE shader and compute float fromPoint = length(sp - u_origin) / 30.0;.
  2. Use n = mix(fromPoint, noise, 0.4) before the clamp, where noise is the stretched fBm.
  3. In love.mousepressed(x, y), turn the click into sprite pixels: subtract the sprite's top-left corner, divide by 8, and flip y with 20 - y. Send it, then start the dissolve.

You are done when clicking the slime's left eye starts the holes there, and clicking its bottom edge starts them at the bottom.

Takeaways

  • A dissolve gives every pixel a number for when it burns, the threshold map, and compares it with one rising value from the game.
  • step(cut, n) keeps or removes the pixel; a second step at cut + edge finds the band to colour.
  • The map sets the look: noise burns in blobs, a gradient wipes, distance spreads from a point, a per-pixel hash crumbles.
  • Stretch the map to fill 0 to 1 and offset the cut by the band width so both ends of the progress range behave.
  • Read the noise in sprite coordinates, once per texel for pixel art.
