Procedural materials: wood, marble and clouds from layered noise

Add several octaves of noise, each finer and fainter, then bend rings, stripes or a threshold with it: wood, marble and clouds from one recipe.

Plain noise looks like blurry fog. Real surfaces have big shapes with smaller detail on top: a cloud has billows, and the billows have ragged edges. This lesson builds that layered detail, then shapes it into wood, marble and a cloudy sky without a texture file.

Layer the noise, then shape it

A fragment shader is a small function that runs once per pixel: a position goes in, a colour comes out. For a procedural material the middle of that function has two jobs. First, make a rich noise value n for this pixel. Second, push that value through a shaping function, a line of maths that turns plain noise into the look of one material. A colour ramp at the end picks the colour.

Step 1: one octave is too smooth

Value noise blends random numbers stored on the corners of a grid. One grid size gives one size of feature and nothing smaller, while real materials have detail at every scale.

Step 2: add octaves

So add several copies of the noise. Each copy is an octave: it has twice the frequency of the one before (its grid cells are half as big) and half the amplitude (it moves the total half as much). The sum is called fractal Brownian motion, or fBm. The factor between frequencies, 2 here, is called the lacunarity; the factor between amplitudes, 0.5 here, is the gain.

In GLSL it is a loop. The loop bound must be a constant in WebGL 1, so the loop always runs six times and an if skips the octaves the slider has switched off:

float fbm(vec2 p) {
  float sum = 0.0;
  float amp = 0.5;
  float total = 0.0;
  for (int k = 0; k < 6; k++) {
    if (float(k) < u_octaves) {
      sum += amp * valueNoise(p);
      total += amp;
    }
    p = p * 2.0 + vec2(5.3, 1.7);   // twice the frequency, and a shift
    amp *= 0.5;                     // half the amplitude
  }
  return sum / total;               // back to 0..1
}

The shift vec2(5.3, 1.7) stops each octave's grid corners landing on the corners of the one before. Dividing by total keeps the result between 0 and 1 for any octave count.

Step 3: shape it into a material

fBm alone still looks like fog, only crisper. What makes a material is a simple pattern that the noise bends. The demo uses one stretched coordinate s: the pixel's position with x divided by a stretch factor, so features come out longer along x, like wood grain or layered cloud.

Wood. Without noise, fract(1.5 * r) draws concentric rings: a sawtooth that climbs from 0 to 1 across each ring, then drops back. The ramp makes each ring darken and end in a sharp edge, as growth rings do. Adding 2.0 * n before the fract pushes each ring in or out by a different amount everywhere, and the stretch turns the circles into long grain.

Marble. sin of a diagonal position makes straight stripes. Adding 8.0 * n inside the sine bends them into swirls; this is the classic marble recipe from Ken Perlin's 1985 paper, with plain fBm standing in for his "turbulence". abs is 0 where the sine crosses zero, and sqrt lifts everything else towards 1, so the crossings become thin dark veins.

Clouds. Here the noise is the shape. smoothstep turns noise above 0.65 into solid cloud, noise below 0.35 into clear sky, and blends between. Adding 0.1 * s.y makes the sky cloudier towards the top.

Finally, contrast scales t away from 0.5 and clamps it: above 1 it sharpens edges and thins the veins, below 1 it flattens everything towards the middle colour.

Which corner is (0, 0), and which colours

WebGL's gl_FragCoord starts at the bottom-left with y up, and the demo moves (0, 0) to the centre. LÖVE's screen_coords and Godot's canvas UV start at the top-left with y down, so the code below flips y; Unity's mesh UVs start at the bottom-left. The ramp colours are display (sRGB) values; in a Unity project set to linear colour space they come out lighter.

Try it

Step through stages 1 to 5 for each material. On stage 2, slide Octaves from 1 to 6 and watch soft blobs gain ragged edges; the graph shows the same along one line. Stage 3 switches the noise off: plain rings, straight stripes, a sky gradient. Then try Stretch at 1 and at 6 on wood, and Contrast at 3 on marble.

The code

In LÖVE the shader is a string with the effect entry point, drawn over the whole window. Keys 1, 2 and 3 pick wood, marble or clouds, up and down change the octaves, left and right the stretch, A and Z the contrast, and space starts or stops the drift.

local material = 0       -- 0 wood, 1 marble, 2 clouds
local octaves = 5        -- layers of noise, 1 to 6
local stretch = 3.0      -- 1 = round features, more = longer along x
local contrast = 1.0     -- 1 = unchanged
local drift = 0          -- slides the noise while drifting is on
local drifting = false
local shader

local pixelcode = [[
uniform vec2 u_resolution;
uniform float u_material;
uniform float u_octaves;
uniform float u_stretch;
uniform float u_contrast;
uniform float u_drift;

float hash(vec2 c)
{
  c = mod(c, 64.0);
  return fract(sin(dot(c, vec2(12.9898, 78.233))) * 43758.5453);
}

float valueNoise(vec2 p)
{
  vec2 i = floor(p);
  vec2 f = fract(p);
  vec2 u = f * f * (3.0 - 2.0 * f);
  float a = hash(i);
  float b = hash(i + vec2(1.0, 0.0));
  float c = hash(i + vec2(0.0, 1.0));
  float d = hash(i + vec2(1.0, 1.0));
  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
}

float fbm(vec2 p)
{
  float sum = 0.0;
  float amp = 0.5;
  float total = 0.0;
  for (int k = 0; k < 6; k++) {
    if (float(k) < u_octaves) {
      sum += amp * valueNoise(p);
      total += amp;
    }
    p = p * 2.0 + vec2(5.3, 1.7);
    amp *= 0.5;
  }
  return sum / total;
}

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
  // LÖVE's origin is the top-left: flip y so up is +y, as in the demo
  vec2 pos = vec2(screen_coords.x, u_resolution.y - screen_coords.y);
  vec2 p = (pos - 0.5 * u_resolution) / u_resolution.y * 4.0;
  vec2 s = vec2(p.x / u_stretch, p.y);
  float n = fbm(s + vec2(u_drift, 0.0));

  float t;
  vec3 c0;      // colour at t = 0
  vec3 c1;      // colour at t = 1
  if (u_material < 0.5) {
    t = fract(length(s - vec2(0.0, -2.6)) * 1.5 + 2.0 * n);
    c0 = vec3(0.82, 0.60, 0.36);
    c1 = vec3(0.47, 0.28, 0.14);
  } else if (u_material < 1.5) {
    t = sqrt(abs(sin(2.0 * s.x + s.y + 8.0 * n)));
    c0 = vec3(0.28, 0.30, 0.36);
    c1 = vec3(0.94, 0.93, 0.90);
  } else {
    t = smoothstep(0.35, 0.65, n + 0.1 * s.y);
    c0 = mix(vec3(0.55, 0.75, 0.95), vec3(0.25, 0.47, 0.85), clamp(0.5 + 0.25 * p.y, 0.0, 1.0));
    c1 = vec3(0.97, 0.97, 1.0);
  }
  t = clamp((t - 0.5) * u_contrast + 0.5, 0.0, 1.0);
  return vec4(mix(c0, c1, t), 1.0) * color;
}
]]

function love.load()
  shader = love.graphics.newShader(pixelcode)
end

function love.keypressed(key)
  if key == "1" then material = 0; stretch = 3.0 end
  if key == "2" then material = 1; stretch = 1.5 end
  if key == "3" then material = 2; stretch = 2.0 end
  if key == "up" then octaves = math.min(octaves + 1, 6) end
  if key == "down" then octaves = math.max(octaves - 1, 1) end
  if key == "right" then stretch = math.min(stretch + 0.5, 6.0) end
  if key == "left" then stretch = math.max(stretch - 0.5, 1.0) end
  if key == "a" then contrast = math.min(contrast * 1.25, 4.0) end
  if key == "z" then contrast = math.max(contrast / 1.25, 0.25) end
  if key == "space" then drifting = not drifting end
end

function love.update(dt)
  if drifting then
    drift = (drift + 0.2 * dt) % 64   -- the noise repeats every 64 cells, so wrapping is invisible
  end
end

function love.draw()
  local w, h = love.graphics.getDimensions()
  local pw, ph = love.graphics.getPixelDimensions()
  shader:send("u_resolution", { pw, ph })
  shader:send("u_material", material)
  shader:send("u_octaves", octaves)
  shader:send("u_stretch", stretch)
  shader:send("u_contrast", contrast)
  shader:send("u_drift", drift)
  love.graphics.setShader(shader)
  love.graphics.rectangle("fill", 0, 0, w, h)
  love.graphics.setShader()
end
#ifdef GL_FRAGMENT_PRECISION_HIGH
precision highp float;   // the hash needs 32-bit floats
#else
precision mediump float;
#endif

uniform vec2 u_resolution;
uniform float u_material;  // 0 wood, 1 marble, 2 clouds
uniform float u_octaves;   // how many layers of noise, 1 to 6
uniform float u_stretch;   // 1 = round features, more = longer along x
uniform float u_contrast;  // 1 = unchanged
uniform float u_drift;     // slides the noise; wrapped to 0..64 on the CPU
uniform float u_stage;     // 0 one octave ... 4 final colour

const float PERIOD = 64.0;   // the noise repeats every 64 cells, so the drift can wrap

float hash(vec2 c) {
  c = mod(c, PERIOD);
  return fract(sin(dot(c, vec2(12.9898, 78.233))) * 43758.5453);
}

float valueNoise(vec2 p) {
  vec2 i = floor(p);
  vec2 f = fract(p);
  vec2 u = f * f * (3.0 - 2.0 * f);
  float a = hash(i);
  float b = hash(i + vec2(1.0, 0.0));
  float c = hash(i + vec2(0.0, 1.0));
  float d = hash(i + vec2(1.0, 1.0));
  return mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
}

// fractal Brownian motion: each octave has twice the frequency and half the amplitude
float fbm(vec2 p) {
  float sum = 0.0;
  float amp = 0.5;
  float total = 0.0;
  for (int k = 0; k < 6; k++) {
    if (float(k) < u_octaves) {
      sum += amp * valueNoise(p);
      total += amp;
    }
    p = p * 2.0 + vec2(5.3, 1.7);   // shift so the octaves' grids do not line up
    amp *= 0.5;
  }
  return sum / total;               // back to the 0..1 range
}

// turn the noise into a material's pattern, 0..1
float shape(vec2 s, float n) {
  if (u_material < 0.5) return fract(length(s - vec2(0.0, -2.6)) * 1.5 + 2.0 * n);  // wood rings
  if (u_material < 1.5) return sqrt(abs(sin(2.0 * s.x + s.y + 8.0 * n)));          // marble veins
  return smoothstep(0.35, 0.65, n + 0.1 * s.y);                                       // clouds
}

// colour ramp: dark to light for each material
vec3 ramp(float t, float y) {
  if (u_material < 0.5) return mix(vec3(0.82, 0.60, 0.36), vec3(0.47, 0.28, 0.14), t);
  if (u_material < 1.5) return mix(vec3(0.28, 0.30, 0.36), vec3(0.94, 0.93, 0.90), t);
  vec3 sky = mix(vec3(0.55, 0.75, 0.95), vec3(0.25, 0.47, 0.85), clamp(0.5 + 0.25 * y, 0.0, 1.0));
  return mix(sky, vec3(0.97, 0.97, 1.0), t);
}

void main() {
  vec2 p = (gl_FragCoord.xy - 0.5 * u_resolution) / u_resolution.y * 4.0;  // 4 cells tall, (0, 0) in the centre
  vec2 s = vec2(p.x / u_stretch, p.y);       // 1. stretch along x
  vec2 q = s + vec2(u_drift, 0.0);           //    where the noise is read

  float n1 = valueNoise(q);                  // 2. one octave
  float n = fbm(q);                          // 3. several octaves
  float t = shape(s, n);                     // 4. shape it
  t = clamp((t - 0.5) * u_contrast + 0.5, 0.0, 1.0);   //    contrast around 0.5
  vec3 col = ramp(t, p.y);                   // 5. colour

  if (u_stage < 3.5) col = vec3(t);
  if (u_stage < 2.5) col = vec3(shape(s, 0.5));
  if (u_stage < 1.5) col = vec3(n);
  if (u_stage < 0.5) col = vec3(n1);
  gl_FragColor = vec4(col, 1.0);
}

shader_type canvas_item;

uniform vec2 rect_size = vec2(640.0, 360.0);   // set this to the ColorRect's size
uniform int material_type : hint_range(0, 2) = 0;   // 0 wood, 1 marble, 2 clouds

uniform float stretch : hint_range(1.0, 6.0) = 3.0;
uniform float contrast : hint_range(0.25, 4.0) = 1.0;
uniform float drift_speed = 0.0;               // noise cells per second

float hash(vec2 c) {
    c = mod(c, 64.0);
    return fract(sin(dot(c, vec2(12.9898, 78.233))) * 43758.5453);
}

float value_noise(vec2 p) {
    vec2 i = floor(p);
    vec2 f = fract(p);
    vec2 u = f * f * (3.0 - 2.0 * f);
    return mix(mix(hash(i), hash(i + vec2(1.0, 0.0)), u.x),
               mix(hash(i + vec2(0.0, 1.0)), hash(i + vec2(1.0, 1.0)), u.x), u.y);
}

float fbm(vec2 p) {
    float sum = 0.0;
    float amp = 0.5;
    float total = 0.0;
    for (int k = 0; k < octaves; k++) {   // Godot allows a uniform loop bound
        sum += amp * value_noise(p);
        total += amp;
        p = p * 2.0 + vec2(5.3, 1.7);
        amp *= 0.5;
    }
    return sum / total;
}

void fragment() {
    // UV starts at the top-left with y down: flip y to match the demo.
    vec2 pos = vec2(UV.x, 1.0 - UV.y) * rect_size;
    vec2 p = (pos - 0.5 * rect_size) / rect_size.y * 4.0;
    vec2 s = vec2(p.x / stretch, p.y);
    float n = fbm(s + vec2(mod(TIME * drift_speed, 64.0), 0.0));

    float t;
    vec3 c0;
    vec3 c1;
    if (material_type == 0) {
        t = fract(length(s - vec2(0.0, -2.6)) * 1.5 + 2.0 * n);
        c0 = vec3(0.82, 0.60, 0.36);
        c1 = vec3(0.47, 0.28, 0.14);
    } else if (material_type == 1) {
        t = sqrt(abs(sin(2.0 * s.x + s.y + 8.0 * n)));
        c0 = vec3(0.28, 0.30, 0.36);
        c1 = vec3(0.94, 0.93, 0.90);

            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            float4 _Cells;
            float _Octaves;
            float _Stretch;
            float _Contrast;

            struct v2f
            {
                float4 pos : SV_POSITION;
                float2 uv : TEXCOORD0;

            v2f vert (appdata_base v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = v.texcoord.xy;
                return o;
            }

            float hash (float2 c)
            {
                c = c - 64.0 * floor(c / 64.0);   // GLSL mod; HLSL fmod differs below zero
                return frac(sin(dot(c, float2(12.9898, 78.233))) * 43758.5453);
            }

            float valueNoise (float2 p)
            {
                float2 i = floor(p);
                float2 f = frac(p);
                float2 u = f * f * (3.0 - 2.0 * f);

                float amp = 0.5;
                float total = 0.0;
                for (int k = 0; k < 6; k++)

                    if ((float)k < _Octaves)
                    {
                        sum += amp * valueNoise(p);
                        total += amp;

                    p = p * 2.0 + float2(5.3, 1.7);
                    amp *= 0.5;

HLSL spells mix as lerp and fract as frac. The Unity version shows marble only; the other shaping lines drop in unchanged. In URP Shader Graph, the Simple Noise node is value noise that, according to its documentation, already sums three octaves; follow it with Sine, Absolute and Square Root nodes for marble.

Pitfalls

  • Octaves smaller than a pixel. Once an octave's cells are smaller than about two pixels it adds only shimmer, at full price. The demo's readout shows the finest cell size.
  • Not normalising the sum. Without the divide by total, every threshold you tuned moves when you change the octave count.
  • Grids that line up. With plain p * 2.0 all the grids share a corner at the origin, where a faint cross can appear. Shift or rotate each octave.
  • mediump on phones. By the sixth octave the coordinates are 32 times larger, and the sine hash needs 32-bit floats. Request highp and keep coordinates small, which is why the drift wraps at 64.
  • HLSL fmod is not GLSL mod. For negative numbers fmod keeps the sign, so the left half of the picture would hash differently. Use c - 64.0 * floor(c / 64.0).

What it costs

One octave of value noise is four hashes, which means four sines, plus a few mixes. Five octaves is twenty sines per pixel before any shaping. Fine on a sprite, heavy across a full phone screen of two to three million pixels. If the material does not move, render it once at load time (in LÖVE, into a love.graphics.newCanvas) and draw that instead. Keep the live version for things that change, such as drifting clouds.

In real games

Ken Perlin's 1985 SIGGRAPH paper "An Image Synthesizer" introduced noise and summed octaves of it, and showed marble made by bending a sine with it. The book Texturing and Modeling: A Procedural Approach by Ebert, Musgrave, Peachey, Perlin and Worley collects these recipes, including fBm. The same idea sits behind the octave settings of common noise tools: Godot's FastNoiseLite has an FBM fractal type with octaves, lacunarity and gain, Blender's Noise Texture node has a Detail input, and Adobe Substance 3D Designer builds tiling game materials from graphs of noise and shaping steps. Procedural terrain height maps often start from fBm: big hills with smaller bumps on top.

Takeaways

  • fBm adds octaves of noise, each with twice the frequency and half the amplitude of the last.
  • Divide by the total amplitude so the result stays between 0 and 1 for any octave count.
  • A material is a simple pattern bent by the noise: rings with fract, stripes with sin, or a threshold with smoothstep.
  • Stretch the coordinates for grain and layers; contrast sharpens or softens the result.
  • Each octave costs a full noise evaluation: stop near 2 pixels per cell, and bake materials that never change.
