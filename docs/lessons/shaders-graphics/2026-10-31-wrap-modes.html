Wrap modes: repeat, clamp and mirror

A UV outside 0 to 1 has to land somewhere. Repeat wraps it with fract, clamp pins it to the edge, mirror folds it back. One line of maths each.

You scale a sprite up and a thin line of colour from its opposite edge appears along the border. Or you tile a grass texture and instead of repeating it smears into long streaks. Both come from one sampler setting that decides what a UV of 1.2 or -0.3 means: the wrap mode.

Every UV has to land inside the texture

A fragment shader is a small function that runs once per pixel and returns a colour. When it reads a texture, it hands the sampler a UV. The texture covers 0 to 1, but scaling, scrolling or distorting the UV easily asks for 1.55 or -0.4.

Yesterday a sample was four steps: wrap, multiply by the size, floor, read. The wrap mode is the first step: a rule that maps any number into 0 to 1. It is set separately for u and v, so a texture can repeat sideways and clamp vertically.

The three common modes

  • Repeat. Keep only the part after the point: fract(u). 1.3 becomes 0.3 and -0.3 becomes 0.7. The texture tiles forever.
  • Clamp to edge. Pin the value to the range: clamp(u, 0.0, 1.0). Past the right edge you read the last column, so edge colours stretch into streaks.
  • Mirrored repeat. Tile, but flip every second copy: 1.0 - abs(mod(u, 2.0) - 1.0). 1.3 becomes 0.7. Copies meet edge to matching edge, so the seam never jumps.

Reading the mirror formula: mod(u, 2.0) gives 0 to 2, minus 1 gives -1 to 1, abs folds that into a V from 1 down to 0 and back, and 1.0 - flips the V so it starts at 0.

A fourth mode: clamp to border

Clamp to border returns a fixed border colour, often transparent black, for any UV outside 0 to 1. Desktop OpenGL, Direct3D and Vulkan have it; WebGL 1 and OpenGL ES 2.0 do not. LÖVE has a version called "clampzero"; check its wiki for which systems support it. Unity's import settings and Godot's Repeat property do not list it, so there you test the UV in the shader.

Which way is up

The demo uses v up with (0, 0) at the bottom-left, as WebGL's gl_FragCoord and Unity's UVs do; the red texel marks (0, 0). Godot and LÖVE put (0, 0) at the top-left with v down, so "past the top edge" there means v below 0.

Rule of thumb

Tiling surfaces repeat. Sprites, UI images and colour ramps clamp. Mirror is for textures that were not made to tile but need to.

The code

In LÖVE the wrap mode is a property of the image, set with Image:setWrap(horizontal, vertical). The shader only stretches the UV with the same range as the demo; the sampler does the wrapping. LÖVE shaders use the entry point effect instead of main. Press u or v to cycle the mode on each axis, - and = to change the range, and hover the right panel for a readout made with the same maths on the CPU.

local SIZE = 8                 -- the texture is 8 by 8 texels
local PANEL = 256              -- each panel is 256 by 256 pixels
local T = PANEL / SIZE         -- one texel is 32 pixels on screen
local MODES = { "repeat", "clamp", "mirroredrepeat" }
local wrapU, wrapV = 1, 1      -- index into MODES for each axis
local range = 3                -- texture widths across the surface
local image, shader

local pixelcode = [[
uniform float u_range;

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
  vec2 uv = (texture_coords - 0.5) * u_range + 0.5;  // 0 to 1 stays in the middle
  return Texel(tex, uv) * color;                     // the wrap mode does the rest
}
]]

local function inRange(x, a, b) return x >= a and x <= b end

-- The texture: texel (i, j), i to the right, j up, both 0 to 7.
local function texel(i, j)
  if i == 0 and j == 0 then return 0.9, 0.2, 0.2 end          -- origin marker
  if (inRange(i, 1, 4) and inRange(j, 3, 4)) or (i == 5 and inRange(j, 2, 5))
    or (i == 6 and inRange(j, 3, 4)) then
    return 1, 0.85, 0.25                                      -- arrow pointing right
  end
  if i == 7 then return 0.95, 0.55, 0.2 end                   -- right column
  if j == 7 then return 0.3, 0.75, 0.4 end                    -- top row
  if (i + j) % 2 == 0 then return 0.12, 0.14, 0.24 end
  return 0.2, 0.23, 0.36
end

-- What the sampler does with one coordinate, for the readout.
local function wrap(x, mode)
  if mode == "repeat" then return x - math.floor(x) end      -- fract
  if mode == "clamp" then return math.max(0, math.min(1, x)) end
  local m = x - 2 * math.floor(x / 2)                        -- mod(x, 2)
  return 1 - math.abs(m - 1)                                 -- mirroredrepeat
end

function love.load()
  local data = love.image.newImageData(SIZE, SIZE)
  for j = 0, SIZE - 1 do
    for i = 0, SIZE - 1 do
      local r, g, b = texel(i, j)
      data:setPixel(i, SIZE - 1 - j, r, g, b, 1)   -- image rows go down
    end
  end
  image = love.graphics.newImage(data)
  image:setFilter("nearest", "nearest")
  image:setWrap(MODES[wrapU], MODES[wrapV])
  shader = love.graphics.newShader(pixelcode)
end

function love.keypressed(key)
  if key == "u" then wrapU = wrapU % #MODES + 1 end
  if key == "v" then wrapV = wrapV % #MODES + 1 end
  if key == "=" then range = math.min(5, range + 0.25) end
  if key == "-" then range = math.max(1, range - 0.25) end
  image:setWrap(MODES[wrapU], MODES[wrapV])
end

function love.draw()
  love.graphics.setColor(1, 1, 1)
  love.graphics.draw(image, 20, 20, 0, T)        -- left: the texture as it is
  shader:send("u_range", range)
  love.graphics.setShader(shader)
  love.graphics.draw(image, 300, 20, 0, T)       -- right: the wrapped surface
  love.graphics.setShader()
  love.graphics.print("u: " .. MODES[wrapU] .. "   v: " .. MODES[wrapV] ..
    "   range: " .. range, 20, 290)

  local mx, my = love.mouse.getPosition()
  local su, sv = (mx - 300) / PANEL, (my - 20) / PANEL
  if su >= 0 and su <= 1 and sv >= 0 and sv <= 1 then
    local u = (su - 0.5) * range + 0.5             -- v counts down in LÖVE
    local v = (sv - 0.5) * range + 0.5
    love.graphics.print(string.format("uv (%.2f, %.2f) wraps to (%.2f, %.2f)",
      u, v, wrap(u, MODES[wrapU]), wrap(v, MODES[wrapV])), 20, 310)
  end
end
#ifdef GL_FRAGMENT_PRECISION_HIGH
precision highp float;
#else
precision mediump float;
#endif

uniform vec2 u_resolution;
uniform float u_range;    // texture widths across the surface
uniform vec2 u_wrap;      // mode for u and v: 0 repeat, 1 clamp, 2 mirror, 3 border
uniform vec2 u_probe;     // surface uv of the probe, 0 to 1, y up
uniform float u_stage;    // 0 raw uv ... 3 final colour
uniform float u_grid;     // 1.0 draws tile edges and the 0 to 1 square

const float SIZE = 8.0;   // the texture is 8 by 8 texels

float inRange(float x, float a, float b) {   // 1.0 when a <= x <= b, for whole numbers
  return step(a - 0.5, x) * step(x, b + 0.5);
}

// The texture, made with maths: the colour of texel (i, j), i to the right, j up.
vec3 texel(vec2 ij) {
  vec3 col = mix(vec3(0.12, 0.14, 0.24), vec3(0.2, 0.23, 0.36), mod(ij.x + ij.y, 2.0));
  col = mix(col, vec3(0.3, 0.75, 0.4), inRange(ij.y, 7.0, 7.0));    // top row
  col = mix(col, vec3(0.95, 0.55, 0.2), inRange(ij.x, 7.0, 7.0));   // right column
  float shaft = inRange(ij.x, 1.0, 4.0) * inRange(ij.y, 3.0, 4.0);
  float head = inRange(ij.x, 5.0, 5.0) * inRange(ij.y, 2.0, 5.0)
             + inRange(ij.x, 6.0, 6.0) * inRange(ij.y, 3.0, 4.0);
  col = mix(col, vec3(1.0, 0.85, 0.25), shaft + head);              // arrow pointing right
  col = mix(col, vec3(0.9, 0.2, 0.2), inRange(ij.x, 0.0, 0.0) * inRange(ij.y, 0.0, 0.0));
  return col;
}

// Step 1 of a sample: bring one coordinate into 0 to 1.
float wrapCoord(float x, float mode) {
  if (mode < 0.5) return fract(x);                        // repeat
  if (mode < 1.5) return clamp(x, 0.0, 1.0);              // clamp to edge
  if (mode < 2.5) return 1.0 - abs(mod(x, 2.0) - 1.0);    // mirrored repeat
  return x;                                               // border: tested by onBorder
}

vec2 wrapUv(vec2 uv) {
  return vec2(wrapCoord(uv.x, u_wrap.x), wrapCoord(uv.y, u_wrap.y));
}

float outside(float x) {                  // 1.0 when x is outside 0 to 1
  return 1.0 - step(0.0, x) * step(x, 1.0);
}

float onBorder(vec2 uv) {                 // 1.0 when a border axis is outside
  return max(step(2.5, u_wrap.x) * outside(uv.x), step(2.5, u_wrap.y) * outside(uv.y));
}

// Steps 2 and 3: scale to texels and floor.
vec2 texelIndex(vec2 w) {
  return clamp(floor(w * SIZE), 0.0, SIZE - 1.0);
}

vec3 emptyColour(vec2 px, float lw) {      // a grey checker for "transparent"
  float c = mod(floor(px.x / (6.0 * lw)) + floor(px.y / (6.0 * lw)), 2.0);
  return mix(vec3(0.18), vec3(0.26), c);
}

float boxEdge(vec2 p, vec2 lo, vec2 hi) {           // distance to the outline of a box
  vec2 q = abs(p - 0.5 * (lo + hi)) - 0.5 * (hi - lo);
  return abs(length(max(q, 0.0)) + min(max(q.x, q.y), 0.0));
}

vec3 drawLine(vec3 col, float d, float lw, vec3 ink) {  // d and lw in pixels
  col = mix(col, vec3(0.0), 1.0 - smoothstep(lw, 2.0 * lw, d));
  return mix(col, ink, 1.0 - smoothstep(0.3 * lw, lw, d));
}

float gridShade(vec2 p, float cellPx, float lw) {   // 1.0 on a cell edge
  vec2 f = fract(p);
  vec2 e = min(f, 1.0 - f) * cellPx;                // to the nearest edge, pixels
  return 1.0 - smoothstep(0.0, lw, min(e.x, e.y));
}

void main() {
  vec2 res = u_resolution;
  float m = 0.06 * res.y;                                         // margin, pixels
  float S = min(res.y - 2.0 * m, 0.5 * (res.x - 3.0 * m));        // panel size, pixels
  vec2 a0 = vec2(0.5 * (res.x - 2.0 * S - m), 0.5 * (res.y - S)); // texture panel
  vec2 b0 = a0 + vec2(S + m, 0.0);                                // surface panel
  float lw = max(1.0, res.y / 300.0);                             // line width, pixels
  vec2 px = gl_FragCoord.xy;                                      // origin bottom-left, y up
  vec3 col = vec3(0.1, 0.11, 0.13);
  vec3 white = vec3(1.0);
  vec3 cyan = vec3(0.3, 0.9, 1.0);

  vec2 probeUv = (u_probe - 0.5) * u_range + 0.5;   // the uv the probe pixel asks for
  vec2 pw = wrapUv(probeUv);                        // where the wrap mode sends it
  vec2 pij = texelIndex(pw);                        // the texel it reads
  float pBorder = onBorder(probeUv);

  // Left panel: the texture itself, uv 0 to 1 on both axes.
  vec2 t = (px - a0) / S;
  if (t.x >= 0.0 && t.x <= 1.0 && t.y >= 0.0 && t.y <= 1.0) {
    col = texel(texelIndex(t));
    if (u_grid > 0.5) col = mix(col, vec3(0.0), 0.5 * gridShade(t * SIZE, S / SIZE, lw));
    if (pBorder < 0.5) {
      col = drawLine(col, boxEdge(t, pij / SIZE, (pij + 1.0) / SIZE) * S, lw, white);
      col = drawLine(col, abs(length(t - pw) * S - 3.0 * lw), lw, white);
    }
  }

  // Right panel: the surface. Its uv runs past both edges of the texture.
  vec2 s = (px - b0) / S;
  if (s.x >= 0.0 && s.x <= 1.0 && s.y >= 0.0 && s.y <= 1.0) {
    vec2 uv = (s - 0.5) * u_range + 0.5;    // the 0 to 1 square sits in the middle
    vec2 w = wrapUv(uv);
    vec2 ij = texelIndex(w);
    vec3 c = texel(ij);
    if (u_stage < 2.5) c = vec3(ij / (SIZE - 1.0), 0.0);
    if (u_stage < 1.5) c = vec3(w, 0.0);
    if (u_stage < 0.5) c = vec3(uv, 0.0);
    if (u_stage > 0.5) c = mix(c, emptyColour(px, lw), onBorder(uv));
    col = c;
    if (u_grid > 0.5) {
      col = mix(col, white, 0.6 * gridShade(uv, S / u_range, 0.7 * lw));   // tile edges
      col = drawLine(col, boxEdge(uv, vec2(0.0), vec2(1.0)) * S / u_range, lw, cyan);
    }
    col = drawLine(col, abs(length(s - u_probe) * S - 3.0 * lw), lw, white);
  }

  col = mix(col, vec3(0.45), 1.0 - smoothstep(0.0, lw, boxEdge(px, a0, a0 + S)));
  col = mix(col, vec3(0.45), 1.0 - smoothstep(0.0, lw, boxEdge(px, b0, b0 + S)));
  gl_FragColor = vec4(col, 1.0);
}
// Godot 4. Put this in a ShaderMaterial on a Sprite2D. The easy way is to skip
// the maths: set CanvasItem > Texture > Repeat to Enabled or Mirror. This
// version does the wrap itself, so it can mix modes per axis.
shader_type canvas_item;

uniform float uv_range = 3.0;   // texture widths across the sprite
uniform int wrap_u = 0;         // 0 repeat, 1 clamp, 2 mirror
uniform int wrap_v = 0;

float wrap_coord(float x, int mode) {
    if (mode == 0) { return fract(x); }
    if (mode == 1) { return clamp(x, 0.0, 1.0); }
    return 1.0 - abs(mod(x, 2.0) - 1.0);
}

void fragment() {
    vec2 uv = (UV - 0.5) * uv_range + 0.5;   // UV (0, 0) is the top-left in Godot
    uv = vec2(wrap_coord(uv.x, wrap_u), wrap_coord(uv.y, wrap_v));
    COLOR = texture(TEXTURE, uv);
}
// Built-in render pipeline, unlit. The easy way is the texture's import
// setting Wrap Mode (Repeat, Clamp, Mirror, Mirror Once, or Per-axis).
// This version does the wrap itself, so a material can choose per axis.
Shader "GameDevDaily/WrapModes"
{
    Properties
    {
        _MainTex ("Texture", 2D) = "white" {}
        _Range ("UV range", Float) = 3
        _WrapU ("Wrap u (0 repeat, 1 clamp, 2 mirror)", Float) = 0
        _WrapV ("Wrap v (0 repeat, 1 clamp, 2 mirror)", Float) = 0
    }
    SubShader
    {
        Tags { "RenderType" = "Opaque" }
        Pass
        {
            CGPROGRAM
            #pragma vertex vert_img
            #pragma fragment frag
            #include "UnityCG.cginc"

            sampler2D _MainTex;
            float _Range;
            float _WrapU;
            float _WrapV;

            float wrapCoord(float x, float mode)
            {
                if (mode < 0.5) return frac(x);
                if (mode < 1.5) return saturate(x);
                float m = x - 2.0 * floor(x / 2.0);   // not fmod: it differs below 0
                return 1.0 - abs(m - 1.0);
            }

            fixed4 frag (v2f_img i) : SV_Target
            {
                float2 uv = (i.uv - 0.5) * _Range + 0.5;   // (0, 0) is the bottom-left
                uv = float2(wrapCoord(uv.x, _WrapU), wrapCoord(uv.y, _WrapV));
                return tex2D(_MainTex, uv);
            }
            ENDCG
        }
    }
}

vert_img and v2f_img come from UnityCG.cginc and pass the mesh UV straight through. In URP or Shader Graph, set the mode on the texture asset, or build the same maths from Fraction, Saturate, Absolute and Floor nodes before the UV input of Sample Texture 2D.

Pitfalls

  • The opposite edge bleeding in. Linear filtering blends the four nearest texels. At the border of a repeating texture some of those come from the far side, so a sprite gets a faint line of its opposite edge. Sprites and UI images should clamp.
  • Clamp streaks. Clamp copies the outermost texels forever. If the edge is not a plain colour, distortion or scrolling past it shows streaks. Leave a one texel margin of background colour.
  • fmod is not mod. GLSL's mod(x, y) is x - y * floor(x / y) and is never negative for positive y. HLSL's fmod keeps the sign of x, so fmod(-0.3, 2.0) is -0.3 and the mirror breaks below 0. Write the floor version yourself, as in the Unity tab.
  • Non-power-of-two textures in WebGL 1. A texture whose sides are not powers of two (such as 100 by 60) must use clamp to edge and no mipmaps there; otherwise it samples as black. WebGL 2 lifts this rule.
  • A line at the seam when you wrap by hand. The GPU picks a mipmap level from how fast the UV changes between neighbouring pixels. Where fract jumps from 1 to 0 that change looks huge, so a thin line of the smallest mipmap can appear along the seam. Prefer the sampler's own wrap mode, or turn mipmaps off for that texture.

What it costs

The texture hardware applies the wrap mode as part of every read, so repeat, clamp and mirror cost nothing extra, on a phone or anywhere else. Wrapping by hand, as in the Godot and Unity tabs, adds a few arithmetic instructions per pixel: cheap, but not free, and it brings the seam problem above. Use it only when the hardware modes cannot do what you need.

In real games

Floors, walls, terrain and water repeat, which is why tiling textures are painted so the left edge matches the right. Sprites, fonts and UI panels clamp to keep their edges clean, and so do colour ramps, where reading past the end should give the last colour, not the first.

Defaults differ. LÖVE images start with "clamp". Godot 4's canvas items inherit their repeat setting from the parent node, and at the top of the tree that defaults to Disabled. Unity imports textures of the Default type with Wrap Mode set to Repeat. When a texture behaves differently after moving it between engines, check this setting first.

Your turn (15 minutes)

Use the LÖVE example to see the edge bleed for yourself, then add a mode by hand.

  1. Set range = 1 and change the filter to image:setFilter("linear", "linear"). Look closely at the left edge of the right panel with repeat on u: a soft orange fringe from the far column appears. Press u to clamp and watch it go.
  2. Add Unity's "mirror once" to the shader by hand: mirror once around 0, then clamp. In effect, add the line uv.x = clamp(abs(uv.x), 0.0, 1.0); before the Texel call.

Before you run it, predict on paper what u = -0.4 and u = 1.6 become. You are done when, at range 3, you see two arrows pointing away from each other with flat orange to their right, and at range 5 flat orange on both sides.

Takeaways

  • The wrap mode is the first step of every sample: it maps any UV into 0 to 1.
  • Repeat is fract(u), clamp to edge is clamp(u, 0.0, 1.0), mirrored repeat is 1.0 - abs(mod(u, 2.0) - 1.0).
  • Each axis has its own mode, and the sampler applies it in hardware at no extra cost.
  • Repeat for tiling surfaces, clamp for sprites, UI and ramps, mirror for textures that do not tile.
  • Engines differ in defaults, in which corner is (0, 0) and in how mod treats negatives.
