Palette swap on the GPU: recolouring sprites with a lookup

Store slot numbers instead of colours in a sprite, look each one up in a small palette texture, and one image becomes every team colour.

Your soldier needs a red team, a blue team and a purple elite version. Saving a recoloured copy of every animation frame triples the art, and every fix to one frame has to be made three times. A palette swap keeps one sprite and moves the colours into a tiny table that the shader reads from.

The sprite stores slots, not colours

A fragment shader is a small function that runs once per pixel and returns a colour. In a palette swap, the sprite it reads does not hold the final colours. Each pixel holds a slot: a small number that means "outline", "cloth", "skin" and so on. A sprite drawn this way is an index sprite. Our soldier uses six slots, 0 to 5.

The colours live in a second image, the palette texture: one column per slot and one row per palette, six by five texels (a texel is one pixel of a texture). Recolouring the soldier means choosing a different row; a new team is one more row.

Turning a slot into a texture coordinate

The slot is stored as a grey level in the red channel, chosen so that it lands in the centre of its palette column:

r = (slot + 0.5) / 6        -- slot 3 is stored as 0.583

Texture coordinates run from 0 to 1, so 0.583 is halfway across column 3. Rows work the same way: v = (row + 0.5) / 5. Aiming at texel centres keeps rounding errors from tipping a read into the neighbour.

The shader, one line per stage

In LÖVE the whole effect is four lines, one per stage of the demo:

vec4 texel = Texel(tex, texture_coords);                  // 1. which slot?
vec2 lookup = vec2(texel.r, (u_rowA + 0.5) / ROWS);       // 2. slot, row -> u, v
vec3 a = Texel(palette, lookup).rgb;                      // 3. its colour
return vec4(mix(a, b, u_blend), texel.a);                 // 4. b is row B

Line 3 is a dependent texture read: its coordinate comes from another read, so it must wait for that one. Alpha comes from the index sprite, so transparent pixels stay transparent.

Blend colours, never slots

To fade from blue to red, read both rows and mix the two colours. Never mix slot numbers: halfway between slot 1 and slot 3 is slot 2, a different part of the sprite. That fact also explains the most common bug.

Which row is row 0

In LÖVE and Godot, v = 0 is the top row of the image, as in a paint program. Unity puts v = 0 at the bottom, so its code uses 1.0 - (row + 0.5) / rows. The demo's gl_FragCoord starts at the canvas's bottom-left with y up; its palette keeps row 0 at the top, like LÖVE.

The code

The LÖVE program builds both images in code and draws the soldier eight times larger. Press 1 to 5 to fade to that row. Palettes, sprite and maths match the demo.

local COLUMNS, ROWS = 6, 5               -- slots per palette, palettes
local SPRITE_W, SPRITE_H = 16, 20
local FADE_TIME = 0.5                    -- seconds for a palette change
local rowA, rowB, blend = 0, 1, 0
local fading = false
local sprite, palette, shader

local PALETTES = {                       -- one row per palette, one colour per slot
  { "1a1729", "213d8c", "386bdb", "75abff", "facca3", "fac738" },  -- 0 Blue
  { "2a1217", "8c1c24", "db3b38", "ff8573", "facca3", "f2f2e0" },  -- 1 Red
  { "122112", "2e6129", "4f9940", "8fd166", "cc9970", "8c5926" },  -- 2 Forest
  { "0d0a14", "331f4d", "5c3585", "8f63c2", "b8b3d1", "eb385c" },  -- 3 Elite
  { "0f380f", "306230", "8bac0f", "9bbc0f", "9bbc0f", "306230" },  -- 4 Four greens
}

local pixelcode = [[
uniform Image palette;
uniform float u_rowA;
uniform float u_rowB;
uniform float u_blend;
const float ROWS = 5.0;

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
  vec4 texel = Texel(tex, texture_coords);    // r = (slot + 0.5) / 6
  vec3 a = Texel(palette, vec2(texel.r, (u_rowA + 0.5) / ROWS)).rgb;
  vec3 b = Texel(palette, vec2(texel.r, (u_rowB + 0.5) / ROWS)).rgb;
  return vec4(mix(a, b, u_blend), texel.a) * color;
}
]]

local function hex(s)
  return tonumber(s:sub(1, 2), 16) / 255, tonumber(s:sub(3, 4), 16) / 255,
         tonumber(s:sub(5, 6), 16) / 255
end

local function len(x, y) return math.sqrt(x * x + y * y) end

local function box(x, y, bx, by)          -- signed distance to a box at 0, 0
  local qx, qy = math.abs(x) - bx, math.abs(y) - by
  return len(math.max(qx, 0), math.max(qy, 0)) + math.min(math.max(qx, qy), 0)
end

-- the slot of one sprite pixel, y measured up from the bottom; nil = transparent
local function spriteIndex(x, y)
  local head = len(x - 8, y - 15.5) - 5
  if head <= 0 then
    if head > -1 then return 0 end
    if len(x - 6.5, y - 14.5) < 0.6 or len(x - 9.5, y - 14.5) < 0.6 then return 0 end
    if math.abs(y - 16.5) < 0.6 then return 5 end
    if y > 17 then return x < 7 and 3 or 2 end
    return 4
  end
  local body = box(x - 8, y - 7, 3, 3) - 1.5
  local feet = math.min(box(x - 5.5, y - 1.5, 1.5, 1.5), box(x - 10.5, y - 1.5, 1.5, 1.5))
  local hands = math.min(len(x - 2.5, y - 5.5), len(x - 13.5, y - 5.5)) - 1.6
  local d = math.min(body, feet, hands)
  if d > 0 then return nil end
  if d > -1 then return 0 end
  if hands <= -1 then return 4 end
  if body > -1 then return 1 end
  if math.abs(y - 6.5) < 0.6 then return 5 end
  if x < 6 then return 3 end
  if x > 10 then return 1 end
  return 2
end

function love.load()
  local data = love.image.newImageData(SPRITE_W, SPRITE_H)   -- starts transparent
  for y = 0, SPRITE_H - 1 do
    for x = 0, SPRITE_W - 1 do
      local slot = spriteIndex(x + 0.5, SPRITE_H - y - 0.5)  -- image rows count down
      if slot then
        local grey = (slot + 0.5) / COLUMNS
        data:setPixel(x, y, grey, grey, grey, 1)
      end
    end
  end
  sprite = love.graphics.newImage(data)
  sprite:setFilter("nearest", "nearest")

  local pal = love.image.newImageData(COLUMNS, ROWS)
  for row = 1, ROWS do
    for col = 1, COLUMNS do
      local r, g, b = hex(PALETTES[row][col])
      pal:setPixel(col - 1, row - 1, r, g, b, 1)
    end
  end
  palette = love.graphics.newImage(pal)
  palette:setFilter("nearest", "nearest")

  shader = love.graphics.newShader(pixelcode)
  shader:send("palette", palette)
end

function love.keypressed(key)
  local n = tonumber(key)
  if n and n >= 1 and n <= ROWS and not fading then
    rowB = n - 1                         -- fade towards this row
    fading = true
  end
end

function love.update(dt)
  if fading then
    blend = math.min(blend + dt / FADE_TIME, 1)
    if blend >= 1 then
      rowA, blend, fading = rowB, 0, false   -- the new palette is now the current one
    end
  end
end

function love.draw()
  local w, h = love.graphics.getDimensions()
  love.graphics.clear(0.28, 0.30, 0.36)
  shader:send("u_rowA", rowA)
  shader:send("u_rowB", rowB)
  shader:send("u_blend", blend)
  love.graphics.setShader(shader)
  love.graphics.draw(sprite, w / 2 - 64, h / 2 - 80, 0, 8, 8)
  love.graphics.setShader()
end
precision mediump float;

uniform vec2 u_resolution;
uniform float u_rowA;    // palette row for A (row 0 = top row of the palette image)
uniform float u_rowB;    // palette row for B
uniform float u_blend;   // 0 = all A, 1 = all B
uniform float u_linear;  // 1 = linear filtering on the index sprite (the mistake)
uniform float u_stage;   // 0 stored index, 1 lookup (u, v), 2 palette A only, 3 final
uniform vec2 u_probe;    // demo only: the probed point, in sprite pixels

const vec2 SPRITE_SIZE = vec2(16.0, 20.0);   // the index sprite, in pixels
const float COLUMNS = 6.0;                   // colour slots per palette
const float ROWS = 5.0;                      // palettes in the palette image
const float PIXEL = 0.042;                   // one sprite pixel, in canvas heights

float sdBox(vec2 p, vec2 b) {
  vec2 q = abs(p) - b;
  return length(max(q, 0.0)) + min(max(q.x, q.y), 0.0);
}

// The art: which slot (0 to 5) one sprite pixel uses, or -1.0 if transparent. y is up.
float spriteIndex(vec2 sp) {
  float head = length(sp - vec2(8.0, 15.5)) - 5.0;
  if (head <= 0.0) {
    if (head > -1.0) return 0.0;                                     // outline
    if (length(sp - vec2(6.5, 14.5)) < 0.6 || length(sp - vec2(9.5, 14.5)) < 0.6) return 0.0;  // eyes
    if (abs(sp.y - 16.5) < 0.6) return 5.0;                          // cap band
    if (sp.y > 17.0) return sp.x < 7.0 ? 3.0 : 2.0;                  // cap, lit on the left
    return 4.0;                                                      // face
  }
  float body = sdBox(sp - vec2(8.0, 7.0), vec2(3.0)) - 1.5;
  float feet = min(sdBox(sp - vec2(5.5, 1.5), vec2(1.5)), sdBox(sp - vec2(10.5, 1.5), vec2(1.5)));
  float hands = min(length(sp - vec2(2.5, 5.5)), length(sp - vec2(13.5, 5.5))) - 1.6;
  float d = min(min(body, feet), hands);
  if (d > 0.0) return -1.0;               // outside: transparent
  if (d > -1.0) return 0.0;               // outline
  if (hands <= -1.0) return 4.0;          // hands
  if (body > -1.0) return 1.0;            // boots
  if (abs(sp.y - 6.5) < 0.6) return 5.0;  // belt
  if (sp.x < 6.0) return 3.0;             // lit side
  if (sp.x > 10.0) return 1.0;            // shaded side
  return 2.0;                             // cloth
}

// One texel of the index sprite as (r, a). The grey stores r = (slot + 0.5) / COLUMNS.
vec2 indexTexel(vec2 cell) {
  if (cell.x < 0.0 || cell.y < 0.0 || cell.x >= SPRITE_SIZE.x || cell.y >= SPRITE_SIZE.y) return vec2(0.0);
  float slot = spriteIndex(cell + 0.5);
  if (slot < 0.0) return vec2(0.0);
  return vec2((slot + 0.5) / COLUMNS, 1.0);
}

// Stands in for reading the index texture, with nearest or linear filtering.
vec2 sampleIndex(vec2 sp) {
  if (u_linear < 0.5) return indexTexel(floor(sp));
  vec2 t = sp - 0.5;
  vec2 c = floor(t);
  vec2 f = t - c;
  vec2 bottom = mix(indexTexel(c), indexTexel(c + vec2(1.0, 0.0)), f.x);
  vec2 top = mix(indexTexel(c + vec2(0.0, 1.0)), indexTexel(c + vec2(1.0, 1.0)), f.x);
  return mix(bottom, top, f.y);
}

vec3 pick(float i, vec3 c0, vec3 c1, vec3 c2, vec3 c3, vec3 c4, vec3 c5) {
  vec3 c = c0;
  if (i > 0.5) c = c1;
  if (i > 1.5) c = c2;
  if (i > 2.5) c = c3;
  if (i > 3.5) c = c4;
  if (i > 4.5) c = c5;
  return c;
}

// The palette image: 6 columns (slots) by 5 rows (palettes), row 0 at the top.
vec3 paletteTexel(float col, float row) {
  if (row < 0.5) return pick(col,   // row 0: Blue
    vec3(0.102, 0.090, 0.161), vec3(0.129, 0.239, 0.549), vec3(0.220, 0.420, 0.859),
    vec3(0.459, 0.671, 1.000), vec3(0.980, 0.800, 0.639), vec3(0.980, 0.780, 0.220));
  if (row < 1.5) return pick(col,   // row 1: Red
    vec3(0.165, 0.071, 0.090), vec3(0.549, 0.110, 0.141), vec3(0.859, 0.231, 0.220),
    vec3(1.000, 0.522, 0.451), vec3(0.980, 0.800, 0.639), vec3(0.949, 0.949, 0.878));
  if (row < 2.5) return pick(col,   // row 2: Forest
    vec3(0.071, 0.129, 0.071), vec3(0.180, 0.380, 0.161), vec3(0.310, 0.600, 0.251),
    vec3(0.561, 0.820, 0.400), vec3(0.800, 0.600, 0.439), vec3(0.549, 0.349, 0.149));
  if (row < 3.5) return pick(col,   // row 3: Elite
    vec3(0.051, 0.039, 0.078), vec3(0.200, 0.122, 0.302), vec3(0.361, 0.208, 0.522),
    vec3(0.561, 0.388, 0.761), vec3(0.722, 0.702, 0.820), vec3(0.922, 0.220, 0.361));
  return pick(col,                  // row 4: Four greens
    vec3(0.059, 0.220, 0.059), vec3(0.188, 0.384, 0.188), vec3(0.545, 0.675, 0.059),
    vec3(0.608, 0.737, 0.059), vec3(0.608, 0.737, 0.059), vec3(0.188, 0.384, 0.188));
}

// Stands in for reading the palette texture: nearest filtering, clamp to edge.
// v = 0 is the top of the image, as in LOVE and Godot.
vec3 samplePalette(vec2 uv) {
  vec2 t = clamp(floor(uv * vec2(COLUMNS, ROWS)), vec2(0.0), vec2(COLUMNS - 1.0, ROWS - 1.0));
  return paletteTexel(t.x, t.y);
}

void main() {
  vec2 p = (gl_FragCoord.xy - 0.5 * u_resolution) / u_resolution.y;   // (0, 0) centre, y up
  vec2 tile = floor(p * 8.0);
  vec3 bg = mix(vec3(0.28, 0.30, 0.36), vec3(0.32, 0.34, 0.40), mod(tile.x + tile.y, 2.0));
  vec2 sp = (p + 0.5 * SPRITE_SIZE * PIXEL) / PIXEL;   // sprite pixels, (0, 0) bottom-left

  vec2 texel = sampleIndex(sp);                          // 1. read the index sprite: (r, a)
  vec2 lookupA = vec2(texel.x, (u_rowA + 0.5) / ROWS);   // 2. r becomes u, the row becomes v
  vec2 lookupB = vec2(texel.x, (u_rowB + 0.5) / ROWS);
  vec3 a = samplePalette(lookupA);                       // 3. read the palette
  vec3 b = samplePalette(lookupB);
  vec3 rgb = mix(a, b, u_blend);                         // 4. blend colours, never slots

  if (u_stage < 2.5) rgb = a;
  if (u_stage < 1.5) rgb = vec3(lookupA, 0.0);
  if (u_stage < 0.5) rgb = vec3(texel.x);
  vec3 col = mix(bg, rgb, texel.y);                      // alpha comes from the index sprite

  // demo only: a ring around the probe
  if (abs(length(sp - u_probe) - 0.45) < 0.1) col = vec3(1.0, 0.3, 0.6);
  gl_FragColor = vec4(col, 1.0);
}
// Godot 4, a ShaderMaterial on a Sprite2D whose texture is the index sprite.
// Set the Sprite2D's Texture Filter to Nearest.
shader_type canvas_item;

uniform sampler2D palette : filter_nearest, repeat_disable;
uniform float row_a = 0.0;
uniform float row_b = 1.0;
uniform float blend : hint_range(0.0, 1.0) = 0.0;
const float ROWS = 5.0;

void fragment() {
    vec4 texel = texture(TEXTURE, UV);   // r = (slot + 0.5) / 6
    // Godot's UV v = 0 is the top row, like LÖVE: row 0 is the top of the palette image
    vec3 a = texture(palette, vec2(texel.r, (row_a + 0.5) / ROWS)).rgb;
    vec3 b = texture(palette, vec2(texel.r, (row_b + 0.5) / ROWS)).rgb;
    COLOR = vec4(mix(a, b, blend), texel.a);
}

// Built-in render pipeline, for a SpriteRenderer whose sprite is the index sprite.
Shader "GameDevDaily/PaletteSwapSprite"
{
    Properties
    {
        [PerRendererData] _MainTex ("Index sprite", 2D) = "white" {}
        _PaletteTex ("Palette", 2D) = "white" {}
        _Rows ("Rows in the palette", Float) = 5
        _RowA ("Palette A row", Float) = 0
        _RowB ("Palette B row", Float) = 1
        _Blend ("Blend", Range(0, 1)) = 0
    }
    SubShader
    {
        Tags { "Queue" = "Transparent" "RenderType" = "Transparent" "IgnoreProjector" = "True" }
        Cull Off
        ZWrite Off
        Blend SrcAlpha OneMinusSrcAlpha

        Pass
        {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            sampler2D _MainTex;
            sampler2D _PaletteTex;
            float _Rows;
            float _RowA;
            float _RowB;
            float _Blend;

            struct appdata
            {
                float4 vertex : POSITION;
                float2 uv : TEXCOORD0;
                float4 color : COLOR;
            };

            struct v2f
            {
                float4 pos : SV_POSITION;
                float2 uv : TEXCOORD0;
                float4 color : COLOR;
            };

            v2f vert (appdata v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = v.uv;
                o.color = v.color;
                return o;
            }

            float4 frag (v2f i) : SV_Target
            {
                float4 texel = tex2D(_MainTex, i.uv);    // r = (slot + 0.5) / 6
                // Unity's v = 0 is the BOTTOM row of the image: count rows from the top
                float vA = 1.0 - (_RowA + 0.5) / _Rows;
                float vB = 1.0 - (_RowB + 0.5) / _Rows;
                float3 a = tex2D(_PaletteTex, float2(texel.r, vA)).rgb;
                float3 b = tex2D(_PaletteTex, float2(texel.r, vB)).rgb;
                return float4(lerp(a, b, _Blend), texel.a) * i.color;
            }
            ENDCG
        }
    }
}

The demo emulates both textures with maths, since the page has no image files. In Unity, set both textures to Filter Mode Point, Compression None, no mipmaps, and untick sRGB (Color Texture) on the index sprite only. In Godot, keep compression lossless and mipmaps off. For URP, use a Sprite Unlit Shader Graph: Sample Texture 2D on the sprite, its R and the row into a Vector 2, a second Sample Texture 2D on the palette with a Point Sampler State, two lookups into a Lerp for Base Color, and the sprite's alpha into Alpha.

Pitfalls

  • Filtering the index sprite. Linear filtering and mipmaps average neighbouring greys, and an averaged slot is a different slot. Use nearest filtering and no mipmaps; if you need smooth scaling, scale the coloured result in a second pass.
  • Lossy compression. Block compression shifts greys a few levels. Six slots tolerate it; with 64 slots each column is four grey levels wide. Store index sprites uncompressed.
  • The index sprite treated as a colour. Marked as sRGB, the grey is converted to linear on read: 0.583 arrives as about 0.30, slot 1. Untick sRGB in Unity; in LÖVE with gamma-correct rendering, pass { linear = true } to newImage. The palette is colour and keeps the normal setting.
  • Aiming at texel edges. Storing slot / 6 lands on column borders, where a tiny error picks the neighbour.
  • The row upside down. In Unity, row 0 read without the flip gives the last palette.

What it costs

Very little, even on a phone. Each pixel does two or three texture reads, and a 6 by 5 palette stays in the cache. Some older mobile GPUs ran dependent reads noticeably slower; current ones handle a few per pixel easily. The win is memory: five teams cost one sprite sheet plus 30 texels. Making slot 0 transparent lets the index sprite use a single 8-bit channel, a quarter of an RGBA sheet.

In real games

This is how 8-bit and 16-bit consoles drew everything: tiles stored slot numbers and the video hardware looked them up in palette memory. On the NES, each sprite uses one of four palettes of three colours plus transparent. Swapping a palette cost almost nothing, so many characters of that era are recolours: in the original Super Mario Bros., Luigi is Mario with a different palette, and fighting games such as Street Fighter II give the second player of a mirror match alternate colours. Modern GPUs have no palette hardware, so the shader in this lesson rebuilds it with a texture.

Your turn (15 minutes)

Give the soldier a "poisoned" look that comes and goes.

  1. Add a sixth row to PALETTES: copy the blue row and change the skin slot (4) to a sickly green, such as "9fd36a". Set ROWS = 6 in Lua and const float ROWS = 6.0; in the shader.
  2. Add local poisoned = false. In love.keypressed, toggle it with the P key, set blend = 0 when it turns off, and ignore the number keys while it is on.
  3. In love.update, while poisoned is true, set rowB = 5 and blend = 0.5 + 0.5 * math.sin(love.timer.getTime() * 4).

You are done when pressing P makes only the face and hands pulse green while the cap, cloth and belt keep their colours, and pressing P again stops it.

Takeaways

  • An index sprite stores a slot per pixel; a small palette texture stores one row of colours per palette.
  • The shader reads the slot, uses it as u and the palette row as v, and reads the palette again: a dependent texture read.
  • Store (slot + 0.5) / slots and use (row + 0.5) / rows so every read lands in a texel's centre.
  • Blend looked-up colours, never slots; so the index sprite needs nearest filtering, no mipmaps, no lossy compression and no sRGB conversion.
