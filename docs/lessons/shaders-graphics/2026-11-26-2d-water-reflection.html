2D water: a mirrored, wobbling reflection

Flip the scene about the waterline, nudge the lookup with moving waves, then tint it: three steps turn any 2D scene into reflective water.

A lake in a side-view game looks dead if it is a flat blue rectangle. The water that feels alive shows a wobbling, darkened copy of the hut, the trees and the sunset above it. Nobody draws that copy by hand: one shader makes it from the picture that is already on screen.

Water is a picture of the scene, read upside down

A fragment shader is a small function that runs once per pixel and returns a colour. For a water pixel, the question is: which colour from the scene above should I show? The answer has three parts, and each one is a line or two of code.

1. Mirror: read the point the same distance above the line

Call the height of the water's surface the waterline. A pixel below it is some distance d under the line. A still lake shows what is the same distance above the line, at the same x. That is the whole mirror:

float d = uv.y - waterLine;            // how far below the line (negative above it)
vec2 r = vec2(uv.x, waterLine - d);    // the point to read: d above the line

Here uv runs from 0 at the top of the screen to 1 at the bottom, as texture coordinates do in LÖVE and Godot. The shader reads the finished scene as a texture at r, so pixels just under the line show things just above it, and the bottom of the screen shows the sky.

2. Wobble: move the read point with a wave

A perfect mirror looks like glass. Real water bends the reflection, and we already know how to bend things: add a wave to the coordinates before reading. This is UV distortion, and making the wave's phase depend on time scrolls it:

float wave = sin(d * 90.0 - t * 3.0) * 0.6 + sin(uv.x * 20.0 + d * 40.0 + t * 2.0) * 0.4;
float calm = clamp(d * 12.0, 0.0, 1.0);
vec2 offset = vec2(wave, 0.5 * wave) * waveHeight * calm;

Here t is time multiplied by a speed. The first sine makes horizontal bands that travel downwards, towards the viewer. The second adds a slanted pattern so the bands do not look like a ruler. wave stays between -1 and 1, and waveHeight scales it into UV units, so 0.01 means one hundredth of the screen.

calm is the detail that sells it. It is 0 at the waterline and reaches 1 a short way down. Without it, the reflection right at the shore jumps around and splits away from the object it reflects. With it, the hut's reflection stays attached to the hut and only ripples further out. It also keeps the vertical part of the offset smaller than d, so the read point never crosses the waterline and the water never reflects itself.

3. Tint: water is not a mirror

Water absorbs light and has its own colour. mix(reflection, waterColor, tint) pulls the reflection towards that colour, and darkening with depth makes the far edge of the lake read as deeper. A thin bright line right at the waterline gives the surface an edge.

Which way is down

WebGL's gl_FragCoord has (0, 0) at the bottom-left with y up, so the demo flips it first: uv.y = 1.0 - uv.y. After that, its formulas are the same as the LÖVE and Godot versions, where texture coordinates and SCREEN_UV have (0, 0) at the top-left with y down. Unity's texture UVs have (0, 0) at the bottom-left with y up, so in the Unity tab d = waterLine - uv.y and the mirror adds d instead of subtracting it.

Try it

Step through Stage first. Stage 2 colours each pixel by the coordinate it reads: the gradient below the yellow waterline is the one above, flipped. Stage 3 is the plain mirror, stage 4 the wave before it is scaled, stage 5 the bent reflection. Then raise Wave height and watch the shore: the hut's reflection stays attached while the far water ripples. Push Tint to 1 and the reflection disappears into flat paint.

The code

LÖVE has no built-in screen texture, so the program draws the scene into a canvas (an off-screen image), then draws that canvas to the screen through the water shader. Above the line the shader passes the texel through. Below it, it reads the canvas at the mirrored point. The up and down arrows change the wave height.

local WATER_LINE = 0.62                  -- 0 is the top of the screen, 1 the bottom
local WATER_COLOR = { 0.10, 0.35, 0.55 }
local waveHeight = 0.008                 -- in UV units
local speed = 1.0
local tint = 0.35
local time = 0
local sceneCanvas, shader

local pixelcode = [[
uniform float u_time;
uniform float u_waterLine;
uniform float u_waveHeight;
uniform float u_speed;
uniform float u_tint;
uniform vec3 u_waterColor;

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
  vec2 uv = texture_coords;                 // (0, 0) top-left, y down
  float d = uv.y - u_waterLine;             // depth below the waterline
  if (d < 0.0) return Texel(tex, uv) * color;
  vec2 r = vec2(uv.x, u_waterLine - d);     // 1. mirror
  float t = u_time * u_speed;               // 2. wobble
  float wave = sin(d * 90.0 - t * 3.0) * 0.6 + sin(uv.x * 20.0 + d * 40.0 + t * 2.0) * 0.4;
  float calm = clamp(d * 12.0, 0.0, 1.0);
  vec2 offset = vec2(wave, 0.5 * wave) * u_waveHeight * calm;
  vec3 refl = Texel(tex, r + offset).rgb;
  vec3 water = mix(refl, u_waterColor, u_tint);         // 3. tint
  water *= 1.0 - 0.35 * smoothstep(0.0, 0.38, d);       // darker further down
  water += 0.3 * (1.0 - smoothstep(0.0, 0.01, d));      // bright edge at the line
  return vec4(water, 1.0) * color;
}
]]

function love.load()
  sceneCanvas = love.graphics.newCanvas()   -- the size of the window
  shader = love.graphics.newShader(pixelcode)
end

function love.update(dt)
  time = time + dt
end

function love.keypressed(key)
  if key == "up" then waveHeight = math.min(waveHeight + 0.002, 0.02) end
  if key == "down" then waveHeight = math.max(waveHeight - 0.002, 0) end
end

-- the world above the water: sky, sun, a drifting cloud, the shore and a hut
local function drawScene(w, h)
  love.graphics.clear(0.30, 0.52, 0.85)
  love.graphics.setColor(1.0, 0.93, 0.70)
  love.graphics.circle("fill", 0.78 * w, 0.24 * h, 0.07 * h)
  local cx = (time * 0.03 * h) % (w + 0.6 * h) - 0.3 * h
  love.graphics.setColor(1.0, 0.98, 0.95)
  love.graphics.circle("fill", cx, 0.17 * h, 0.05 * h)
  love.graphics.circle("fill", cx + 0.06 * h, 0.15 * h, 0.065 * h)
  love.graphics.circle("fill", cx + 0.13 * h, 0.17 * h, 0.045 * h)
  love.graphics.setColor(0.30, 0.55, 0.28)
  love.graphics.rectangle("fill", 0, 0.575 * h, w, h)
  local hx = 0.26 * w
  love.graphics.setColor(0.85, 0.72, 0.52)
  love.graphics.rectangle("fill", hx - 0.06 * h, 0.50 * h, 0.12 * h, 0.10 * h)
  love.graphics.setColor(0.75, 0.22, 0.18)
  love.graphics.polygon("fill", hx - 0.08 * h, 0.50 * h, hx + 0.08 * h, 0.50 * h, hx, 0.42 * h)
  love.graphics.setColor(1, 1, 1)
end

function love.draw()
  local w, h = love.graphics.getDimensions()
  love.graphics.setCanvas(sceneCanvas)
  drawScene(w, h)
  love.graphics.setCanvas()

  shader:send("u_time", time)
  shader:send("u_waterLine", WATER_LINE)
  shader:send("u_waveHeight", waveHeight)
  shader:send("u_speed", speed)
  shader:send("u_tint", tint)
  shader:send("u_waterColor", WATER_COLOR)
  love.graphics.setShader(shader)
  love.graphics.draw(sceneCanvas)          -- above the line as it is, below it reflected
  love.graphics.setShader()
end
precision mediump float;

uniform vec2 u_resolution;
uniform float u_time;
uniform float u_waveHeight;    // in UV units
uniform float u_speed;
uniform float u_tint;          // 0 pure reflection, 1 flat water colour
uniform vec3 u_waterColor;
uniform float u_stage;         // 0 scene, 1 coordinates, 2 mirror, 3 wave, 4 bent mirror, 5 final

const float WATER_LINE = 0.62; // 0 top, 1 bottom

// The "screen texture": the scene, drawn with maths. uv has (0, 0) at the top-left.
vec3 scene(vec2 uv) {
  uv = clamp(uv, 0.0, 1.0);                       // like a clamped texture
  float aspect = u_resolution.x / u_resolution.y;
  vec2 p = vec2(uv.x * aspect, uv.y);             // x scaled so circles stay round
  vec3 col = mix(vec3(0.30, 0.52, 0.85), vec3(0.98, 0.80, 0.62), smoothstep(0.05, 0.6, uv.y));

  float sd = length(p - vec2(aspect * 0.78, 0.24));                       // sun and glow
  col += vec3(1.0, 0.75, 0.40) * 0.35 * (1.0 - smoothstep(0.0, 0.25, sd));
  col = mix(col, vec3(1.0, 0.93, 0.70), 1.0 - smoothstep(0.065, 0.072, sd));

  float cx = mod(u_time * 0.03, aspect + 0.6) - 0.3;                     // drifting cloud
  float cl = min(length(p - vec2(cx, 0.17)) - 0.05, length(p - vec2(cx + 0.06, 0.15)) - 0.065);
  cl = min(cl, length(p - vec2(cx + 0.13, 0.17)) - 0.045);
  cl = min(cl, max(abs(p.y - 0.195) - 0.025, abs(p.x - cx - 0.065) - 0.11));
  col = mix(col, vec3(1.0, 0.98, 0.95), 1.0 - smoothstep(0.0, 0.004, cl));

  float hill = 0.47 + 0.05 * sin(p.x * 3.0 + 1.0) + 0.025 * sin(p.x * 7.3);   // far hills
  if (uv.y > hill) col = vec3(0.47, 0.47, 0.66);
  float ground = 0.575 + 0.015 * sin(p.x * 5.0 + 2.0);                        // shore
  if (uv.y > ground) col = vec3(0.30, 0.55, 0.28);

  float hx = aspect * 0.26;                                                   // hut
  if (abs(p.x - hx) < 0.06 && uv.y > 0.50 && uv.y < 0.60) col = vec3(0.85, 0.72, 0.52);
  if (uv.y > 0.42 && uv.y <= 0.50 && abs(p.x - hx) < uv.y - 0.42) col = vec3(0.75, 0.22, 0.18);
  if (abs(p.x - hx - 0.02) < 0.015 && uv.y > 0.545 && uv.y < 0.60) col = vec3(0.35, 0.20, 0.12);
  if (abs(p.x - hx + 0.03) < 0.012 && abs(uv.y - 0.535) < 0.012) col = vec3(0.95, 0.85, 0.40);

  float tx = aspect * 0.55;                                                   // tree
  if (abs(p.x - tx) < 0.012 && uv.y > 0.48 && uv.y < 0.60) col = vec3(0.40, 0.26, 0.16);
  if (length(p - vec2(tx, 0.44)) < 0.065 || length(p - vec2(tx - 0.045, 0.47)) < 0.045)
    col = vec3(0.18, 0.45, 0.22);
  return col;
}

void main() {
  vec2 uv = gl_FragCoord.xy / u_resolution;
  uv.y = 1.0 - uv.y;                       // y down, like texture coordinates in LÖVE and Godot
  vec3 col = scene(uv);                    // above the water: the scene as it is
  float d = uv.y - WATER_LINE;             // depth below the waterline, negative above it

  vec2 r = vec2(uv.x, WATER_LINE - d);                                   // 1. mirror
  float t = u_time * u_speed;                                             // 2. wobble
  float wave = sin(d * 90.0 - t * 3.0) * 0.6 + sin(uv.x * 20.0 + d * 40.0 + t * 2.0) * 0.4;
  float calm = clamp(d * 12.0, 0.0, 1.0);
  vec2 offset = vec2(wave, 0.5 * wave) * u_waveHeight * calm;
  vec3 refl = scene(r + offset);
  vec3 water = mix(refl, u_waterColor, u_tint);                           // 3. tint
  water *= 1.0 - 0.35 * smoothstep(0.0, 0.38, d);
  water += 0.3 * (1.0 - smoothstep(0.0, 0.01, d));

  // the stage selector: show an intermediate value instead of the final colour
  vec2 c = d < 0.0 ? uv : r;               // the coordinate this pixel reads
  vec3 coords = vec3(c.x, c.y, 0.3);
  vec2 g = abs(fract(c * 10.0) - 0.5);
  if (max(g.x, g.y) > 0.46) coords = vec3(1.0);

  vec3 below = water;
  if (u_stage < 4.5) below = refl;
  if (u_stage < 3.5) below = vec3(0.5 + 0.5 * wave * calm);
  if (u_stage < 2.5) below = scene(r);
  if (u_stage < 0.5) below = col;
  if (d >= 0.0) col = below;
  if (u_stage > 0.5 && u_stage < 1.5) col = coords;

  float onePixel = 1.0 / u_resolution.y;
  if (u_stage > 0.5 && u_stage < 4.5 && abs(d) < onePixel) col = vec3(1.0, 0.85, 0.2);
  gl_FragColor = vec4(col, 1.0);
}
// Godot 4. Put this on a ColorRect that covers the whole screen
// and is drawn after (below, in the scene tree) everything it should reflect.
shader_type canvas_item;

uniform sampler2D screen_texture : hint_screen_texture, repeat_disable, filter_linear;
uniform float water_line = 0.62;                  // 0 top, 1 bottom
uniform float wave_height = 0.008;
uniform float speed = 1.0;
uniform float tint : hint_range(0.0, 1.0) = 0.35;
uniform vec4 water_color : source_color = vec4(0.10, 0.35, 0.55, 1.0);

void fragment() {
    vec2 uv = SCREEN_UV;                          // (0, 0) top-left, y down
    float d = uv.y - water_line;
    vec3 col = textureLod(screen_texture, uv, 0.0).rgb;
    if (d >= 0.0) {
        vec2 r = vec2(uv.x, water_line - d);
        float t = TIME * speed;
        float wave = sin(d * 90.0 - t * 3.0) * 0.6 + sin(uv.x * 20.0 + d * 40.0 + t * 2.0) * 0.4;
        float calm = clamp(d * 12.0, 0.0, 1.0);
        vec2 offset = vec2(wave, 0.5 * wave) * wave_height * calm;
        vec3 refl = textureLod(screen_texture, r + offset, 0.0).rgb;
        col = mix(refl, water_color.rgb, tint);
        col *= 1.0 - 0.35 * smoothstep(0.0, 0.38, d);
        col += 0.3 * (1.0 - smoothstep(0.0, 0.01, d));
    }
    COLOR = vec4(col, 1.0);
}
// Built-in render pipeline, as an image effect: a script on the camera calls
// Graphics.Blit(source, destination, material) in OnRenderImage.
Shader "GameDevDaily/Water2D"
{
    Properties
    {
        _MainTex ("Screen", 2D) = "white" {}
        _WaterLine ("Water line (0 bottom, 1 top)", Range(0, 1)) = 0.38
        _WaveHeight ("Wave height", Range(0, 0.02)) = 0.008
        _Speed ("Speed", Range(0, 3)) = 1
        _Tint ("Tint", Range(0, 1)) = 0.35
        _WaterColor ("Water colour", Color) = (0.10, 0.35, 0.55, 1)
    }
    SubShader
    {
        Cull Off ZWrite Off ZTest Always
        Pass
        {
            CGPROGRAM
            #pragma vertex vert_img
            #pragma fragment frag
            #include "UnityCG.cginc"

            sampler2D _MainTex;
            float _WaterLine, _WaveHeight, _Speed, _Tint;
            fixed4 _WaterColor;

            fixed4 frag (v2f_img i) : SV_Target
            {
                float2 uv = i.uv;                       // (0, 0) bottom-left, y up
                float d = _WaterLine - uv.y;            // y up, so the subtraction is reversed
                if (d < 0) return tex2D(_MainTex, uv);
                float2 r = float2(uv.x, _WaterLine + d);
                float t = _Time.y * _Speed;
                float wave = sin(d * 90 - t * 3) * 0.6 + sin(uv.x * 20 + d * 40 + t * 2) * 0.4;
                float calm = saturate(d * 12);
                float2 offset = float2(wave, -0.5 * wave) * _WaveHeight * calm;
                float3 refl = tex2D(_MainTex, r + offset).rgb;
                float3 water = lerp(refl, _WaterColor.rgb, _Tint);
                water *= 1 - 0.35 * smoothstep(0, 0.38, d);
                water += 0.3 * (1 - smoothstep(0, 0.01, d));
                return fixed4(water, 1);
            }
            ENDCG
        }
    }
}

The Godot version reads the screen through hint_screen_texture, which holds what was drawn before the ColorRect. The Unity version is for the Built-in render pipeline; because its UVs are y up, the waterline 0.38 from the bottom is the same place as 0.62 from the top. In URP, use a Full Screen Pass Renderer Feature or the camera's Opaque Texture instead of OnRenderImage; the maths in frag stays the same. In a project set to Linear colour space, Unity converts _WaterColor to linear and the blend happens in linear space, so mid tints look slightly different from the demo.

Pitfalls

  • The water reflects itself. If the vertical wobble is larger than d, pixels near the line read from below it and pick up water instead of scene. Fade the offset to 0 at the line, as calm does.
  • Reading off the top of the screen. When the water is taller than the scene above it, the mirror asks for points above the top edge. With clamping you get a smear of the top row, with repeat you get the bottom of the screen. Keep the water shorter than the space above it, or fade to plain water colour where r.y leaves the screen.
  • Reading the screen you are drawing to. A shader cannot read the image it is writing. That is why LÖVE draws into a canvas first, Godot copies the screen for hint_screen_texture, and Unity hands the finished frame to the image effect.
  • Wave height in the wrong units. The offset is in UV units, so 1.0 is the whole screen. Values around 0.005 to 0.015 look like water; 0.1 looks like a broken television.
  • Upside-down reflections. If your water shows the sky right at the shore, the y axis points the other way from what the code assumes. Check where (0, 0) is in your engine and swap the sign of d.

What it costs

Per water pixel the shader does two texture reads at most, two sin calls and a few multiplies: cheap, even on a phone. The expensive part is getting the scene as a texture. Drawing into a canvas or copying the screen touches every pixel of the screen once more, and on mobile GPUs memory bandwidth is the scarce resource. One copy per frame is fine; one copy per puddle is not, so put all the water that reflects the same scene in one draw. On some older mobile GPUs, reads at a computed UV (a dependent texture read) were also slower than reads at the plain interpolated UV.

In real games

Engines expose exactly the pieces this effect needs: Godot has screen-reading shaders through hint_screen_texture, Unity's Built-in pipeline has GrabPass and image effects, URP has the Opaque Texture, and LÖVE has canvases. 3D games use the same mirror idea at a larger scale: a planar reflection renders the scene a second time from a camera mirrored below the water plane, and the water shader reads that image with a ripple offset, just as our 2D water reads the scene above the line.

Your turn (15 minutes)

Start from the LÖVE program.

  1. Add a player rectangle that walks left and right on the shore with the arrow keys, drawn into the scene canvas. Check that its reflection follows it.
  2. Make the ripples bunch up towards the horizon, as they do in perspective: replace d * 90.0 with sqrt(d) * 40.0, and compare.
  3. Fade the reflection out with depth: use mix(u_tint, 1.0, smoothstep(0.0, 0.38, d)) as the tint amount, so the far edge of the screen is plain water colour.

You are done when the player's reflection wobbles under them, the ripples are tighter near the waterline and the bottom of the screen fades to flat water.

Takeaways

  • A water pixel d below the waterline shows the scene d above it: r = (uv.x, waterLine - d).
  • Adding a time-scrolled wave to r bends the reflection; scale it by calm so it stays attached at the shore.
  • mix with a water colour and a little darkening with depth turn a mirror into water.
  • The shader needs the scene as a texture: a canvas in LÖVE, the screen texture in Godot, an image effect in Unity.
  • Know where (0, 0) is: the sign of d flips between y-down and y-up coordinates.
