Circles from distance: discs, rings and glows

length(uv - centre) gives every pixel its distance to a point. Threshold it for a disc, fold it for a ring, and let it fade for a glow.

A selection ring under a unit, the glowing orb of a pickup, the expanding shockwave of an explosion. A circle sprite works until it is scaled up and the edge goes blurry or blocky.

A shader draws all three from one number, the distance from the pixel to a centre point, and the edge stays sharp at any size.

One number per pixel: how far from the centre

A fragment shader is a small function that runs once per pixel and returns a colour. Today the input is the pixel's centred UV, with (0, 0) in the middle of the picture and y running from -0.5 at the bottom to 0.5 at the top. The output is a mix of two colours. Three lines sit in between.

Step 1: position relative to the centre

Subtract the centre of the circle from the pixel's UV. The result p is an arrow from the centre to this pixel:

vec2 p = uv - u_center;

Step 2: the length of that arrow

length(p) returns sqrt(p.x * p.x + p.y * p.y), Pythagoras in one call. Call it d. It is 0.0 at the centre and grows by the same amount in every direction, so every set of pixels with equal d forms a circle around the centre.

float d = length(p);

This is a distance field: a value at every pixel that says how far that pixel is from something. Shapes come from asking questions about it.

Step 3: ask a question about d

Disc. Is the pixel closer than the radius r? That is a threshold, and smoothstep from three lessons ago draws it with a soft edge. The edge spans from r - e to r + e, where e is one pixel (aa, for anti-aliasing) plus any extra softness:

float m = 1.0 - smoothstep(r - e, r + e, d);   // 1.0 inside, 0.0 outside

Ring. A ring is the pixels close to the circle's edge. abs(d - r) is the distance from the pixel to that edge, from either side. This is the same fold as yesterday's stripes, where min(f, 1.0 - f) turned a position into a distance to the nearest line. Cut it at half the thickness t:

float m = 1.0 - smoothstep(0.5 * t - e, 0.5 * t + e, abs(d - r));

Glow. A glow never has a hard edge. It is bright inside the disc and fades with distance outside it. max(d - r, 0.0) is 0.0 inside and grows outside; exp turns that into a value that starts at 1.0 and halves again and again as you move out. Here e sets how far the glow reaches:

float m = exp(-max(d - r, 0.0) / e);

Each mask then goes into mix(background, colour, m).

Rule of thumb

Get a distance, then shape it. d threshold is a disc, abs(d - r) threshold is a ring, a falloff on d - r is a glow. Every shape in the next track works the same way with a different distance.

Try it

Drag on the picture (or focus it and press the arrow keys) to move the centre. Walk the Stage menu from 1 to 5. Stage 1 is p as red and green: just the UV, shifted to your centre. Stage 2 is d as grey, with an orange contour every 0.1 units; the contours are perfect circles. Stage 3 is the value the mask thresholds. For Disc it is d again; switch to Ring and watch it go black along the circle, which is abs(d - r) reaching zero.

Then try the edges. With Edge softness at 0 the edge is still one pixel soft, never jagged. Choose Glow and raise the softness to about 0.08. Hover to read d and the mask under the pointer.

The code

The Lua version runs the same shade function in LÖVE, whose pixel shaders use the entry point effect instead of main. Drag with the left mouse button to move the centre. Up and down change the radius, [ and ] the softness, , and . the ring thickness, 1, 2 and 3 pick disc, ring or glow, and S cycles the stage. A right click prints the distance and the disc mask under the mouse, worked out with the same maths in plain Lua.

-- The demo's starting values. Centred uv: (0, 0) in the middle, y up.
local center = { 0, 0 }
local radius = 0.25
local soft = 0           -- extra edge softness, in uv units
local thick = 0.04       -- ring thickness, in uv units
local shape = 0          -- 0 disc, 1 ring, 2 glow
local stage = 4          -- 0 p, 1 d, 2 field, 3 mask, 4 final
local rect = { 20, 20, 640, 360 }   -- x, y, width, height in pixels
local shader

local pixelcode = [[
uniform vec2 u_center;
uniform float u_radius;
uniform float u_soft;
uniform float u_thick;
uniform float u_shape;
uniform float u_stage;
uniform vec4 u_rect;

vec3 shade(vec2 uv, float aa)
{
    vec2 p = uv - u_center;                       // 1. relative to the centre
    float d = length(p);                          // 2. distance to the centre
    float e = u_soft + aa;                        //    half-width of the edge
    float field = d;                              // 3. disc: d
    if (u_shape > 0.5) field = abs(d - u_radius);     //    ring: distance to the edge
    if (u_shape > 1.5) field = max(d - u_radius, 0.0); //    glow: distance outside
    float edge = u_radius;
    if (u_shape > 0.5) edge = 0.5 * u_thick;
    float m = 1.0 - smoothstep(edge - e, edge + e, field); // 4. mask
    if (u_shape > 1.5) m = exp(-field / e);
    vec3 col = mix(vec3(0.1, 0.12, 0.22), vec3(1.0, 0.62, 0.2), m); // 5. final
    float iso = abs(fract(d * 10.0 + 0.5) - 0.5) / 10.0;  // distance to a 0.1 contour
    vec3 rings = mix(vec3(2.0 * d), vec3(1.0, 0.62, 0.2), 1.0 - smoothstep(0.5 * aa, 1.5 * aa, iso));
    if (u_stage < 3.5) col = vec3(m);
    if (u_stage < 2.5) col = vec3(2.0 * field);
    if (u_stage < 1.5) col = rings;
    if (u_stage < 0.5) col = vec3(p + 0.5, 0.0);
    return col;
}

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
    vec2 uv = (screen_coords - u_rect.xy - 0.5 * u_rect.zw) / u_rect.w;
    uv.y = -uv.y;                     // y points down here; make it point up
    float aa = 1.0 / u_rect.w;        // one pixel, in uv units
    return vec4(shade(uv, aa), 1.0);
}
]]

local function toUV(x, y)
  local u = (x - rect[1] - rect[3] / 2) / rect[4]
  local v = -(y - rect[2] - rect[4] / 2) / rect[4]
  return u, v
end

local function smoothstep(e0, e1, x)
  local t = math.min(math.max((x - e0) / (e1 - e0), 0), 1)
  return t * t * (3 - 2 * t)
end

function love.load()
  shader = love.graphics.newShader(pixelcode)
end

function love.keypressed(key)
  if key == "up" then radius = math.min(0.5, radius + 0.01) end
  if key == "down" then radius = math.max(0.02, radius - 0.01) end
  if key == "]" then soft = math.min(0.2, soft + 0.005) end
  if key == "[" then soft = math.max(0, soft - 0.005) end
  if key == "." then thick = math.min(0.3, thick + 0.005) end
  if key == "," then thick = math.max(0.005, thick - 0.005) end
  if key == "1" then shape = 0 end
  if key == "2" then shape = 1 end
  if key == "3" then shape = 2 end
  if key == "s" then stage = (stage + 1) % 5 end
end

function love.mousepressed(x, y, button)
  if button == 1 then
    center[1], center[2] = toUV(x, y)
  elseif button == 2 then
    local u, v = toUV(x, y)
    local d = math.sqrt((u - center[1]) ^ 2 + (v - center[2]) ^ 2)
    local e = soft + 1 / rect[4]
    local m = 1 - smoothstep(radius - e, radius + e, d)
    print(string.format("d = %.3f, disc mask = %.2f", d, m))
  end
end

function love.mousemoved(x, y)
  if love.mouse.isDown(1) then
    center[1], center[2] = toUV(x, y)
  end
end

function love.draw()
  shader:send("u_center", center)
  shader:send("u_radius", radius)
  shader:send("u_soft", soft)
  shader:send("u_thick", thick)
  shader:send("u_shape", shape)
  shader:send("u_stage", stage)
  shader:send("u_rect", rect)
  love.graphics.setShader(shader)
  love.graphics.rectangle("fill", rect[1], rect[2], rect[3], rect[4])
  love.graphics.setShader()
end

precision highp float;
#else
precision mediump float;
#endif

uniform vec2 u_resolution;
uniform vec2 u_center;
uniform float u_radius;
uniform float u_soft;
uniform float u_thick;
uniform float u_shape;
uniform float u_stage;

vec3 shade(vec2 uv, float aa) {
  vec2 p = uv - u_center;                       // 1. relative to the centre
  float d = length(p);                          // 2. distance to the centre
  float e = u_soft + aa;                        //    half-width of the edge
  float field = d;                              // 3. disc: d
  if (u_shape > 0.5) field = abs(d - u_radius);     //    ring: distance to the edge
  if (u_shape > 1.5) field = max(d - u_radius, 0.0); //    glow: distance outside
  float edge = u_radius;
  if (u_shape > 0.5) edge = 0.5 * u_thick;
  float m = 1.0 - smoothstep(edge - e, edge + e, field); // 4. mask
  if (u_shape > 1.5) m = exp(-field / e);
  vec3 col = mix(vec3(0.1, 0.12, 0.22), vec3(1.0, 0.62, 0.2), m); // 5. final
  float iso = abs(fract(d * 10.0 + 0.5) - 0.5) / 10.0;  // distance to a 0.1 contour
  vec3 rings = mix(vec3(2.0 * d), vec3(1.0, 0.62, 0.2), 1.0 - smoothstep(0.5 * aa, 1.5 * aa, iso));
  if (u_stage < 3.5) col = vec3(m);
  if (u_stage < 2.5) col = vec3(2.0 * field);
  if (u_stage < 1.5) col = rings;
  if (u_stage < 0.5) col = vec3(p + 0.5, 0.0);
  return col;
}

void main() {
  vec2 px = gl_FragCoord.xy;                    // pixels, origin bottom-left
  vec2 uv = (px - 0.5 * u_resolution) / u_resolution.y; // centred, y up
  float aa = 1.0 / u_resolution.y;              // one pixel, in uv units
  gl_FragColor = vec4(shade(uv, aa), 1.0);
}
// Godot 4. Put this in a ShaderMaterial on a ColorRect.
shader_type canvas_item;

uniform vec2 center = vec2(0.0, 0.0);   // centred uv, y up
uniform float radius = 0.25;
uniform float soft : hint_range(0.0, 0.2) = 0.0;
uniform float thick = 0.04;
uniform float shape = 0.0;     // 0 disc, 1 ring, 2 glow
uniform float aspect = 1.0;    // set to the ColorRect's width / height

void fragment() {
    vec2 uv = (UV - 0.5) * vec2(aspect, 1.0);
    uv.y = -uv.y;              // UV (0, 0) is the top-left; make y point up
    float d = length(uv - center);
    float e = soft + fwidth(uv.y);           // one pixel, in uv units
    float field = d;
    if (shape > 0.5) field = abs(d - radius);
    if (shape > 1.5) field = max(d - radius, 0.0);
    float edge = radius;
    if (shape > 0.5) edge = 0.5 * thick;
    float m = 1.0 - smoothstep(edge - e, edge + e, field);
    if (shape > 1.5) m = exp(-field / e);
    COLOR = vec4(mix(vec3(0.1, 0.12, 0.22), vec3(1.0, 0.62, 0.2), m), 1.0);
}

        _Thick ("Ring thickness", Range(0.005, 0.3)) = 0.04

        _Aspect ("Aspect (width / height)", Float) = 1

    SubShader

        Pass

            #pragma target 3.0

The Godot and Unity versions leave out the stages and measure one pixel with fwidth, which WebGL 1 lacks without an extension. In URP Shader Graph, Subtract the centre from the UV, feed it to a Length node, then Smoothstep or Absolute as above. The ready-made Ellipse node also draws a disc, but you cannot get at the distance inside it, so you cannot turn it into a ring or a glow.

Which way is up matters as soon as you place the centre with the mouse. WebGL's gl_FragCoord and a Unity Quad's uv have y pointing up. Godot's canvas_item UV and LÖVE's screen_coords have y pointing down, so those two versions flip y first; without the flip, moving the centre up would move the circle down. The colours are hard-coded numbers, so a Unity project in Linear colour space treats them as linear values, and they will look lighter there than on this page.

Pitfalls

  • Ellipses instead of circles. If the UV is divided by width on x and height on y, one unit is a different number of pixels on each axis and the circle stretches. Divide both by the height, as the UV lesson showed, or multiply x by the aspect ratio as the Godot and Unity versions do.
  • Jagged edges from step. step(d, r) gives a hard 0 or 1, and a curved hard edge shows stair steps. Spread the edge over about one pixel with smoothstep. The width of a pixel in UV units is 1.0 / u_resolution.y here, or fwidth where it is available.
  • A glow that never ends. The popular 0.02 / d glow looks nice but never reaches zero, and it divides by zero at the centre. The exp falloff here also never quite reaches zero; if you add many glows together, the whole screen slowly lifts. Clamp the result, or subtract a small floor value.
  • Squared distance as a shortcut. Comparing dot(p, p) with r * r skips the square root and gives the same hard disc. But a soft edge on squared distance is not even: it gets thinner as the radius grows. Use length whenever the edge is soft.

What it costs

A disc is a subtraction, a length (a multiply-add and a square root) and a smoothstep. That is a handful of instructions, cheap even on a phone. exp is a little more but still cheap. On mobile the real cost of a glow is its area: a large transparent quad shades every pixel it covers, even the nearly invisible ones. Keep glow quads only as large as the visible fade.

In real games

Circular masks from distance are everywhere in effects work: selection rings and range indicators under units, ripples and shockwaves that grow by animating the radius, soft round particles drawn on plain quads instead of with textures, and radial fades such as a vignette. Unity's Shader Graph ships an Ellipse node for the simple disc case.

The same distance-to-an-edge idea, stored in a texture rather than computed, is how many engines render sharp text at any size: signed distance field fonts. Track 2 builds the computed version for boxes and lines.

Your turn (15 minutes)

Turn the LÖVE example into a shockwave:

  1. Set shape to 1 (ring) and soft to 0.01.
  2. Add a variable age. In love.mousepressed, for the left button, set age = 0. In love.update(dt), add dt to it.
  3. Each frame set radius = 0.02 + age * 0.6 and thick = math.max(0.005, 0.08 * (1 - age)).

You are done when every click sends out a ring from the click point that grows, thins and disappears in about a second, with a clean edge the whole way.

Takeaways

  • length(uv - centre) gives each pixel its distance to a point; pixels with equal distance form circles.
  • Threshold the distance for a disc, threshold abs(d - r) for a ring, apply a falloff to d - r for a glow.
  • Use smoothstep across about one pixel for an edge that is smooth at every size.
  • Divide both UV axes by the same length, or the circle becomes an ellipse.
  • The maths is cheap; large soft glows cost because of how many pixels they cover.
