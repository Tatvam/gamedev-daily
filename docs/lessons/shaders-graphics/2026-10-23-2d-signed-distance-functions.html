2D signed distance functions: boxes, rounded boxes and lines

A signed distance function says how far each pixel is from a shape's edge, negative inside. One smoothstep then draws boxes, rounded boxes and lines.

Health bars with rounded ends, dialogue boxes with soft corners, a laser between two points. As sprites, each needs nine-slicing (cutting the image into a 3 by 3 grid so the corners never stretch) or a new texture whenever its size changes.

A shader can draw all of them from one number per pixel: how far the pixel is from the shape's edge, with a sign that says which side it is on.

A shape is a distance with a sign

A fragment shader is a small function that runs once per pixel and returns a colour. In the last lesson the input was the pixel's centred UV p, with y pointing up, and the circle came from d = length(p) compared with a radius r. Move the radius inside the function and something useful happens:

float sdCircle(vec2 p, float r) { return length(p) - r; }

This returns a negative number inside the circle, zero exactly on its edge and a positive number outside. Its size is the distance to the edge. A function like this is a signed distance function, or SDF: give it a point, get back how far the point is from the shape's edge, with the sign telling you inside (negative) or outside (positive).

Once a shape is an SDF, drawing it is always the same line. The edge is where d crosses zero, so spread a smoothstep across one pixel aa on either side:

float m = 1.0 - smoothstep(-aa, aa, d);   // 1.0 inside, 0.0 outside

The shape lives entirely in the function. Swap the function and the same mask line draws a box or a line instead.

The box: fold space into one corner

A box centred on the origin is described by b, its half width and half height. A box is symmetric, so a point at (-0.4, -0.3) is exactly as far from the edge as (0.4, 0.3). abs(p) folds all four quarters onto the top-right one, and the shader only has to solve that one corner.

Then q = abs(p) - b measures the folded point from the box's corner. Each part of q is positive when the point is past that edge. That leaves three cases:

  • Past both edges (both parts positive): the nearest point is the corner, and the distance is length(q).
  • Past one edge: the distance is straight to that edge, the positive part of q. length(max(q, 0.0)) covers both outside cases in one call, because the negative part becomes zero.
  • Inside (both negative): the nearest edge is the one with the larger, less negative part, so the distance is max(q.x, q.y), a negative number.

Rounded corners: shrink, then subtract

Subtracting r from any SDF moves its zero line outwards by r. Every point on the new edge is exactly r from the old shape, so the sides move out and the corners become quarter circles. To round a box without growing it, shrink it by r first:

d = sdBox(p, b - r) - r;

A line: the nearest point on a segment

For a segment from a to b, find how far along the segment the pixel sits, as a fraction h: 0.0 at a, 1.0 at b. That is a dot product divided by the squared length, clamped so the nearest point cannot leave the segment. The distance is the length from that nearest point to the pixel. A segment has no inside, so subtract a thickness and it becomes a capsule, which is a line with round ends.

float h = clamp(dot(pa, ba) / dot(ba, ba), 0.0, 1.0);
return length(pa - ba * h);

Outlines come free

abs(d) is the unsigned distance to the edge from either side, the same fold that made a ring in the circle lesson. Threshold it at half a width w and every SDF gets an outline that hugs it exactly, rounded corners included.

Rule of thumb

Write the shape as a function that returns a signed distance. Everything else, the fill, the soft edge, the outline and the rounding, is the same one or two lines for every shape.

The code

The Lua version runs the same shader in LÖVE, whose pixel shaders use the entry point effect instead of main. It also has the box and line distances in plain Lua: a left click or drag moves the probe and prints d there, worked out on the CPU with the same maths. Keys 1 to 4 pick circle, box, rounded box or line, up and down change the corner radius, O toggles a 0.02 outline, B the bands and S cycles the stage.

-- The demo's starting values. Centred uv: (0, 0) in the middle, y up.
local size = { 0.35, 0.2 }   -- half width, half height
local radius = 0.06          -- corner radius, or half thickness of the line
local outline = 0
local shape = 2              -- 0 circle, 1 box, 2 rounded box, 3 line
local stage = 4              -- 0 uv, 1 |d|, 2 signed bands, 3 mask, 4 final
local bands = 0
local probe = { 0.5, 0.3 }
local rect = { 20, 20, 640, 360 }   -- x, y, width, height in pixels
local shader

local pixelcode = [[
uniform vec2 u_size;
uniform float u_radius;
uniform float u_outline;
uniform float u_shape;
uniform float u_stage;
uniform float u_bands;
uniform vec2 u_probe;
uniform float u_show_probe;
uniform vec4 u_rect;

float sdCircle(vec2 p, float r) {
    return length(p) - r;
}

float sdBox(vec2 p, vec2 b) {
    vec2 q = abs(p) - b;                          // fold into one corner
    return length(max(q, vec2(0.0))) + min(max(q.x, q.y), 0.0);
}

float sdSegment(vec2 p, vec2 a, vec2 b) {
    vec2 pa = p - a;
    vec2 ba = b - a;
    float h = clamp(dot(pa, ba) / dot(ba, ba), 0.0, 1.0); // 0 at a, 1 at b
    return length(pa - ba * h);
}

float scene(vec2 p) {
    float r = min(u_radius, min(u_size.x, u_size.y));
    float d = sdCircle(p, u_size.x);
    if (u_shape > 0.5) d = sdBox(p, u_size);
    if (u_shape > 1.5) d = sdBox(p, u_size - r) - r;
    if (u_shape > 2.5) d = sdSegment(p, -u_size, u_size) - u_radius;
    return d;
}

vec3 shade(vec2 uv, float aa) {
    vec2 p = uv;                                  // 1. input: position
    float d = scene(p);                           // 2-3. signed distance
    float m = 1.0 - smoothstep(-aa, aa, d);       // 4. mask: 1 inside
    vec3 col = mix(vec3(0.1, 0.12, 0.22), vec3(1.0, 0.62, 0.2), m); // 5. final
    float o = 1.0 - smoothstep(0.5 * u_outline - aa, 0.5 * u_outline + aa, abs(d));
    col = mix(col, vec3(0.95, 0.95, 0.9), o * step(0.001, u_outline));
    vec3 side = mix(vec3(0.35, 0.6, 1.0), vec3(1.0, 0.62, 0.2), step(d, 0.0));
    vec3 signedView = side * (0.75 + 0.25 * cos(6.2832 * 20.0 * d));
    signedView = mix(signedView, vec3(1.0), 1.0 - smoothstep(aa, 2.0 * aa, abs(d)));
    if (u_stage < 3.5) col = vec3(m);
    if (u_stage < 2.5) col = signedView;
    if (u_stage < 1.5) col = vec3(2.0 * abs(d));
    if (u_stage < 0.5) col = vec3(p + 0.5, 0.0);
    float iso = abs(fract(d * 20.0 + 0.5) - 0.5) / 20.0;  // distance to a 0.05 contour
    col = mix(col, vec3(1.0), 0.5 * u_bands * (1.0 - smoothstep(0.5 * aa, 1.5 * aa, iso)));
    float pd = abs(scene(u_probe));               // distance at the probe
    float ring = 1.0 - smoothstep(0.5 * aa, 1.5 * aa, abs(length(uv - u_probe) - pd));
    float spot = 1.0 - smoothstep(3.0 * aa, 4.0 * aa, length(uv - u_probe));
    col = mix(col, vec3(0.2, 0.9, 0.5), max(ring, spot) * u_show_probe);
    return col;
}

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
    vec2 uv = (screen_coords - u_rect.xy - 0.5 * u_rect.zw) / u_rect.w;
    uv.y = -uv.y;                     // y points down here; make it point up
    float aa = 1.0 / u_rect.w;        // one pixel, in uv units
    return vec4(shade(uv, aa), 1.0);
}
]]

-- The same distances on the CPU.
local function sdBox(px, py, bx, by)
  local qx = math.abs(px) - bx
  local qy = math.abs(py) - by
  local ox, oy = math.max(qx, 0), math.max(qy, 0)
  return math.sqrt(ox * ox + oy * oy) + math.min(math.max(qx, qy), 0)
end

local function sdSegment(px, py, ax, ay, bx, by)
  local pax, pay = px - ax, py - ay
  local bax, bay = bx - ax, by - ay
  local h = (pax * bax + pay * bay) / (bax * bax + bay * bay)
  h = math.min(math.max(h, 0), 1)
  local dx, dy = pax - bax * h, pay - bay * h
  return math.sqrt(dx * dx + dy * dy)
end

local function scene(px, py)
  local r = math.min(radius, size[1], size[2])
  if shape == 0 then return math.sqrt(px * px + py * py) - size[1] end
  if shape == 1 then return sdBox(px, py, size[1], size[2]) end
  if shape == 2 then return sdBox(px, py, size[1] - r, size[2] - r) - r end
  return sdSegment(px, py, -size[1], -size[2], size[1], size[2]) - radius
end

local function toUV(x, y)
  local u = (x - rect[1] - rect[3] / 2) / rect[4]
  local v = -(y - rect[2] - rect[4] / 2) / rect[4]
  return u, v
end

local function moveProbe(x, y)
  probe[1], probe[2] = toUV(x, y)
  print(string.format("d = %.3f", scene(probe[1], probe[2])))
end

function love.load()
  shader = love.graphics.newShader(pixelcode)
end

function love.keypressed(key)
  if key == "1" then shape = 0 end
  if key == "2" then shape = 1 end
  if key == "3" then shape = 2 end
  if key == "4" then shape = 3 end
  if key == "up" then radius = math.min(0.2, radius + 0.005) end
  if key == "down" then radius = math.max(0, radius - 0.005) end
  if key == "o" then outline = 0.02 - outline end
  if key == "b" then bands = 1 - bands end
  if key == "s" then stage = (stage + 1) % 5 end
end

function love.mousepressed(x, y, button)
  if button == 1 then moveProbe(x, y) end
end

function love.mousemoved(x, y)
  if love.mouse.isDown(1) then moveProbe(x, y) end
end

function love.draw()
  shader:send("u_size", size)
  shader:send("u_radius", radius)
  shader:send("u_outline", outline)
  shader:send("u_shape", shape)
  shader:send("u_stage", stage)
  shader:send("u_bands", bands)
  shader:send("u_probe", probe)
  shader:send("u_show_probe", 1)
  shader:send("u_rect", rect)
  love.graphics.setShader(shader)
  love.graphics.rectangle("fill", rect[1], rect[2], rect[3], rect[4])
  love.graphics.setShader()
end

uniform float u_shape;
uniform float u_stage;
uniform float u_bands;
uniform vec2 u_probe;
uniform float u_show_probe;

  return length(p) - r;
}

float sdBox(vec2 p, vec2 b) {
  vec2 q = abs(p) - b;                          // fold into one corner
  return length(max(q, vec2(0.0))) + min(max(q.x, q.y), 0.0);
}

float sdSegment(vec2 p, vec2 a, vec2 b) {
  vec2 pa = p - a;
  vec2 ba = b - a;
  float h = clamp(dot(pa, ba) / dot(ba, ba), 0.0, 1.0); // 0 at a, 1 at b
  return length(pa - ba * h);
}

float scene(vec2 p) {
  float r = min(u_radius, min(u_size.x, u_size.y));
  float d = sdCircle(p, u_size.x);
  if (u_shape > 0.5) d = sdBox(p, u_size);
  if (u_shape > 1.5) d = sdBox(p, u_size - r) - r;
  if (u_shape > 2.5) d = sdSegment(p, -u_size, u_size) - u_radius;
  return d;
}

vec3 shade(vec2 uv, float aa) {
  vec2 p = uv;                                  // 1. input: position
  float d = scene(p);                           // 2-3. signed distance
  float m = 1.0 - smoothstep(-aa, aa, d);       // 4. mask: 1 inside
  vec3 col = mix(vec3(0.1, 0.12, 0.22), vec3(1.0, 0.62, 0.2), m); // 5. final
  float o = 1.0 - smoothstep(0.5 * u_outline - aa, 0.5 * u_outline + aa, abs(d));
  col = mix(col, vec3(0.95, 0.95, 0.9), o * step(0.001, u_outline));
  vec3 side = mix(vec3(0.35, 0.6, 1.0), vec3(1.0, 0.62, 0.2), step(d, 0.0));
  vec3 signedView = side * (0.75 + 0.25 * cos(6.2832 * 20.0 * d));
  signedView = mix(signedView, vec3(1.0), 1.0 - smoothstep(aa, 2.0 * aa, abs(d)));
  if (u_stage < 3.5) col = vec3(m);
  if (u_stage < 2.5) col = signedView;
  if (u_stage < 1.5) col = vec3(2.0 * abs(d));
  if (u_stage < 0.5) col = vec3(p + 0.5, 0.0);
  float iso = abs(fract(d * 20.0 + 0.5) - 0.5) / 20.0;  // distance to a 0.05 contour
  col = mix(col, vec3(1.0), 0.5 * u_bands * (1.0 - smoothstep(0.5 * aa, 1.5 * aa, iso)));
  float pd = abs(scene(u_probe));               // distance at the probe
  float ring = 1.0 - smoothstep(0.5 * aa, 1.5 * aa, abs(length(uv - u_probe) - pd));
  float spot = 1.0 - smoothstep(3.0 * aa, 4.0 * aa, length(uv - u_probe));
  col = mix(col, vec3(0.2, 0.9, 0.5), max(ring, spot) * u_show_probe);
  return col;
}

void main() {
  vec2 px = gl_FragCoord.xy;                    // pixels, origin bottom-left
  vec2 uv = (px - 0.5 * u_resolution) / u_resolution.y; // centred, y up
  float aa = 1.0 / u_resolution.y;              // one pixel, in uv units
  gl_FragColor = vec4(shade(uv, aa), 1.0);
}

// Put this in a ShaderMaterial on a ColorRect.
shader_type canvas_item;

uniform vec2 half_size = vec2(0.35, 0.2);
uniform float radius : hint_range(0.0, 0.2) = 0.06;
uniform float outline : hint_range(0.0, 0.06) = 0.0;
uniform float aspect = 1.0;    // set to the ColorRect's width / height

float sd_box(vec2 p, vec2 b) {
    vec2 q = abs(p) - b;
    return length(max(q, vec2(0.0))) + min(max(q.x, q.y), 0.0);
}

void fragment() {
    vec2 uv = (UV - 0.5) * vec2(aspect, 1.0);
    uv.y = -uv.y;              // UV (0, 0) is the top-left; make y point up
    float r = min(radius, min(half_size.x, half_size.y));
    float d = sd_box(uv, half_size - r) - r;
    float aa = fwidth(uv.y);   // one pixel, in uv units
    float m = 1.0 - smoothstep(-aa, aa, d);
    vec3 col = mix(vec3(0.1, 0.12, 0.22), vec3(1.0, 0.62, 0.2), m);
    float o = 1.0 - smoothstep(0.5 * outline - aa, 0.5 * outline + aa, abs(d));
    col = mix(col, vec3(0.95, 0.95, 0.9), o * step(0.001, outline));
    COLOR = vec4(col, 1.0);
}

The Godot and Unity versions draw only the rounded box, the shape you will use most for UI, and measure one pixel with fwidth, which WebGL 1 lacks without an extension. The other functions copy over line for line. Unity's URP Shader Graph has a Rounded Rectangle node, but it returns a finished mask, not the distance, so it cannot take an outline; put the HLSL function in a Custom Function node instead.

Which way is up matters for the line, which runs bottom-left to top-right only when y points up. WebGL's gl_FragCoord and a Unity Quad's uv have y up; Godot's canvas_item UV and LÖVE's screen_coords have y down, so those versions flip y first. In a Unity project set to Linear colour space, the hard-coded colours are treated as linear values and look lighter than on this page.

Pitfalls

  • Full size instead of half size. b is measured from the centre. Pass the full width and the box comes out twice as big.
  • Rounding that grows the shape. sdBox(p, b) - r rounds the corners but also makes the box r bigger on every side. Shrink first with b - r, and clamp r to the smaller half size, or b - r goes negative and the shape breaks.
  • The cheap box that is not a distance. max(q.x, q.y) alone is correct inside and on the edge, so the filled box looks right. Outside the corners it is too small, so outlines and glows get square outer corners. Use the full formula whenever you use the distance outside the shape.
  • Scaling p without scaling d. Drawing a shape twice as big with sd(p / 2.0) returns distances in the shrunken space. Multiply the result by 2.0, or the one-pixel edge becomes two pixels wide.
  • A zero-length line. dot(ba, ba) is zero when both ends meet, and the division is undefined. Check the length first.

What it costs

A box is an abs, a subtraction, a few max and min and one square root: around a dozen instructions, cheap even on a phone. A line adds a dot product and a division. The cost is per shape: every pixel evaluates every SDF in the shader, so a hundred shapes cost a hundred times one. The if statements on u_shape are cheap because every pixel takes the same path. The demo works out the probe's distance once per pixel, which is wasteful; a game would do it once on the CPU, as the Lua does, and send it as a uniform.

In real games

Rounded panels, buttons and capsule health bars in game UI are often drawn this way, because one material handles any size and corner radius with a sharp edge. The functions in this lesson are the common forms found across Shadertoy.

Distance fields also render sharp text: Unity's TextMesh Pro uses signed distance field fonts, and Godot 4 can import fonts as multichannel signed distance fields. There the distance is stored in a texture, but the edge is the same smoothstep around zero.

Takeaways

  • An SDF returns the distance to a shape's edge: negative inside, zero on the edge, positive outside.
  • One line draws any SDF: 1.0 - smoothstep(-aa, aa, d). The shape lives in the function.
  • The box folds space with abs(p) and solves one corner; the line clamps to the nearest point on the segment.
  • Subtract r to round and grow a shape; threshold abs(d) for an outline.
  • Each SDF is cheap, but every pixel pays for every shape in the shader.
