Sprite outlines: asking the neighbours for alpha

A transparent pixel next to an opaque one becomes outline: sample the alpha of nearby texels, take the max, and paint where the sprite is not.

You hover over a chest and it gets a bright border, or you select a unit and a coloured line appears around it. An artist could draw an outlined copy of every frame, but then every animation exists twice and the colour is fixed. A shader can draw that border on any sprite, in any colour, from the sprite's alpha alone.

An outline is "empty here, but something next to me"

A fragment shader is a small function that runs once per pixel and returns a colour. So far our sprite shaders read one texel (one pixel of the sprite's texture) and changed it. That is not enough here: a pixel just outside the sprite reads alpha 0, exactly like a pixel far away.

But a shader may read the texture as often as it likes, anywhere. So each pixel asks "is there sprite next to me?" It reads the alpha a short step to the right, left, up and down, and keeps the largest value. Call that n, the neighbour alpha. Its own alpha is a.

  • a = 1: the pixel is sprite. Draw the texel as normal.
  • a = 0 and n = 1: empty, but touching the sprite. This is outline.
  • a = 0 and n = 0: empty and far away. Stay transparent.

Those three cases fold into one line, outline = n * (1.0 - a). The final colour mixes the outline colour with the texel using a as the mask, and the alpha becomes max(a, n) so the outline is visible too.

Steps are measured in texels

Texture coordinates run from 0 to 1 across the whole texture, so "one texel to the right" is not +1.0. It is 1.0 / width. The game sends that texel size, (1 / width, 1 / height), as a uniform, and the offset becomes texelSize * thickness. Godot gives it to you as TEXTURE_PIXEL_SIZE, and Unity fills a _MainTex_TexelSize vector for you if you declare it.

The outline needs somewhere to be drawn

The shader only runs for pixels inside the rectangle (the quad) that the sprite is drawn on. If the art touches the edge of its image, the outline falls outside the quad, where no shader call ever runs. The fix is in the image: leave a transparent border at least as wide as the thickest outline. The demo's mushroom is 16 by 16 texels inside a 24 by 24 image, which leaves room for 4.

Which way is up does not matter here

The demo counts texels from the bottom-left with y up, like gl_FragCoord. LÖVE and Godot put texture coordinate (0, 0) at the top-left with y down; Unity puts UV (0, 0) at the bottom-left. The samples are symmetric, so the outline is the same in all of them. A one-sided offset, such as a drop shadow, is where direction matters.

Try it

The yellow square marks one texel, and the dots are the texels its shader reads: a filled dot hits the sprite, a hollow one misses. Move it with the pointer, or focus the canvas and use the arrow keys. It starts off the lower-left corner of the cap: switch Samples between 4 and 8 and watch that corner fill in. Set Thickness to 3 with 4 samples and look for holes around the thin sprout. Step through Stage to see a, n and the mask, and turn off the border to see the outline cut off at the quad's edge.

The code

The LÖVE program builds the same 24 by 24 mushroom in code, so there is no image file, and draws it twelve times larger with an 8-sample outline. The up and down arrow keys change the thickness from 1 to 4 texels.

local SIZE = 24                          -- texture size, with a 4 texel empty border
local OUTLINE_COLOR = { 0.10, 0.06, 0.14 }
local thickness = 1                      -- in texels, 1 to 4
local sprite, shader

local pixelcode = [[
uniform vec2 u_texelSize;     // 1 / texture size: one texel in UV units
uniform float u_thickness;    // in texels
uniform vec3 u_outlineColor;

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
  vec4 texel = Texel(tex, texture_coords);
  vec2 o = u_texelSize * u_thickness;
  float n = 0.0;
  n = max(n, Texel(tex, texture_coords + vec2(o.x, 0.0)).a);
  n = max(n, Texel(tex, texture_coords - vec2(o.x, 0.0)).a);
  n = max(n, Texel(tex, texture_coords + vec2(0.0, o.y)).a);
  n = max(n, Texel(tex, texture_coords - vec2(0.0, o.y)).a);
  n = max(n, Texel(tex, texture_coords + o).a);                  // the diagonals
  n = max(n, Texel(tex, texture_coords - o).a);
  n = max(n, Texel(tex, texture_coords + vec2(o.x, -o.y)).a);
  n = max(n, Texel(tex, texture_coords + vec2(-o.x, o.y)).a);
  vec3 rgb = mix(u_outlineColor, texel.rgb, texel.a);
  return vec4(rgb, max(texel.a, n)) * color;
}
]]

local function near(x, y, cx, cy, r)
  local dx, dy = x - cx, y - cy
  return dx * dx + dy * dy < r * r
end

-- the demo's mushroom; tx, ty count texels from the bottom-left like the demo
local function mushroomPixel(tx, ty)
  local x, y = tx + 0.5 - 4, ty + 0.5 - 4    -- texel centre in the 16 by 16 drawing
  local r, g, b, a = 0, 0, 0, 0
  if math.abs(x - 8) < 2.6 and y > 0 and y < 7 then r, g, b, a = 0.93, 0.87, 0.74, 1 end
  if near(x, y, 6.5, 3.5, 0.6) or near(x, y, 9.5, 3.5, 0.6) then r, g, b, a = 0.12, 0.08, 0.10, 1 end
  local ex, ey = (x - 8) / 7.8, (y - 7) / 7.5
  if ex * ex + ey * ey < 1 and y > 6 then
    local k = (y - 6) / 8
    r, g, b, a = 0.70 + 0.20 * k, 0.13 + 0.12 * k, 0.16 + 0.06 * k, 1
    if near(x, y, 4.5, 10.5, 1.6) or near(x, y, 11.5, 11.5, 1.8) or near(x, y, 8.5, 8.5, 1.1) then
      r, g, b = 0.97, 0.94, 0.88
    end
  end
  if (x == 8.5 and y > 14 and y < 16) or (y == 15.5 and (x == 9.5 or x == 10.5)) then
    r, g, b, a = 0.30, 0.62, 0.25, 1                  -- the thin sprout
  end
  return r, g, b, a
end

function love.load()
  local data = love.image.newImageData(SIZE, SIZE)
  data:mapPixel(function(x, y) return mushroomPixel(x, SIZE - 1 - y) end)  -- LÖVE rows go down
  sprite = love.graphics.newImage(data)
  sprite:setFilter("nearest", "nearest")
  shader = love.graphics.newShader(pixelcode)
end

function love.keypressed(key)
  if key == "up" then thickness = math.min(thickness + 1, 4) end
  if key == "down" then thickness = math.max(thickness - 1, 1) end
end

function love.draw()
  local w, h = love.graphics.getDimensions()
  love.graphics.clear(0.30, 0.48, 0.34)
  shader:send("u_texelSize", { 1 / SIZE, 1 / SIZE })
  shader:send("u_thickness", thickness)
  shader:send("u_outlineColor", OUTLINE_COLOR)
  love.graphics.setShader(shader)
  love.graphics.draw(sprite, w / 2 - SIZE * 6, h / 2 - SIZE * 6, 0, 12, 12)
  love.graphics.setShader()
end
precision mediump float;

uniform vec2 u_resolution;
uniform float u_thickness;     // in texels, 1.0 to 4.0
uniform float u_mode;          // 0 four samples, 1 eight samples, 2 every texel in a disc
uniform vec3 u_outlineColor;
uniform float u_padding;       // 1 the quad keeps the 4 texel border, 0 trimmed to the art
uniform float u_stage;         // 0 texel, 1 own alpha, 2 neighbour alpha, 3 outline, 4 final
uniform vec2 u_probe;          // the texel marked with a square
uniform float u_showQuad;

const vec2 TEX_SIZE = vec2(24.0, 24.0);   // the "texture", border included

// The "texture": colour and alpha of texel t (whole numbers, y up).
vec4 sprite(vec2 t) {
  if (t.x < 0.0 || t.y < 0.0 || t.x >= TEX_SIZE.x || t.y >= TEX_SIZE.y) return vec4(0.0);
  vec2 c = t + 0.5 - 4.0;                  // texel centre in the 16 by 16 drawing
  vec4 col = vec4(0.0);
  if (abs(c.x - 8.0) < 2.6 && c.y > 0.0 && c.y < 7.0) col = vec4(0.93, 0.87, 0.74, 1.0);   // stem
  if (length(c - vec2(6.5, 3.5)) < 0.6 || length(c - vec2(9.5, 3.5)) < 0.6)
    col = vec4(0.12, 0.08, 0.10, 1.0);                                                  // eyes
  if (length((c - vec2(8.0, 7.0)) / vec2(7.8, 7.5)) < 1.0 && c.y > 6.0) {               // cap
    float k = (c.y - 6.0) / 8.0;
    col = vec4(0.70 + 0.20 * k, 0.13 + 0.12 * k, 0.16 + 0.06 * k, 1.0);
    if (length(c - vec2(4.5, 10.5)) < 1.6 || length(c - vec2(11.5, 11.5)) < 1.8 ||
        length(c - vec2(8.5, 8.5)) < 1.1) col = vec4(0.97, 0.94, 0.88, 1.0);            // spots
  }
  if ((abs(c.x - 8.5) < 0.1 && c.y > 14.0 && c.y < 16.0) ||
      (abs(c.y - 15.5) < 0.1 && (abs(c.x - 9.5) < 0.1 || abs(c.x - 10.5) < 0.1)))
    col = vec4(0.30, 0.62, 0.25, 1.0);                                                  // sprout
  return col;
}

float alphaAt(vec2 t) {
  return sprite(t).a;
}

void main() {
  vec2 p = (gl_FragCoord.xy - 0.5 * u_resolution) / u_resolution.y;   // (0, 0) centre, y up

  vec2 tile = floor(p * 8.0);                                           // grass background
  vec3 bg = mix(vec3(0.30, 0.48, 0.34), vec3(0.35, 0.54, 0.38), mod(tile.x + tile.y, 2.0));

  float texelSize = 0.84 / TEX_SIZE.y;           // the quad is 0.84 of the canvas height
  vec2 sp = (p + 0.42) / texelSize;              // position in texels, (0, 0) bottom-left
  vec2 t = floor(sp);                            // which texel this pixel shows
  float lo = u_padding > 0.5 ? 0.0 : 4.0;
  float hi = TEX_SIZE.x - lo;
  bool inQuad = sp.x >= lo && sp.x < hi && sp.y >= lo && sp.y < hi;
  float r = u_thickness;
  float onePixel = 1.0 / (u_resolution.y * texelSize);   // one screen pixel, in texels

  vec3 col = bg;
  if (inQuad) {
    vec4 texel = sprite(t);
    float a = texel.a;                                       // 1. own alpha
    float n = 0.0;                                           // 2. neighbour alpha
    if (u_mode < 1.5) {
      n = max(n, alphaAt(t + vec2(r, 0.0)));
      n = max(n, alphaAt(t - vec2(r, 0.0)));
      n = max(n, alphaAt(t + vec2(0.0, r)));
      n = max(n, alphaAt(t - vec2(0.0, r)));
      if (u_mode > 0.5) {
        n = max(n, alphaAt(t + vec2(r, r)));
        n = max(n, alphaAt(t - vec2(r, r)));
        n = max(n, alphaAt(t + vec2(r, -r)));
        n = max(n, alphaAt(t + vec2(-r, r)));
      }
    } else {
      for (int j = -4; j <= 4; j++) {
        for (int i = -4; i <= 4; i++) {
          vec2 o = vec2(float(i), float(j));
          float d = dot(o, o);
          if (d > 0.5 && d <= r * r + r + 0.25) n = max(n, alphaAt(t + o));
        }
      }
    }
    float outline = n * (1.0 - a);                           // 3. outline mask
    vec4 outc = vec4(mix(u_outlineColor, texel.rgb, a), max(a, n));   // 4. paint
    col = mix(bg, outc.rgb, outc.a);

    if (u_stage < 3.5) col = vec3(outline);
    if (u_stage < 2.5) col = vec3(n);
    if (u_stage < 1.5) col = vec3(a);
    if (u_stage < 0.5) col = mix(bg, texel.rgb, a);

    vec2 f = fract(sp);                                      // faint texel grid in stages 2 to 4
    if (u_stage > 0.5 && u_stage < 3.5 && min(f.x, f.y) < onePixel) col = mix(col, vec3(0.5), 0.4);

    float edge = min(min(sp.x - lo, hi - sp.x), min(sp.y - lo, hi - sp.y));
    if (u_showQuad > 0.5 && edge < 1.5 * onePixel) col = vec3(0.95, 0.95, 0.85);
  } else if (u_stage > 0.5 && u_stage < 3.5) {
    col = bg * 0.4;                                          // the sprite's shader never runs here
  }

  // teaching overlay: the marked texel and the texels its shader reads
  vec2 dt = t - u_probe;
  bool isProbe = abs(dt.x) < 0.5 && abs(dt.y) < 0.5;
  bool isSample = false;
  if (u_mode < 1.5) {
    bool ax = abs(abs(dt.x) - r) < 0.5;
    bool ay = abs(abs(dt.y) - r) < 0.5;
    bool zx = abs(dt.x) < 0.5;
    bool zy = abs(dt.y) < 0.5;
    isSample = (ax && zy) || (zx && ay) || (u_mode > 0.5 && ax && ay);
  } else {
    float dd = dot(dt, dt);
    isSample = dd > 0.5 && dd <= r * r + r + 0.25;
  }
  vec2 g = fract(sp) - 0.5;
  if (isProbe) {
    float box = max(abs(g.x), abs(g.y));
    if (box > 0.26) col = vec3(0.08);
    if (box > 0.32 && box < 0.5) col = vec3(1.0, 0.85, 0.2);
  }
  if (isSample) {
    float len = length(g);
    vec3 under = col;
    bool hit = alphaAt(t) > 0.5;
    if (len < 0.42) col = vec3(0.95);
    if (len < 0.33) col = vec3(0.08);
    if (len < 0.23) col = hit ? vec3(1.0, 0.85, 0.2) : under;   // filled: hit, hollow: miss
  }
  gl_FragColor = vec4(col, 1.0);
}
// Godot 4, a ShaderMaterial on a Sprite2D.
shader_type canvas_item;

uniform vec4 outline_color : source_color = vec4(0.10, 0.06, 0.14, 1.0);
uniform float thickness : hint_range(1.0, 4.0, 1.0) = 1.0;   // in texels

void fragment() {
    vec4 texel = texture(TEXTURE, UV);
    vec2 o = TEXTURE_PIXEL_SIZE * thickness;   // one texel = 1 / texture size
    float n = 0.0;
    n = max(n, texture(TEXTURE, UV + vec2(o.x, 0.0)).a);
    n = max(n, texture(TEXTURE, UV - vec2(o.x, 0.0)).a);
    n = max(n, texture(TEXTURE, UV + vec2(0.0, o.y)).a);
    n = max(n, texture(TEXTURE, UV - vec2(0.0, o.y)).a);
    n = max(n, texture(TEXTURE, UV + o).a);
    n = max(n, texture(TEXTURE, UV - o).a);
    n = max(n, texture(TEXTURE, UV + vec2(o.x, -o.y)).a);
    n = max(n, texture(TEXTURE, UV + vec2(-o.x, o.y)).a);
    COLOR = vec4(mix(outline_color.rgb, texel.rgb, texel.a), max(texel.a, n));
}
// Built-in render pipeline, for a SpriteRenderer.
// Set the sprite's Mesh Type to Full Rect in its import settings.
Shader "GameDevDaily/SpriteOutline"
{
    Properties
    {
        [PerRendererData] _MainTex ("Sprite", 2D) = "white" {}
        _OutlineColor ("Outline colour", Color) = (0.10, 0.06, 0.14, 1)
        _Thickness ("Thickness (texels)", Range(1, 4)) = 1
    }
    SubShader
    {
        Tags { "Queue" = "Transparent" "RenderType" = "Transparent" "IgnoreProjector" = "True" }
        Cull Off
        ZWrite Off
        Blend SrcAlpha OneMinusSrcAlpha

        Pass
        {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            sampler2D _MainTex;
            float4 _MainTex_TexelSize;   // Unity fills this: x = 1/width, y = 1/height
            fixed4 _OutlineColor;
            float _Thickness;

            struct appdata { float4 vertex : POSITION; float2 uv : TEXCOORD0; fixed4 color : COLOR; };
            struct v2f { float4 pos : SV_POSITION; float2 uv : TEXCOORD0; fixed4 color : COLOR; };

            v2f vert (appdata v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = v.uv;
                o.color = v.color;
                return o;
            }

            fixed4 frag (v2f i) : SV_Target
            {
                fixed4 texel = tex2D(_MainTex, i.uv);
                float2 o = _MainTex_TexelSize.xy * _Thickness;
                float n = 0;
                n = max(n, tex2D(_MainTex, i.uv + float2(o.x, 0)).a);
                n = max(n, tex2D(_MainTex, i.uv - float2(o.x, 0)).a);
                n = max(n, tex2D(_MainTex, i.uv + float2(0, o.y)).a);
                n = max(n, tex2D(_MainTex, i.uv - float2(0, o.y)).a);
                n = max(n, tex2D(_MainTex, i.uv + o).a);
                n = max(n, tex2D(_MainTex, i.uv - o).a);
                n = max(n, tex2D(_MainTex, i.uv + float2(o.x, -o.y)).a);
                n = max(n, tex2D(_MainTex, i.uv + float2(-o.x, o.y)).a);
                fixed4 c = fixed4(lerp(_OutlineColor.rgb, texel.rgb, texel.a), max(texel.a, n));
                return c * i.color;
            }
            ENDCG
        }
    }
}

The Unity shader is for the Built-in render pipeline. In URP the same maths can be built in a Sprite Unlit Shader Graph: one Sample Texture 2D node per offset, the alphas combined with Maximum nodes, and a Lerp for the colour. HLSL spells mix as lerp. The Godot version ignores the node's modulate; multiply by COLOR first if you need it.

Pitfalls

  • No room for the outline. If the art reaches the edge of its image, the outline is clipped by the quad. Leave a transparent border at least as wide as the outline. Unity adds a second trap: by default a sprite's Mesh Type is Tight, a mesh that hugs the opaque pixels, so there is no empty space for the outline even with a border. Set it to Full Rect.
  • Offsets in the wrong units. An offset of 1.0 in UV space is the whole texture. Multiply the thickness by the texel size.
  • Sprite sheets bleed. In a sheet or atlas, the samples of one frame can reach into the next frame and draw a stray outline. Leave at least the outline thickness of empty space between frames.
  • Thick outlines get holes and corners. Sampling only at distance thickness jumps over thin parts, like the sprout at thickness 3. Eight samples make square corners. Reading every texel within the radius fixes both, at a much higher price.
  • Thickness grows with scale. The offset is in texels, so a sprite drawn three times larger gets a three times wider outline. For a fixed screen width, divide the thickness by the scale.

What it costs

The main cost is texture reads: 5 per pixel with 4 samples, 9 with 8, and 69 for the full disc at thickness 4 (the readout shows the count). Every pixel of the quad pays it, border included, so a 24 by 24 image runs the shader on 2.25 times as many pixels as a trimmed 16 by 16 one. On a phone, 9 reads on a handful of sprites is fine; a big disc on hundreds of sprites is not. For thick, round outlines on many sprites, bake them into the art, or precompute a distance field so one read gives the distance to the edge.

In real games

Coloured outlines are a common way for 2D games to mark the object under the cursor, the selected unit or something the player can pick up. Many pixel-art games draw dark outlines into the sprites by hand instead; a shader outline is what you reach for when the colour or the visibility has to change while the game runs.

Your turn (15 minutes)

Start from the LÖVE program.

  1. Add a hovered flag that is true while the mouse is over the mushroom's 288 by 288 pixel rectangle, and only draw the outline when it is set. Send a thickness of 0 otherwise, or draw without the shader.
  2. Change the shader into a drop shadow: read only one sample, at uv - o, which in LÖVE is up and to the left, so the shadow falls down and to the right. Give it a dark colour with alpha 0.5.
  3. Make an inner outline: take the smallest alpha of the samples, m, and paint where a * (1.0 - m) is 1.

You are done when the mushroom gets an outline on hover, and you can switch between outline, drop shadow and inner outline with a key.

Takeaways

  • A pixel cannot tell it is on the border from its own texel. Read the alpha of its neighbours and keep the largest, n.
  • outline = n * (1.0 - a): empty here, sprite nearby. Paint with mix(outlineColor, texel.rgb, a) and alpha max(a, n).
  • Offsets are thickness * texelSize, never whole UV units.
  • The outline can only appear inside the quad: give the art a transparent border, and use Full Rect sprites in Unity.
  • 4 samples cut corners, 8 make them square, and thick outlines need more reads, which cost on every pixel of the quad.
