Blending with mix: any number can be a mask

mix(a, b, t) slides from colour a to colour b as t goes from 0 to 1. Feed it a gradient, an edge or a circle as t and it paints a shape.

A sky fades from deep blue overhead to orange at the horizon. A glowing pickup is bright in the middle and melts into the background at its rim. An enemy flashes white when hit, then fades back to its own colours.

These look like three different effects. In a shader they are the same line of code with a different number fed into it.

One line that blends two colours

A fragment shader is a small function that runs once per pixel and returns a colour. In the last lesson, step and smoothstep turned a value into a mask: a number from 0.0 to 1.0 for each pixel. We then multiplied a colour by it, which only ever blends towards black. This lesson blends towards any colour.

The built-in function is mix(a, b, t). It returns a when t is 0.0, b when t is 1.0, and the matching point between them otherwise. This is called linear interpolation, often shortened to lerp, which is the name HLSL and Unity use. The formula is:

mix(a, b, t) = a * (1.0 - t) + b * t

Read it as two weights that always add up to 1. At t = 0.25 the result is 75 percent of a plus 25 percent of b. When a and b are vec3 colours, the same sum happens on red, green and blue separately.

The mask can be anything

The useful part is that t does not have to be a constant. It can be a different number at every pixel. Any value you can compute and keep between 0.0 and 1.0 works as a mask:

  • uv.x gives a left-to-right gradient.
  • step(0.5, uv.x) gives a hard split.
  • 1.0 - smoothstep(0.2, 0.4, length(p)) gives a soft disc, where p is the pixel's offset from the centre.
  • 0.5 + 0.5 * sin(...) gives waves, because sin runs from -1 to 1 and this moves it to 0 to 1.

So drawing becomes two separate questions: where (the mask) and what colours (a and b). Here is the demo's picture, built one line at a time; the Stage menu shows each result:

vec2 uv = (px - lo) / size;          // 1. input: UV from 0 to 1
float t = blendMask(uv, aspect);     // 2. mask: one number per pixel
vec3 partA = u_a * (1.0 - t);        // 3. how much of a survives
vec3 partB = u_b * t;                // 4. how much of b is added
vec3 col = mix(u_a, u_b, t);         // 5. final: partA + partB

One float goes in per pixel, one colour comes out. Stages 3 and 4 are what mix does inside; you never write them yourself.

Rule of thumb

Multiplying by a mask fades to black. mix fades to anything. Put the background in a, the shape's colour in b, and the shape itself in t.

The code

The Lua version runs the same blendMask and shade functions in LÖVE, whose pixel shaders use the entry point effect instead of main. Keys 0 to 4 pick the mask, up and down change the blend amount, A and B cycle the colours, X swaps them and S cycles the stage.

-- The demo's colours and starting values.
local colours = {
  { 0.10, 0.15, 0.40 },   -- 1 night blue
  { 1.00, 0.55, 0.15 },   -- 2 orange
  { 1.00, 1.00, 1.00 },   -- 3 white
  { 0.00, 0.00, 0.00 },   -- 4 black
  { 1.00, 0.00, 0.00 },   -- 5 red
  { 0.00, 1.00, 0.00 },   -- 6 green
  { 0.10, 0.70, 0.65 },   -- 7 teal
}
local a, b = 1, 2        -- which colours to blend
local maskKind = 3       -- 0 flat, 1 gradient, 2 hard edge, 3 soft circle, 4 waves
local amount = 1.0
local stage = 4          -- 0 UV, 1 mask, 2 a part, 3 b part, 4 final
local rect = { 20, 20, 600, 300 }   -- x, y, width, height in pixels
local shader

local pixelcode = [[
uniform vec3 u_a;
uniform vec3 u_b;
uniform float u_mask;
uniform float u_amount;
uniform float u_stage;
uniform vec4 u_rect;

float blendMask(vec2 uv, float aspect)
{
    float m = 1.0;                                     // 0. flat
    if (u_mask > 0.5) m = uv.x;                        // 1. gradient
    if (u_mask > 1.5) m = step(0.5, uv.x);             // 2. hard edge
    vec2 p = (uv - 0.5) * vec2(aspect, 1.0);
    if (u_mask > 2.5) m = 1.0 - smoothstep(0.2, 0.4, length(p));  // 3. soft circle
    if (u_mask > 3.5) m = 0.5 + 0.5 * sin((uv.x + uv.y) * 25.0);  // 4. waves
    return m * u_amount;
}

vec3 shade(vec2 uv, float aspect)
{
    float t = blendMask(uv, aspect);
    vec3 col = mix(u_a, u_b, t);                       // 5. final
    if (u_stage < 3.5) col = u_b * t;                  // 4. b part
    if (u_stage < 2.5) col = u_a * (1.0 - t);          // 3. a part
    if (u_stage < 1.5) col = vec3(t);                  // 2. mask
    if (u_stage < 0.5) col = vec3(uv, 0.0);            // 1. UV
    return col;
}

vec4 effect(vec4 color, Image tex, vec2 texture_coords, vec2 screen_coords)
{
    vec2 uv = (screen_coords - u_rect.xy) / u_rect.zw;   // (0, 0) is top-left here
    return vec4(shade(uv, u_rect.z / u_rect.w), 1.0);
}
]]

function love.load()
  shader = love.graphics.newShader(pixelcode)
end

function love.update(dt)
  if love.keyboard.isDown("up") then amount = amount + 0.5 * dt end
  if love.keyboard.isDown("down") then amount = amount - 0.5 * dt end
  amount = math.max(0, math.min(1, amount))
end

function love.keypressed(key)
  local n = tonumber(key)
  if n and n >= 0 and n <= 4 then maskKind = n end
  if key == "a" then a = a % #colours + 1 end
  if key == "b" then b = b % #colours + 1 end
  if key == "x" then a, b = b, a end
  if key == "s" then stage = (stage + 1) % 5 end
end

function love.draw()
  shader:send("u_a", colours[a])
  shader:send("u_b", colours[b])
  shader:send("u_mask", maskKind)
  shader:send("u_amount", amount)
  shader:send("u_stage", stage)
  shader:send("u_rect", rect)
  love.graphics.setShader(shader)
  love.graphics.rectangle("fill", rect[1], rect[2], rect[3], rect[4])
  love.graphics.setShader()
end
#ifdef GL_FRAGMENT_PRECISION_HIGH
precision highp float;
#else
precision mediump float;
#endif

uniform vec2 u_resolution;
uniform float u_dpr;
uniform vec3 u_a;
uniform vec3 u_b;
uniform float u_mask;
uniform float u_amount;
uniform float u_stage;
uniform vec2 u_probe;

// The mask: one number from 0.0 to 1.0 for this pixel.
float blendMask(vec2 uv, float aspect) {
  float m = 1.0;                                     // 0. flat
  if (u_mask > 0.5) m = uv.x;                        // 1. gradient
  if (u_mask > 1.5) m = step(0.5, uv.x);             // 2. hard edge
  vec2 p = (uv - 0.5) * vec2(aspect, 1.0);
  if (u_mask > 2.5) m = 1.0 - smoothstep(0.2, 0.4, length(p));  // 3. soft circle
  if (u_mask > 3.5) m = 0.5 + 0.5 * sin((uv.x + uv.y) * 25.0);  // 4. waves
  return m * u_amount;
}

// The lesson: blend colour a towards colour b by the mask.
vec3 shade(vec2 uv, float aspect) {
  float t = blendMask(uv, aspect);
  vec3 col = mix(u_a, u_b, t);                       // 5. final
  if (u_stage < 3.5) col = u_b * t;                  // 4. b part
  if (u_stage < 2.5) col = u_a * (1.0 - t);          // 3. a part
  if (u_stage < 1.5) col = vec3(t);                  // 2. mask
  if (u_stage < 0.5) col = vec3(uv, 0.0);            // 1. UV
  return col;
}

// Demo only: 1.0 inside the rectangle lo..hi, 0.0 outside.
float box(vec2 q, vec2 lo, vec2 hi) {
  vec2 s = step(lo, q) * step(q, hi);
  return s.x * s.y;
}

void main() {
  vec2 px = gl_FragCoord.xy;                  // pixels, origin bottom-left
  vec2 res = u_resolution;
  float pad = 12.0 * u_dpr;
  vec2 lo = vec2(pad, pad + 40.0 * u_dpr);    // bottom-left of the picture
  vec2 hi = res - vec2(pad);                  // top-right of the picture
  vec2 size = hi - lo;
  vec2 uv = (px - lo) / size;                 // 0.0 to 1.0 inside the picture
  float aspect = size.x / size.y;
  vec3 col = vec3(0.13, 0.14, 0.16);
  col = mix(col, shade(uv, aspect), box(px, lo, hi));

  // The strip: every colour mix can make, t from 0.0 (left) to 1.0 (right).
  float w = res.x - 2.0 * pad;
  float rt = (px.x - pad) / w;
  float inStrip = box(px, vec2(pad, pad), vec2(res.x - pad, pad + 28.0 * u_dpr));
  col = mix(col, mix(u_a, u_b, rt), inStrip);

  // The probe ring, with a dark outline so it shows on any colour.
  vec2 pp = lo + u_probe * size;
  float d = length(px - pp);
  col = mix(col, vec3(0.0), step(abs(d - 8.0 * u_dpr), 2.5 * u_dpr));
  col = mix(col, vec3(1.0), step(abs(d - 8.0 * u_dpr), 1.0 * u_dpr));

  // The marker on the strip at the probe's t.
  float mx = pad + blendMask(u_probe, aspect) * w;
  float dx = abs(px.x - mx);
  float band = box(px, vec2(0.0, pad - 4.0 * u_dpr), vec2(res.x, pad + 32.0 * u_dpr));
  col = mix(col, vec3(0.0), step(dx, 2.5 * u_dpr) * band);
  col = mix(col, vec3(1.0), step(dx, 1.0 * u_dpr) * band);

  gl_FragColor = vec4(col, 1.0);
}
// Godot 4. Put this in a ShaderMaterial on a ColorRect.
shader_type canvas_item;

uniform vec4 color_a : source_color = vec4(0.10, 0.15, 0.40, 1.0);
uniform vec4 color_b : source_color = vec4(1.00, 0.55, 0.15, 1.0);
uniform float mask_kind = 3.0;   // 0 flat, 1 gradient, 2 hard edge, 3 soft circle, 4 waves
uniform float amount : hint_range(0.0, 1.0) = 1.0;
uniform float aspect = 1.0;      // set to the ColorRect's width / height

float blendMask(vec2 uv) {
    float m = 1.0;
    if (mask_kind > 0.5) m = uv.x;
    if (mask_kind > 1.5) m = step(0.5, uv.x);
    vec2 p = (uv - 0.5) * vec2(aspect, 1.0);
    if (mask_kind > 2.5) m = 1.0 - smoothstep(0.2, 0.4, length(p));
    if (mask_kind > 3.5) m = 0.5 + 0.5 * sin((uv.x + uv.y) * 25.0);
    return m * amount;
}

void fragment() {
    float t = blendMask(UV);   // UV (0, 0) is the top-left of the ColorRect
    COLOR = vec4(mix(color_a.rgb, color_b.rgb, t), 1.0);
}
// Built-in render pipeline, unlit. Put it on a material and apply it to a Quad.
Shader "GameDevDaily/MixBlend"
{
    Properties
    {
        _ColorA ("Colour A", Color) = (0.10, 0.15, 0.40, 1)
        _ColorB ("Colour B", Color) = (1.00, 0.55, 0.15, 1)
        _Mask ("Mask (0 flat .. 4 waves)", Float) = 3
        _Amount ("Blend amount", Range(0, 1)) = 1
        _Aspect ("Aspect (width / height)", Float) = 1
    }
    SubShader
    {
        Tags { "RenderType" = "Opaque" }
        Pass
        {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            float4 _ColorA, _ColorB;
            float _Mask, _Amount, _Aspect;

            struct v2f
            {
                float4 pos : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            v2f vert (appdata_base v)
            {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = v.texcoord.xy;
                return o;
            }

            float blendMask (float2 uv)
            {
                float m = 1.0;
                if (_Mask > 0.5) m = uv.x;
                if (_Mask > 1.5) m = step(0.5, uv.x);
                float2 p = (uv - 0.5) * float2(_Aspect, 1.0);
                if (_Mask > 2.5) m = 1.0 - smoothstep(0.2, 0.4, length(p));
                if (_Mask > 3.5) m = 0.5 + 0.5 * sin((uv.x + uv.y) * 25.0);
                return m * _Amount;
            }

            fixed4 frag (v2f i) : SV_Target
            {
                float t = blendMask(i.uv);
                float3 col = lerp(_ColorA.rgb, _ColorB.rgb, t);
                return fixed4(col, 1.0);
            }
            ENDCG
        }
    }
}

HLSL calls the function lerp, with the same argument order as mix. In URP, Shader Graph's Lerp node does the same, with inputs A, B and T. The Godot and Unity versions leave out the stage menu.

Which way is up matters for the gradient and the waves. WebGL's gl_FragCoord starts at the bottom-left, a Unity Quad's uv also has (0, 0) at the bottom-left, but Godot's canvas_item UV and LÖVE's screen_coords start at the top-left. The waves run the other diagonal there; the circle and the left-to-right gradient look the same everywhere.

Pitfalls

  • Letting t leave 0 to 1. mix does not clamp. At t = 1.5 it goes past b, and a channel can go above 1.0 or below 0.0. Raw sin runs from -1 to 1, so a mask of plain sin(x) spends half its time below zero. Wrap doubtful masks in clamp(t, 0.0, 1.0).
  • Swapping a and b. mix(a, b, 0.0) is a, not b. If a shape comes out inside out, swap the colours or use 1.0 - t; mix(a, b, t) equals mix(b, a, 1.0 - t). The demo's Swap button shows this.
  • Muddy middles. Pick red and green: the middle of the strip is a dark olive, not a bright yellow. The demo blends the stored colour numbers, which are gamma-encoded (sRGB) rather than proportional to light; a blend in linear light has a brighter middle. In a Unity project set to Linear colour space, Color properties are converted to linear before the shader sees them, so the same shader blends differently there. The gamma lesson in Track 5 covers this properly.
  • Integer or boolean t. mix(a, b, 1) does not compile in WebGL 1, which never converts an int to a float; write 1.0. The form that takes a bvec to pick per channel does not exist in GLSL ES 1.00 either; build a float mask with step instead.

What it costs

mix itself is very cheap, even on a phone: about a subtract and a multiply-add per channel. The cost is in what you feed it. mix(effectA(), effectB(), t) computes both effects for every pixel, even where t is exactly 0.0 or 1.0. With two colours that does not matter; with two expensive effects it can. The branching lesson in Track 6 returns to this.

You can also pass a vec3 as t to blend each channel by its own amount. It costs the same as a single float.

In real games

Linear interpolation is one of the most common operations in any shader, so the engines put it front and centre: Unity's Shader Graph has a Lerp node and Godot's visual shader editor has a Mix node.

Terrain is a clear case of a mask chosen by an artist. Unity's built-in terrain stores how much of each layer, such as grass, rock or sand, to show at each spot in control textures it calls alphamaps, and its shader blends the layers by those weights. Hit flashes and fades to black are the same blend with a t that changes over time instead of across space.

Your turn (15 minutes)

Turn the LÖVE example into a day and night sky:

  1. Use the vertical coordinate as the mask: float t = uv.y;. In LÖVE, uv.y is 0.0 at the top, so a is the colour overhead and b is the colour at the horizon.
  2. Add a u_time_of_day uniform from 0.0 (night) to 1.0 (day), sent from Lua and changed with the left and right keys.
  3. Build the two sky colours with two more mixes: vec3 top = mix(vec3(0.02, 0.03, 0.10), vec3(0.20, 0.45, 0.90), u_time_of_day); and the same for the horizon colour with your own choices. Then return mix(top, horizon, t).

You are done when sliding the time of day fades smoothly from a dark night gradient to a blue day gradient, using nothing but mix.

Takeaways

  • mix(a, b, t) is a * (1.0 - t) + b * t: a at 0.0, b at 1.0, a straight line between.
  • t can be different at every pixel. Any value from 0.0 to 1.0 is a mask: a gradient, a step, a circle, a wave.
  • Keep t inside 0 to 1, because mix does not clamp.
  • HLSL and Unity call it lerp; Godot and GLSL call it mix. The argument order is the same.
  • The function is cheap; everything you compute to feed it is the real cost.
