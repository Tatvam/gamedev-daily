Raycasts

How to find the first thing a ray hits, how far away it is and which way the surface faces, for boxes and circles.

A guard sees you straight through a wall. A laser passes a crate and burns the player standing behind it. A turret shoots at an enemy behind its own back. All three are the same function giving the wrong answer: the raycast, which asks "if I look from here in this direction, what do I hit first?"

A ray is a start point, a direction and a distance

A ray starts at an origin O and runs in a direction D. Keep D at length 1, a unit vector, so that distances along the ray come out in pixels. Every point on the ray is:

P(t) = O + t * D

In words: walk t pixels from the origin in the direction D. Only t of zero or more is on the ray; negative t is behind the origin. A raycast also has a maximum distance.

A good raycast reports five things: whether anything was hit, which object, the distance t, the hit point P(t), and the normal, the unit vector pointing straight out of the surface at that point. Ricochets and wall decals need it.

Ray against box: two slabs

Think of the box as the place where two bands overlap: the x slab between its left and right edges, and the y slab between its top and bottom. The ray crosses each band once, entering at one distance and leaving at another.

The distance at which the ray reaches the left edge is:

t = (left - O.x) / D.x

In words: how far the ray must go before its x reaches the edge. Do the same for the right edge, and swap the two if the ray points left, so that the smaller one is the entry. Repeat on y.

The ray is inside the box only while it is inside both slabs. So it enters the box at the later of the two entries and leaves at the earlier of the two exits. If it would leave before it enters, it missed.

The normal comes for free: it belongs to the axis whose entry was later. If that is x and the ray points right, it hit the left face, so the normal is (-1, 0).

One special case: a ray pointing straight down has D.x = 0, and the division above is a division by zero. Such a ray never crosses a vertical edge, so check instead whether O.x lies between left and right. If it does, the x slab places no limit on t; if not, it is a miss.

Ray against circle

Let f = O - C be the arrow from the circle's centre C to the origin, and r the radius. Two numbers do the work:

b = f.x * D.x + f.y * D.y     -- minus the distance to the closest approach
k = f.x * f.x + f.y * f.y - r * r

The first is a dot product. It says how far along the ray the centre is, with the sign flipped. The second is the squared distance to the centre minus the squared radius: negative when the origin is inside the circle.

t = -b - math.sqrt(b * b - k)

In words: go to the point of closest approach, then step back half a chord. If b * b - k is negative, the ray passes further than r from the centre and misses. If t is negative, the circle is behind the origin or the origin is inside it. The normal is the arrow from the centre to the hit point, divided by r to make it length 1.

The first hit is the closest one

Test every shape, keep only hits with t from 0 to the maximum distance, and keep the one with the smallest t. Stopping at the first shape in your list that reports a hit is the classic bug: the list is in creation order, not distance order.

Correct maths, wrong game answer

A ray that starts inside a shape is, strictly, touching it at distance 0. A game almost never wants that answer: a character's sight ray starts inside its own body. The code here ignores shapes that contain the origin. Godot does the same by default (hit_from_inside is off on RayCast2D); Unity's 2D physics instead has a project setting, Queries Start In Colliders, that decides it.

The code

A complete LÖVE program with the demo's starting scene. The ray aims at the mouse; click to move its origin. It prints the shape, distance and normal of the first hit.

-- Shapes in list order. Boxes: x, y top-left corner, w, h. Circles: x, y centre, r.
-- y grows downwards. All lengths are in pixels.
local shapes = {
  { name = "A", x = 440, y = 150, w = 110, h = 70 },
  { name = "B", x = 300, y = 150, r = 40 },
  { name = "C", x = 170, y = 70, w = 80, h = 50 },
  { name = "D", x = 210, y = 270, r = 40 },
  { name = "E", x = 12, y = 140, w = 36, h = 60 },
  { name = "F", x = 330, y = 270, w = 150, h = 40 },
}
local MAX_DIST = 500
-- Origin x, y and a direction dx, dy of length 1.
local ray = { x = 80, y = 170, dx = 1, dy = 0 }
local hit = nil

-- Entry and exit distance on one axis, or nil if the ray misses this slab.
local function slab(o, d, lo, hi)
  if d == 0 then
    if o < lo or o > hi then return nil end
    return -math.huge, math.huge
  end
  local t1, t2 = (lo - o) / d, (hi - o) / d
  if t1 > t2 then t1, t2 = t2, t1 end
  return t1, t2
end

-- Returns distance, normal x, normal y, or nil.
local function rayBox(ray, b)
  local xin, xout = slab(ray.x, ray.dx, b.x, b.x + b.w)
  if not xin then return nil end
  local yin, yout = slab(ray.y, ray.dy, b.y, b.y + b.h)
  if not yin then return nil end
  local tin, tout = math.max(xin, yin), math.min(xout, yout)
  if tin > tout or tin < 0 then return nil end  -- missed, behind, or starts inside
  if xin > yin then return tin, (ray.dx > 0) and -1 or 1, 0 end
  return tin, 0, (ray.dy > 0) and -1 or 1
end

local function rayCircle(ray, c)
  local fx, fy = ray.x - c.x, ray.y - c.y
  local b = fx * ray.dx + fy * ray.dy
  local k = fx * fx + fy * fy - c.r * c.r
  local disc = b * b - k
  if disc < 0 then return nil end
  local t = -b - math.sqrt(disc)
  if t < 0 then return nil end  -- behind, or starts inside
  local px, py = ray.x + ray.dx * t, ray.y + ray.dy * t
  return t, (px - c.x) / c.r, (py - c.y) / c.r
end

-- Test every shape and keep the closest hit, not the first one in the list.
local function raycast(ray, maxDist)
  local best = nil
  for _, s in ipairs(shapes) do
    local t, nx, ny
    if s.r then t, nx, ny = rayCircle(ray, s) else t, nx, ny = rayBox(ray, s) end
    if t and t <= maxDist and (best == nil or t < best.t) then
      best = { t = t, nx = nx, ny = ny, shape = s }
    end
  end
  if best then
    best.x, best.y = ray.x + ray.dx * best.t, ray.y + ray.dy * best.t
  end
  return best
end

function love.mousepressed(mx, my, button)
  if button == 1 then ray.x, ray.y = mx, my end
end

function love.update(dt)
  local mx, my = love.mouse.getPosition()
  local ax, ay = mx - ray.x, my - ray.y
  local len = math.sqrt(ax * ax + ay * ay)
  if len > 0 then ray.dx, ray.dy = ax / len, ay / len end
  hit = raycast(ray, MAX_DIST)
end

function love.draw()
  for _, s in ipairs(shapes) do
    if s.r then
      love.graphics.circle("line", s.x, s.y, s.r)
    else
      love.graphics.rectangle("line", s.x, s.y, s.w, s.h)
    end
  end
  local ex, ey = ray.x + ray.dx * MAX_DIST, ray.y + ray.dy * MAX_DIST
  if hit then ex, ey = hit.x, hit.y end
  love.graphics.line(ray.x, ray.y, ex, ey)
  if hit then
    love.graphics.circle("fill", hit.x, hit.y, 4)
    love.graphics.line(hit.x, hit.y, hit.x + hit.nx * 30, hit.y + hit.ny * 30)
    love.graphics.print(string.format("%s at %.1f px, normal (%.2f, %.2f)",
      hit.shape.name, hit.t, hit.nx, hit.ny), 10, 10)
  end
end
# A RayCast2D child node. target_position is relative to the node.
@onready var ray: RayCast2D = $RayCast2D

func _physics_process(_delta: float) -> void:
    ray.target_position = Vector2(500, 0)   # 500 px to the right
    ray.force_raycast_update()              # use the new target this frame
    if ray.is_colliding():
        var point := ray.get_collision_point()
        var normal := ray.get_collision_normal()
        var other := ray.get_collider()

# Or ask the physics space directly, without a node.
# The result is an empty Dictionary when nothing is hit.
func cast_ray(from: Vector2, to: Vector2) -> Dictionary:
    var space := get_world_2d().direct_space_state
    var query := PhysicsRayQueryParameters2D.create(from, to)
    return space.intersect_ray(query)   # keys include "position" and "normal"
public LayerMask wallMask;   // which layers the ray can hit

void FixedUpdate()
{
    Vector2 origin = transform.position;
    RaycastHit2D hit = Physics2D.Raycast(origin, Vector2.right, 500f, wallMask);
    if (hit.collider != null)
    {
        float distance = hit.distance;
        Vector2 point = hit.point;
        Vector2 normal = hit.normal;
    }
}

Both engines return the closest hit and filter by collision layers: the ray's collision_mask in Godot, the layer mask argument in Unity.

Pitfalls

  • Taking the first hit in the list. Shapes are stored in creation order. Always compare distances. Box2D's ray cast reports the fixtures it crosses in no guaranteed order, for the same reason.
  • Forgetting t >= 0. Without it you are intersecting an infinite line, and enemies shoot at things behind them.
  • A direction that is not length 1. Then t is not in pixels, the maximum distance means something else, and the circle formula above is wrong. Normalise once, and never divide by a zero length: keep the old direction instead.
  • Hitting yourself. A ray cast from a character's centre starts inside the character. Ignore shapes that contain the origin, exclude the caster, or start the ray just outside its body.

In real games

Hitscan weapons, where the bullet arrives instantly, are a raycast from the gun. Enemy line of sight is a ray from the eyes to the player that must not hit a wall first. Platformers often cast short rays down from the feet to find the floor, which a later lesson covers. Mouse picking in a 2D scene is a ray or point test from the cursor.

Your turn (15 minutes)

Take the Lua program above and make the ray bounce once. When it hits, reflect the direction off the normal: dot = dx * nx + dy * ny, then the new direction is dx - 2 * dot * nx, dy - 2 * dot * ny. Cast a second ray from the hit point, moved 0.01 pixels along the normal so it does not start inside the surface, with the distance that was left over.

You are done when a ray aimed at box A's left face bounces straight back, and one aimed at circle B bounces off at an angle that changes smoothly as you move the mouse.

Takeaways

  • A ray is O + t * D with D of length 1, so t is a distance in pixels, and only t >= 0 counts.
  • Ray against box: the hit is the later of the two slab entries, and it is a miss if that comes after the earlier exit. The normal belongs to the later axis.
  • Ray against circle: go to the closest approach and step back half a chord, t = -b - sqrt(b² - k).
  • The first hit is the one with the smallest t, never the first one in the list.
  • Decide what a ray that starts inside a shape should do. Games usually ignore that shape.
