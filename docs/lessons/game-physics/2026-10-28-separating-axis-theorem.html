The separating axis theorem

How to test two convex polygons, rotated boxes included, for overlap by looking for one axis on which their shadows have a gap.

Your spinning saw blade hits the player while it is still visibly a hand's width away. Both were wrapped in axis-aligned boxes, and the boxes overlapped even though the shapes inside did not. Once things rotate or slope, you need a test that looks at the real outline.

Shadows on a line

The test in this lesson works on convex shapes: shapes where a straight line between any two points inside stays inside. Boxes, triangles and regular hexagons are convex. An L shape or a star is not.

Pick a direction, an axis, as a vector of length 1, (ax, ay). Shine a light at right angles to it and every shape casts a shadow onto it. The shadow of one corner is a dot product:

local s = x * ax + y * ay

In words: s is how far the corner lies along the axis. The smallest and largest s over all corners give the polygon's shadow, also called its projection.

The separating axis theorem (SAT) says that two convex shapes do not overlap if and only if some axis shows a gap between their shadows. One gap proves they are apart. One overlap proves nothing: you must check every axis that could show a gap.

The bug: x and y are not enough

The AABB test from earlier lessons is the SAT with only x and y. That is enough for boxes that never rotate, and nothing else.

Take a triangle with corners (100, 100), (200, 100) and (100, 200), and a box from (170, 170) to (230, 230). On x the triangle covers 100 to 200 and the box 170 to 230: an overlap of 30. The same on y. An AABB test reports a hit.

Now try the diagonal axis (0.707, 0.707), perpendicular to the triangle's long edge. The triangle's corners give 141.4, 212.1 and 212.1. The box's give 240.4, 282.8, 282.8 and 325.3. The gap is 240.4 - 212.1 = 28.3 pixels: the shapes are apart.

Which axes to test

For two convex polygons in 2D you only need the edge normals: the directions perpendicular to each edge of either shape. Why: if the shapes are apart, slide a straight line into the gap and turn it until it lies flat against an edge of one shape. It still separates them, and the axis perpendicular to it is that edge's normal.

local ex, ey = q.x - p.x, q.y - p.y     -- the edge from corner p to corner q
local len = math.sqrt(ex * ex + ey * ey)
local ax, ay = -ey / len, ex / len      -- turned a quarter turn, length 1

In words: swap the edge's two parts, negate one, and divide by the length. Which way it points does not matter; flipping it flips both shadows and keeps the gap.

The full test: for every edge of A, then of B, project both shapes and compare. Stop at the first gap. If none shows one, they overlap. The triangle and box give 3 + 4 = 7 axes; the test stops at the second.

For rotated shapes, turn each local corner into a world position first, x = cx + lx * cos(a) - ly * sin(a) and y = cy + lx * sin(a) + ly * cos(a), then run the same test.

The overlap is a number too

With no gap, each axis still says how much the shadows overlap: the code computes it as a negative gap. The smallest overlap is the shortest way to push the shapes apart, the next lesson.

The code

A LÖVE program with the diagram's shapes as flat lists of corners, the format love.graphics.polygon takes. It prints gap 28.3 px on axis (-0.71, -0.71): the diagram's axis, pointing the other way.

-- Convex polygons as flat lists of corners: x1, y1, x2, y2, ...
local triangle = { 100, 100,  200, 100,  100, 200 }
local box      = { 170, 170,  230, 170,  230, 230,  170, 230 }

-- The shadow of a polygon on the unit axis (ax, ay): smallest and largest value.
local function project(poly, ax, ay)
  local lo, hi = math.huge, -math.huge
  for i = 1, #poly, 2 do
    local d = poly[i] * ax + poly[i + 1] * ay   -- dot product
    lo = math.min(lo, d)
    hi = math.max(hi, d)
  end
  return lo, hi
end

-- Tries the normal of every edge of shape. Returns gap, ax, ay at the first gap.
local function findGap(shape, a, b)
  for i = 1, #shape, 2 do
    local j = i + 2
    if j > #shape then j = 1 end               -- the last edge closes the loop
    local ex, ey = shape[j] - shape[i], shape[j + 1] - shape[i + 1]
    local len = math.sqrt(ex * ex + ey * ey)
    local ax, ay = -ey / len, ex / len          -- the edge turned a quarter turn
    local aLo, aHi = project(a, ax, ay)
    local bLo, bHi = project(b, ax, ay)
    local gap = math.max(bLo - aHi, aLo - bHi)  -- negative means overlap
    if gap > 0 then return gap, ax, ay end
  end
  return nil
end

-- Separated if either shape has an edge whose normal shows a gap.
local function separation(a, b)
  local gap, ax, ay = findGap(a, a, b)
  if not gap then gap, ax, ay = findGap(b, a, b) end
  return gap, ax, ay
end

function love.draw()
  love.graphics.polygon("line", triangle)
  love.graphics.polygon("line", box)
  local gap, ax, ay = separation(triangle, box)
  if gap then
    love.graphics.print(string.format("gap %.1f px on axis (%.2f, %.2f)", gap, ax, ay), 10, 10)
  else
    love.graphics.print("overlap", 10, 10)
  end
end
# Godot shapes can test themselves against each other with Shape2D.collide.
extends Node2D

func _ready() -> void:
    var tri := ConvexPolygonShape2D.new()
    tri.points = PackedVector2Array([Vector2(100, 100), Vector2(200, 100), Vector2(100, 200)])
    var box := RectangleShape2D.new()
    box.size = Vector2(60, 60)                  # centred on its transform
    # Each shape is placed by a Transform2D(rotation, position).
    var hit := tri.collide(Transform2D.IDENTITY, box, Transform2D(0.0, Vector2(200, 200)))
    print(hit)   # false: the shapes are apart
// GapCheck.cs: assign a PolygonCollider2D and a BoxCollider2D in the Inspector.
using UnityEngine;

public class GapCheck : MonoBehaviour
{
    public PolygonCollider2D triangle;
    public BoxCollider2D box;

    void FixedUpdate()
    {
        ColliderDistance2D d = Physics2D.Distance(triangle, box);
        if (!d.isValid) return;
        // distance is the gap, negative when the colliders overlap; normal is the direction
        if (d.isOverlapped) Debug.Log("overlap " + (-d.distance));
        else Debug.Log("gap " + d.distance + " along " + d.normal);
    }
}

In Godot or Unity you rarely write this yourself: a CollisionPolygon2D or PolygonCollider2D is tested every physics step for you. Neither engine documents which algorithm it uses inside; only the answer is promised.

Pitfalls

  • Testing only one shape's normals. In the demo's starting scene the only gap is on the triangle's axis A2. Test only the box's normals, x and y, and the bounding-box bug is back.
  • Concave shapes. A box inside the notch of a U shape can be clear of it while every axis shows an overlap. Split concave shapes into convex pieces. Godot's CollisionPolygon2D does this in its default Solids build mode.
  • Skipping the normalising. The yes or no answer survives, but gaps and overlaps get multiplied by the edge length, so you cannot compare them between axes.
  • Circles. A circle's shadow is its centre's value plus and minus the radius, and it needs one extra axis: from its centre to the polygon's nearest corner.
  • Touching. The code treats a gap of exactly zero as an overlap. Either choice works if every test in your game agrees.
  • Cost. Work grows with corners times edges. Skip parallel edges (a box has only two directions; the demo does this) and run a cheap bounding-box test first: AABBs remain a good quick rejection.
  • 3D needs more axes. Besides face normals, test the cross products of pairs of edges, one from each shape.

In real games

Box2D version 2, the 2D physics engine behind many games, tests two polygons by searching the edge normals of both for the axis of largest separation (b2FindMaxSeparation in its source): the SAT, also reporting the least overlap. Godot's 2D physics server has a separating-axis collision solver too.

In 3D, the 15-axis test for two rotated boxes (3 face normals from each plus 9 edge cross products) was popularised by the OBBTree paper of Gottschalk, Lin and Manocha in 1996.

Takeaways

  • The shadow of a polygon on an axis is the smallest and largest dot product of its corners with that axis.
  • Two convex shapes are apart if and only if some axis shows a gap between their shadows. One gap is proof; one overlap is not.
  • For two polygons in 2D, test the edge normals of both shapes and stop at the first gap.
  • The AABB test is the SAT with only x and y, which is why rotated shapes fool it.
  • The SAT works only on convex shapes; split concave ones into convex pieces.
