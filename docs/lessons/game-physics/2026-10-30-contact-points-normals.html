Contact points and normals

What a collision must report for a response to work: the normal, the depth, and up to two contact points found by clipping one face against another.

You drop a crate flat onto the floor. Instead of settling, it rocks from corner to corner forever. The overlap test and the push-out direction are both right. The problem is where the push is applied: your collision reports one corner, and that corner jumps sides every time the crate tilts by a hair.

What a collision has to report

The last two lessons answered "do they overlap?" and "which way out, and how far?". A response also needs to know where. The full report for one touching pair is called a contact manifold.

FieldWhat it meansUsed for
NormalA unit vector pointing from A to B, at right angles to the touching surfaceThe direction to push and to bounce
Contact pointsWhere the bodies touch, one or two points in 2DSpin, friction, sparks and sounds
Depth per pointHow far each point has sunk past the surfaceHow hard to push at that point

The points matter because a push away from a body's centre also makes it turn. Push a box up near its right corner and it spins anticlockwise. Push equally at both bottom corners and the turns cancel.

Why one point fails

A flat face resting on a flat face touches along a whole segment. In 2D, any spread of pushes along a segment can be described by two pushes at its ends, so two points are enough.

A common shortcut reports only the deepest corner. Tilt the box one degree clockwise and its right corner takes the whole push; tilt it the other way and the left corner does. The push jumps across the box, the spin flips, and the box rocks.

Clipping: finding the points in four steps

The usual method is called clipping. It works for any two convex polygons.

1. Choose the reference face

For every face of A, take its outward normal n and a corner p on that face, and find the corner of B that sits furthest behind it:

separation = min over corners q of B of (q - p) · n

In words: how far B's deepest corner is outside this face. Positive means a gap. Negative means B pokes in that far. This is the separating axis test written from one side; the face with the largest separation is the axis of least penetration from the last lesson. Do the same for B's faces against A. The winner is the reference face, and its normal is the contact normal.

2. Find the incident face

On the other body, the incident face is the face whose outward normal gives the most negative dot product with n: the face doing the poking.

3. Clip to the sides

Draw a line through each end of the reference face, at right angles to it. Cut away any part of the incident face outside those two side lines.

4. Keep the points that are inside

The clipped segment has two ends. For each end q, with v1 the first corner of the reference face:

depth = -(q - v1) · n

In words: how far the point has sunk below the reference face. Keep it if the depth is zero or more; a negative depth means that end is still outside. A flat landing gives two points, a corner landing one.

The numbers

Slab A runs from (100, 200) to (300, 240). Crate B runs from (260, 145) to (320, 205): it overhangs A's right end and has sunk 5 pixels. The y axis points down.

  • A's top face has normal (0, -1). B's deepest corner below it is at y = 205, so the separation is -(205 - 200) = -5. A's other faces score -40, -95 and -220.
  • B's bottom face also scores -5. Ties go to A, so A's top face is the reference face.
  • B's bottom face, normal (0, 1), is the incident face, from (320, 205) to (260, 205).
  • The side lines are x = 100 and x = 300. The end at x = 320 is outside and moves to x = 300.
  • Both ends are 5 pixels below y = 200: depth 5 each, both kept.

The manifold: normal (0, -1), points (300, 205) and (260, 205), depth 5 each. Without step 3, one point would float at (320, 205), past the end of the slab.

Correct physics, good game

Real objects touch over a patch with pressure spread across it. Two points is a simplification, and the right one for a game: cheap, exact for a resting box, and steady when a body tilts slightly.

The code

The four steps for two convex polygons. With the example boxes it prints the normal (0.0, -1.0) and the points (300, 205) and (260, 205), each 5 deep.

-- Convex polygons as flat lists of corners, clockwise on screen (y points down).
local slab = { 100, 200,  300, 200,  300, 240,  100, 240 }
local box  = { 260, 145,  320, 145,  320, 205,  260, 205 }

local function corner(poly, i)                 -- i counts from 1 and wraps around
  i = (i - 1) % (#poly / 2) + 1
  return poly[2 * i - 1], poly[2 * i]
end

local function outwardNormal(poly, i)
  local x1, y1 = corner(poly, i)
  local x2, y2 = corner(poly, i + 1)
  local len = math.sqrt((x2 - x1) ^ 2 + (y2 - y1) ^ 2)
  return (y2 - y1) / len, -(x2 - x1) / len
end

-- Step 1: the face of a that b sinks into least. Positive separation means a gap.
local function bestFace(a, b)
  local bestSep, bestI = -math.huge, 1
  for i = 1, #a / 2 do
    local nx, ny = outwardNormal(a, i)
    local px, py = corner(a, i)
    local sep = math.huge
    for j = 1, #b / 2 do
      local qx, qy = corner(b, j)
      sep = math.min(sep, (qx - px) * nx + (qy - py) * ny)
    end
    if sep > bestSep then bestSep, bestI = sep, i end
  end
  return bestSep, bestI
end

-- Step 3: keep the part of a segment where x * tx + y * ty >= o.
local function clip(x1, y1, x2, y2, tx, ty, o)
  if not x1 then return nil end
  local d1 = x1 * tx + y1 * ty - o
  local d2 = x2 * tx + y2 * ty - o
  if d1 < 0 and d2 < 0 then return nil end
  local t = d1 / (d1 - d2)                     -- where the segment crosses the line
  if d1 < 0 then
    x1, y1 = x1 + (x2 - x1) * t, y1 + (y2 - y1) * t
  elseif d2 < 0 then
    x2, y2 = x1 + (x2 - x1) * t, y1 + (y2 - y1) * t
  end
  return x1, y1, x2, y2
end

local function contacts(a, b)
  local sepA, faceA = bestFace(a, b)
  local sepB, faceB = bestFace(b, a)
  if sepA > 0 or sepB > 0 then return nil end
  local ref, inc, face, flip = a, b, faceA, false
  if sepB > sepA + 0.1 then ref, inc, face, flip = b, a, faceB, true end
  local nx, ny = outwardNormal(ref, face)
  local x1, y1 = corner(ref, face)
  local x2, y2 = corner(ref, face + 1)
  -- Step 2: the face of inc that points most against the normal.
  local incI, lowest = 1, math.huge
  for i = 1, #inc / 2 do
    local mx, my = outwardNormal(inc, i)
    if mx * nx + my * ny < lowest then incI, lowest = i, mx * nx + my * ny end
  end
  local px1, py1 = corner(inc, incI)
  local px2, py2 = corner(inc, incI + 1)
  local tx, ty = x2 - x1, y2 - y1              -- along the reference face
  px1, py1, px2, py2 = clip(px1, py1, px2, py2, tx, ty, x1 * tx + y1 * ty)
  px1, py1, px2, py2 = clip(px1, py1, px2, py2, -tx, -ty, -(x2 * tx + y2 * ty))
  if not px1 then return nil end
  -- Step 4: keep the ends that have sunk below the reference face.
  local points = {}
  for _, p in ipairs({ { px1, py1 }, { px2, py2 } }) do
    local depth = -((p[1] - x1) * nx + (p[2] - y1) * ny)
    if depth >= 0 then table.insert(points, { x = p[1], y = p[2], depth = depth }) end
  end
  if #points == 0 then return nil end
  if flip then nx, ny = -nx, -ny end           -- the normal always points from a to b
  return { nx = nx, ny = ny, points = points }
end

function love.draw()
  love.graphics.polygon("line", slab)
  love.graphics.polygon("line", box)
  local m = contacts(slab, box)
  if not m then return end
  love.graphics.print(string.format("normal (%.1f, %.1f)", m.nx, m.ny), 10, 10)
  for i, p in ipairs(m.points) do
    love.graphics.circle("fill", p.x, p.y, 4)
    love.graphics.print(string.format("(%.0f, %.0f) depth %.1f", p.x, p.y, p.depth), 10, 10 + 20 * i)
  end
end

# this prints what it reports each physics step.
extends RigidBody2D

func _ready() -> void:
    contact_monitor = true
    max_contacts_reported = 4

func _integrate_forces(state: PhysicsDirectBodyState2D) -> void:
    for i in state.get_contact_count():
        print(i, " at ", state.get_contact_local_position(i),
              " normal ", state.get_contact_local_normal(i))
// ShowContacts.cs: on a GameObject with a Rigidbody2D and a Collider2D.
using UnityEngine;

public class ShowContacts : MonoBehaviour
{
    void OnCollisionStay2D(Collision2D collision)
    {
        for (int i = 0; i < collision.contactCount; i++)
        {
            ContactPoint2D c = collision.GetContact(i);
            Debug.DrawRay(c.point, c.normal * 0.5f, Color.red);
            Debug.Log(i + " at " + c.point + " depth " + (-c.separation));
        }
    }
}

In Godot, a CharacterBody2D gets the same data from KinematicCollision2D: get_position, get_normal, get_depth. In Unity, ContactPoint2D.separation is negative when the colliders overlap. Check which way each engine's normal points before relying on its sign.

Pitfalls

  • Normal pointing the wrong way. When B's face wins, the reference normal points out of B, towards A. Flip it so the normal always means "from A to B", or every push for that case goes the wrong way.
  • Flicker between reference faces. Two flat faces resting on each other score almost the same separation. If the winner swaps every step, the points jump around. Prefer A unless B is better by a small margin; the code uses 0.1 pixels.
  • One depth for all points. Then the shallow corner is pushed as hard as the deep one and a tilted box never straightens. Store a depth per point.
  • Mixing up which body the points lie on. Clipping gives points on the incident face; some engines report a midpoint instead. Pick one and stick to it.
  • Circles are different. A circle touches anything at a single point, so it never needs clipping.
  • Contacts are rebuilt every step. Fine for a bounce. Stable stacks need to recognise the same contact across steps, covered with solver iterations later.

In real games

Box2D version 2.4 builds polygon contacts this way in b2CollidePolygons: it finds the face of least penetration on each polygon, prefers the first polygon unless the second is better by a small tolerance, finds the incident edge, and clips it with b2ClipSegmentToLine. Its b2Manifold holds at most two points.

Godot and Unity both hand your scripts contacts as lists of points with normals, through the calls in the code section.

Takeaways

  • A contact manifold reports a normal from A to B, one or two contact points, and a depth for each point.
  • Points decide spin. A single deepest corner makes a resting box rock, because it jumps sides with every tiny tilt.
  • Clipping: pick the reference face, find the incident face, cut it to the reference face's sides, keep the ends that sank in.
  • Flip the normal when the reference face belongs to B, and break near ties the same way every step.
